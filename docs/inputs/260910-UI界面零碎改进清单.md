## UI-001 模型选择入口冻结提示优化

- 反馈日期：2026-09-10。
- 状态：待评估（已记录，未实现）。
- 目标版本：待定。
- 补充材料：用户会话附图。
- 相关背景：[模型注册与管理模式讨论](260827-模型注册与管理模式讨论.md)。

### 原始反馈

> 这个问题记一下, 不要每个模型provider后面都加上冻结解释, 你要么就把select入口直接冻结了, 加上tooltip

### 问题与期望

- 附图中，模型选择菜单在每个 provider 后重复展示“存在活动运行或排队输入……”的冻结说明，文字被截断并挤占菜单空间。
- 无法切换模型时，直接禁用模型选择的 select 入口，并在入口通过 tooltip 统一说明冻结原因。
- 不在每个 provider 条目后重复追加冻结解释。
- 本次仅记录问题与用户期望，后续安排实现。
