# 协作模式与助理模式

- 记录日期：2026-09-30。
- 状态：待评估，后续深化。
- 来源：用户关于后续界面改版的会话讨论。
- 目标版本：待定；本次仅记录方向，不调整当前版本范围。

## 已确定的方向

后续希望提供两种操作模式，名称采用「协作模式 / 助理模式」。讨论中曾使用
「协同办公」「交付式办公」「委托模式」「交办模式」等名称，最终以本组名称为准。

### 协作模式

延续当前模式：用户自己选择项目、会话、智能体和模型来组织工作；会话内可以查看
处理过程、上下文信息等，并参与和调整执行。

### 助理模式

把智能体当作真人同事或助理使用：

- 左侧列表只显示对应的智能体入口，不以项目和会话列表作为主要导航。
- 与智能体交流像与人聊天一样，采用气泡消息界面；聊天是主要操作入口。
- 用户向智能体交代工作，具体任务由智能体自行组织和分派，类似现有总控会话的方向。
- 用户通过沟通跟进工作、补充要求并接收成果，减少手动组织执行会话的负担。

## 后续深化线索（讨论建议，尚未确认）

- 智能体作为长期沟通入口，承接多项独立工作时，如何隔离任务上下文并确定消息归属。
- 任务进展、待确认事项和交付成果如何融入聊天；任务卡片、文件卡片和工作清单的具体形式。
- 处理过程和上下文详情的查看入口，以及用户需要深入介入时与协作模式的衔接。
- 接单智能体如何汇总委派进展与最终成果，如何处理失败、阻塞和用户调整。
- 模型选择、项目关联、工具授权和自主执行范围如何配置。
- 两种模式如何复用现有 Session、Run、计划和委派能力，以及模式切换的具体语义。
