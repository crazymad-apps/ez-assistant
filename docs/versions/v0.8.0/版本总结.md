## 三、形成的核心能力

- `assistant-runtime` 成为 Session、Conversation、Run、事件、取消、并发和关闭的权威业务层，
  不依赖 Tauri、数据库或具体 Provider。
- `assistant-protocol` 提供轻量跨层 Command/Result、Snapshot、Event、ID 和安全错误 DTO；完整
  Conversation、握手、frame 和请求关联保持 Host 私有。
- 一个 Session 长期持有一个冻结 Agent；同一 Session 的上下文变更 Run 串行，不同 Session 使用
  Tokio 异步并发，不创建会话级操作系统进程。
- `apps/runtime-host` 作为正式产品进程入口装配 Provider、Agent Factory 和安全默认 Authorizer；
  Unix Socket、内核实例锁、异常退出恢复和受控关闭形成最小跨进程闭环。
- feature-gated Ratatui Demo 证明 Runtime 可脱离 Tauri 运行和重连，但其 wire、状态、快捷键和
  Conversation 查询仍是私有验证实现。

## 四、偏差与边界

- 实现与已确认功能设计没有范围偏差；技术方案原传输物理树按职责收敛为 `endpoint.rs` 与
  `wire.rs`，没有改变契约或依赖方向。
- M5 Review 将手写 CLI 改为 `clap`、逐行 REPL 改为 Ratatui TUI，并用标准库内核文件锁替代
  可能受单活动客户端影响的握手探测；相关设计和模块文档已同步。
- 本版本没有接入正式 Plan/Build、Ask/Auto、文件/Shell、Workspace、上传、记忆、持久化、事件
  replay、系统 daemon 或桌面 UI；这些能力继续按独立业务版本进入 Runtime。
- Linux、Windows 和第二家真实 OpenAI-compatible Provider 未实测，不作通过声明。
