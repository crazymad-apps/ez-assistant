# v0.24.0 版本总结

## 版本结论

`v0.24.0` 资源工作区、用户浏览器与终端于 2026-09-05 完成并归档。
用户在确认人工检查项、收到浏览器补充修复结果后要求准备归档，M7 据此完成收尾确认。
本次归档完成开发验收，不包含 Git 暂存、提交、推送、tag 或分发发布。

## 实际完成

- Desktop 右栏成为按会话/草稿归属的资源标签区，保留当前上下文，支持工作空间、文件、浏览器和终端；
  切换会话切换整组内容，切回恢复；普通页面使用 20 实例 LRU，终端持续运行。
- 主目录、附加目录和会话私有目录只读浏览，支持目录定位、展开/收起、过滤、统一 Material 文件图标、
  面包屑同级下拉和集中资源菜单。
- 文本/代码使用 Monaco 自动高亮；Markdown 复用消息渲染器；图片使用 react-zoom-pan-pinch 缩放拖拽；
  PDF 使用原生阅读器。Assistant 的显式 file URI 交付可以进入资源栏，模型冻结上下文增加对应输出约定。
- 用户浏览器使用系统 WebView，具备导航、标题、网站数据保持、弹窗/下载处理和主界面 IPC 隔离；
  修复加载超时隐藏网页、普通操作错误阻断网页及旧 URL 查询污染当前页面的问题。
- 用户终端使用 xterm.js 与独立 PTY，统一浅色主题变量，支持中文输入、后台输出、背压和进程组回收；
  Shell 退出自动关闭标签，窗口隐藏继续运行，真正退出统一清理。
- 轻量标签与查看状态保存到既有桌面偏好，客户端重开恢复；修复多 WebView 下窗口关闭/显示等操作。

## 偏差、遗留与后续

- 会话快照、终端免淘汰、PDF 和图片交互均为用户在开发中确认的范围补充，已纳入最终设计。
- Windows/Linux 未实机验收；Windows 终端当前不支持可取消 I/O。macOS 签名、公证与分发发布未执行。
- 缓存淘汰或重启后网页重载最后 URL，终端重建 Shell；PDF 不恢复阅读器页码/缩放。
- 原生菜单保留平台外观，其他 HTML 浮层仍暂时隐藏网页。普通页面缓存是数量预算；不承诺回收主动脱离 PTY 的进程。
- 本地另有 agent-robot S3.2 设备/语音联调待办，继续保留在本地进度，不由本次归档关闭。
- 下一目标版本与范围尚未确认，状态为待启动。候选方向继续由[版本管理](../../版本管理.md)和
  [输入池](../../inputs/)维护，不自动启动新阶段。
