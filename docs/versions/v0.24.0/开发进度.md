### child WebView 结果

- Tauri `Window::add_child` 能在同一窗口创建系统 WKWebView；实机截图检查确认主 WebView 位于左侧，
  不受控页面位于右侧，不是独立窗口或 Chromium。
- 创建尺寸 `620×700 @ (550, 24)`，运行时调整为 `580×660 @ (575, 48)`；`bounds()` 返回值与请求一致。
  `hide()`、`show()`、`set_focus()` 均成功，窗口整体隐藏 500ms 后能由原生线程恢复。
- `on_navigation`、`on_page_load` 与 `on_document_title_changed` 均收到真实页面事件；固定
  `history.back()`、`history.forward()` 和 `window.stop()` 脚本生效。慢请求停止后服务端出现一次预期的
  `Broken pipe`，说明加载已被 WebView 中止。
- `window.open` 被 `NewWindowResponse::Deny` 拒绝；下载回调返回 `false`，随后收到
  `Finished { success: false }`。WebKit 同时打印取消下载的系统日志，未生成下载文件。
- 外部页面的 `window.__TAURI__` 与主页面设置的 Runtime token 均为 `undefined`。Tauri 内部 IPC 对象仍
  可被页面探测到，但 `prototype_secret`、模拟文件桥和模拟终端桥调用均被仅绑定 `webviews: ["main"]`
  的 capability 拒绝，命令处理函数没有执行。
- 首轮写入的 `m0_cookie=persisted` 在重启后的首次 HTTP 请求中已随 `Cookie` header 发出，且
  `Webview::cookies()` 可读，证明系统 WebView 数据存储跨进程保留。wry 0.55.1 的
  `cookies_for_url()` 会过滤掉 `domain=None` 的 host-only Cookie，产品不能把该接口的空结果误判为未登录。
- `Webview::close()` 成功，关闭后状态槽清空。再次启动和重复执行均能重新创建同 label 的 child WebView。

### portable-pty 结果

- `CommandBuilder::new_default_prog()` 成功启动本机默认登录 Shell；两个 PTY 获得不同 PID 并可并行运行。
- 原始输出保留 NUL 字节、ANSI 转义序列和中文 UTF-8；`stty size` 从 `24×80` 正确更新为 `41×119`。
- 向 master 写入 `0x03` 能中断前台 `sleep` 并返回 130；vim 实际进入并退出 alternate screen，macOS
  `top -l 1` 正常运行。
- 容量为 1 的 `sync_channel` 在消费者暂停时施加背压；恢复消费后 2,500 条记录保持首尾与顺序，
  本轮读取 35,688 bytes、用时 34ms，没有无界缓存。
- `MasterPty::process_group_leader()` 的 Unix 实现实际调用 `tcgetpgrp`，运行前台作业时返回作业 PGID，
  与 Shell PID 不同；向负 PGID 发送 SIGHUP 后作业返回 129，随后 Shell 可继续使用并自然退出。
- 组合原型在窗口隐藏前启动 PTY 命令，命令在 500ms 隐藏期间完成，恢复后读取到
  `continued-after-window-hide`；说明终端生命周期可以由 Desktop manager 持有，不依赖 WebView 可见性。
- 原型结束后按进程名、测试命令和 vim 临时目标检查，无可归因的 Shell、前台作业或原型进程残留。

### 偏差与实现约束

- 首版安全原型曾临时启用 `withGlobalTauri`，外部页因此看到了 `window.__TAURI__`，命令仍被 capability
  拒绝。最终原型已删除该配置并按产品现状重测通过；M4 不得启用 `withGlobalTauri` 或远程域 IPC 权限。
- 前台进程组查询不需要产品额外使用 `tcgetpgrp` 或 nix `term` feature，直接使用 portable-pty 提供的
  `process_group_leader()`；nix 只需已设计的 `signal`、`process` feature 发送负 PGID 信号。
- 浏览器导航命令返回后的同步 `url()` 可能短暂仍是旧地址，正式状态必须以导航/加载回调为准。
- M0 没有修改产品代码，也没有执行数据库、真实 Runtime Home、真实 Provider 或真实账号网站操作。

## M2 Session 文件根与工作空间树（✅ 已完成，2026-09-04 用户确认）

- `assistant-protocol` 新增 Session 资源根、根内定位、一层目录项和有界文本/图片预览 DTO，
  TypeScript 投影已重新生成。根使用 `workspace_primary`、`workspace_additional` 和

- Runtime Host 在既有 bearer 鉴权资源路由族中增加 `list`、`preview` 和 `native-path`；
  每次请求均重新规范化相对路径、canonicalize 根与目标并校验包含关系，拒绝绝对路径、
  空字节、`..` 上跳和越界符号链接。

  `native-path`，WebView 得到的打开与 Finder 定位命令只返回成功或受控错误，不返回物理路径或
  Runtime token。
- 工作空间菜单已对已物化 Session 开放，资源标签并列冻结主目录、附加目录和会话私有目录；
