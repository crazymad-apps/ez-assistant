# v0.24.0 界面交互设计指导：资源工作区、用户浏览器与终端

## 一、设计信息

- 版本：`v0.24.0`
- 状态：已完成并归档（2026-09-05）；设计于 2026-09-04 确认
- 日期：2026-09-04
- 关联功能设计：[`v0.24.0 功能设计`](功能设计.md)
- 关联技术方案：[`v0.24.0 技术方案`](技术方案.md)
- 影响界面：AppShell 三栏布局、右侧资源工作区、Conversation Markdown、附件/工具资源菜单、
  Session 删除与 Desktop 退出确认

本文给出真实 Desktop 窗口中的布局、交互、状态和视觉口径，不建立独立页面或新的设计语言。

## 二、页面入口与整体结构

资源工作区替换现有右侧“当前上下文”栏，仍由标题栏的右栏开关显示或收起：

```text
┌──────────────┬─────────────────────────────┬──────────────────────────┐
│ 会话栏       │ Conversation                │ 资源标签栏        [+]   │
│ min 220      │ min 500                     ├──────────────────────────┤
│              │                             │ 活动资源正文             │
│              │                             │ min 320                  │
└──────────────┴─────────────────────────────┴──────────────────────────┘
```

- 左栏不因右栏扩展而变窄；中栏达到 `500px` 后阻止右栏继续扩展。
- 右栏默认 `380px`、最小 `320px`，没有固定最大宽度。
- 窄窗口无法容纳三栏时沿用现有侧栏优先级折叠，不出现主页面横向滚动。
- 右栏收起只隐藏资源，不关闭浏览器或终端；重新展开恢复原活动标签。

## 三、标签栏

### 3.1 结构

- 资源栏 Header 与中栏会话标题栏统一为 `56px` 高；Header 使用水平内边距和垂直居中，底部分隔线
  与中栏标题栏对齐。
- “当前上下文”固定为第一个标签，不显示关闭按钮。
- `+` 位于标签滚动区右侧并保持可见；标签不参与 Flex 压缩，标签过多时横向滚动，标签区内的纵向
  滚轮增量映射为横向滚动，`+` 不随内容滚走。
- 标签使用约 `32px` 高的圆角 Tag 形态；活动标签使用主文字色、强调边框和表面背景，非活动标签
  使用次要文字色和弱背景，不再以铺满 Header 高度的页签或底部横线表现。
- `+` 使用独立的 `32×32px` 圆角 text 图标按钮，不拉伸到 Header 全高；默认背景和边框透明，
  hover 或菜单展开时才显示弱背景。
- 文字按钮和图标按钮统一复用 Desktop `Button` 原语；外观使用 `text`、`outlined`、`primary`、
  `danger` 变体，尺寸使用 `small`、`default`、`large`。纯图标按钮通过 `iconOnly` 保持正方形命中区，
  DropdownMenu Trigger 在声明这些视觉属性时复用同一套状态样式。
- 卡片标题和路径尾部的小型行内操作使用 `InlineIconButton`：无 padding、边框和背景，容器由图标本身
  决定尺寸，默认图标为 `16px`，hover 仅提升图标颜色。需要固定命中区的工具栏图标仍使用
  `Button iconOnly`。
- 浏览器使用地球图标，终端使用终端图标，工作空间使用文件夹图标，文本/Markdown 使用文件类型图标。
- 通用图标保持组件声明的固定宽高，在 Flex 容器空间不足时不参与压缩；空间让给可省略的文字内容。
- 标签标题单行省略，不为标题重复显示无实际信息的 Tooltip。

### 3.2 键盘与关闭

- 标签栏使用 `role="tablist"`、标签使用 `role="tab"`，采用 roving tabindex。
- 左右方向键切换焦点，Home/End 到首尾，Enter/Space 激活，Delete 或标签关闭按钮关闭可关闭标签。
- 关闭活动标签后激活其左侧最近标签；没有其他资源时回到“当前上下文”。
- 右栏全部标签按会话分组，切换会话后只显示目标会话的标签，切回恢复原顺序与活动项。
- 命中页面缓存时直接恢复原正文；超限淘汰后按索引重建并恢复目录展开、滚动与文件查看位置。浏览器
  已淘汰时重新打开最后 URL，不显示常驻缓存说明；终端始终恢复原实例，不因缓存淘汰重新启动。
- 关闭运行中终端时弹出确认；关闭普通文件、Markdown 和浏览器不额外确认。
- 中键关闭仅作为可选便利，不作为验收入口。

### 3.3 `+` 菜单

点击 `+` 打开与现有 DropdownMenu 一致的菜单：

- 菜单项使用单行图标与标题，图标槽位固定并与文字垂直居中，不显示功能状态副标题。

1. 工作空间
2. 浏览器
3. 终端

- “工作空间”已有标签时聚焦，不重复创建。
- “浏览器”每次新建，先显示空白地址页并聚焦地址栏。
- “终端”每次新建并聚焦输入；不可解析启动目录时禁用并在菜单项下说明原因。
- 菜单关闭后焦点返回 `+`；选择成功后焦点进入新资源的首要操作点。

## 四、当前上下文与工作空间

### 4.1 当前上下文

现有 `ContextPanel` 的卡片、折叠状态和信息顺序保持。工作区卡片增加“会话私有目录”一行：

- 可用时显示文件夹图标、“会话私有目录”和“打开”动作。
- 点击后打开/聚焦工作空间标签，并定位到私有根。
- 草稿尚未物化时显示“创建会话后可用”，不显示伪路径。

### 4.2 工作空间树

- 根节点依次为主目录、附加目录、会话私有目录；每个根显示类型副标题和末级目录名。
- 未绑定 Workspace 的 Session 只显示会话私有目录。
- 目录使用 disclosure 展开，首次展开加载；刷新按钮只刷新当前目录。
- 默认弱化隐藏目录和大型生成目录，并提供“显示隐藏项/生成目录”开关。
- 文件名、类型图标和必要的大小信息保持单行；双击与 Enter 打开可查看资源。
- 文件类型、根目录和普通目录图标使用 `material-icon-theme` 的浅色图标、开合状态与原始配色；未知
  文件类型使用该主题的通用文件图标。
- 文本、代码、Markdown 和通过媒体校验的图片可在资源栏打开；其他文件只提供系统打开和 Finder 定位。
- 越界符号链接显示禁用图标和“目标位于当前根之外”，不可展开或打开。
- 超过单次目录项上限时在列表末尾显示“目录内容过多，请使用 Finder 查看”，不伪装完整列表。

## 五、文件、Markdown 与图片查看

所有资源查看标签在标签栏下方显示一行路径面包屑与右侧“更多”菜单，随后直接显示正文：

```text
主目录 ›  src ›  components ›  AppShell.tsx                                      ⋯
```

- 路径从获准访问的根开始，目录名和文件名逐级显示，不展示根以前的物理路径。空间不足时面包屑自身
  横向滚动，完整路径通过“更多 > 复制完整路径”获取。
- 除最后一级外，目录文本和箭头合并为一个下拉节点；箭头默认向右，菜单展开时转为向下。最后一级
  仍以当前文件名作为同级菜单触发器，但不渲染箭头。下拉显示该节点对应的同级目录和文件，目录优先、文件随后，当前项
  带选中标记；菜单限制高度并支持滚动和方向键。
- 选择目录时打开或聚焦工作空间标签并定位该目录；选择文本、Markdown 或图片时打开或聚焦对应资源
  标签。定位目录时自动展开从资源根到目标目录的各级节点。其他二进制文件仍显示在同级菜单中，但
  标记为“使用系统应用打开”，不伪装成内置预览。
- Workspace 外的显式 `file://` 从获准父目录开始显示；不展示更高物理路径，也不把单个文件授权扩成
  整卷浏览。

### 5.1 普通文本和代码

- 正文完全交给 Monaco 只读视图，占满标签剩余空间。
- 查看器不显示语言选择、“转到行”或独立工具条；查找、自动换行、刷新、系统打开、Finder 定位和
  复制完整路径收进面包屑右侧“更多”菜单。
- 行号链接打开时滚动到目标行并短暂高亮；行号失效时打开文件顶部并显示非阻断提示。
- 加载、过大、非文本、已删除和权限变化都在正文区域显示明确状态，不弹全局错误。

### 5.2 Markdown

- 默认且仅显示渲染页面，不提供源码、编辑或“预览/源码”切换。
- 字体、段落间距、代码块、表格、数学公式和 Mermaid 与消息列表的 Markdown 表现一致。
- 文档正文使用适合长文阅读的内边距；宽表格和代码块在自身区域横向滚动，不扩张右栏。
- `http`/`https` 外链图片正常加载，保持宽高比并限制在正文宽度内；失败时显示带替代文字的占位。
- 网络链接点击后通过系统浏览器打开。本地相对链接点击后进入资源栏，本地图片通过 Desktop 桥显示。
- 原始 HTML 被跳过，不在页面中显示脚本或可执行控件。

### 5.3 图片

- 图片在右栏正文内居中适配，支持滚轮缩放、触控板捏合、拖拽平移、双击放大/复位；聚焦后可用方向键和加减键操作。
- “更多”菜单统一提供放大、缩小、适应窗口、原始尺寸（100%）、重新加载、系统打开、Finder 定位和复制路径；不增加常驻工具栏。
- 切换标签、会话、缓存淘汰或重启客户端后恢复缩放比例与位置。正文沿用右栏背景，变换限于图片视口，不影响面包屑和其他资源。
- 不提供编辑、标注、旋转或图片集合轮播。

### 5.4 PDF

- PDF 使用资源查看标签内的 WebView 原生阅读器，占满面包屑以下区域；页面排版、滚动和 WebView
  自身提供的阅读交互由系统 PDF 能力负责，不重复实现一套工具栏。
- PDF 必须先经过文件签名和大小上限校验，再以临时 Blob URL 加载；关闭或切换资源时释放该 URL，
  WebView 不直接接触文件物理路径。

## 六、消息、附件与资源菜单

- Assistant 消息中的显式 `file://` 文本/代码/Markdown 链接使用文件图标与普通链接样式。
- Agent 在交付已经确认存在的本地文件时优先生成上述链接；直接交付图片时优先生成内嵌图片。界面不
  显示“System Prompt 已要求”之类实现文案，也不把未使用 file URI 的普通路径自动补成链接。
- 本地图片按消息宽度显示预览，点击打开或聚焦图片资源标签。
- 文本、代码、Markdown、图片和 PDF 的菜单：在资源栏打开、使用系统应用打开、在 Finder 中显示。
- 其他二进制文件：使用系统应用打开、在 Finder 中显示。
- 资源元素右键或 `Shift+F10` 打开同一菜单；普通消息文本和选区继续使用原生右键行为。
- 菜单动作失败时保留资源元素并在邻近位置显示可重试状态。

## 七、用户浏览器

### 7.1 空白与地址栏

- 新建标签先显示简洁空白页，地址栏自动聚焦。
- 用户输入不含 scheme 的常规主机名时补 `https://`；无法解析时在地址栏下方提示，保留输入供修正，
  不发起导航或隐藏当前网页。系统浏览器打开失败也只在工具条下提示，当前网页仍可操作。
- 浏览器工具条从左到右：后退、前进、刷新/停止、地址栏、在系统浏览器打开。
- 工具条固定在资源正文顶部，网页 child WebView 只占其下方矩形区域。

### 7.2 导航状态

- 加载中刷新按钮切换为停止，地址栏仍可编辑；提交新地址覆盖当前导航。
  迟到的旧地址查询不能覆盖新目标，已回收页面的查询失败不能使恢复后的页面进入错误态。
- 标签标题优先显示页面标题，缺少标题时显示主机名；完整 URL 放在 Tooltip。
- 创建或原生操作失败时显示错误与重试。超过 30 秒未完成加载只在工具条下显示可关闭的慢加载提示，
  结束进度动画但保留网页及交互；支持重试/系统打开，迟到完成事件清除提示。不能仅凭等待时间把
  已显示网页替换成错误页，也不猜测网络或证书原因。iframe 跳转不重启整页加载状态。
  被拒绝的协议在工具条下提示，保留当前网页。
- `target=_blank` 的 `http`/`https` 请求创建新的资源浏览器标签；下载请求提示使用系统浏览器。
- 资源 `+` 使用系统原生菜单，打开时保留网页显示；外观随系统，尚未实现自定义透明 WebView 菜单。
- HTML Dialog/Popover 仍先隐藏网页，再显示浮层；关闭并更新边界后恢复网页，不能覆盖应用控件。

### 7.3 权限表达

- 浏览器界面不出现“Agent 可操作”“已接管”或 MCP 状态。
- 空白页使用短提示：“输入网址，开始浏览”。
- 不显示内部 WebView label、capability 或 IPC 术语。

## 八、用户终端

### 8.1 标签与正文

- 新建终端后直接显示 xterm.js 并聚焦，标签标题只显示“终端”，不把固定启动目录名当作当前目录展示。
- 终端正文直接接在资源标签栏下方，不设置目录名、来源会话或清屏按钮的常驻工具栏。启动目录仍在创建时冻结，切换会话不影响已运行 Shell。
- 终端使用与应用一致的浅色背景、等宽字体和适合浅色底的 ANSI 配色，正文无多余卡片边框。
  背景、文字、光标、选区与 ANSI 颜色统一消费主题变量；未来应用或系统主题切换时更新现有终端配色，保留 PTY、输出缓冲和选区。
- 正常运行时不增加状态工具条；Shell 退出后自动关闭标签，并沿用标签关闭时的相邻页回退。
  不按退出码区分；启动、通信或清理失败保留标签与错误供重试。
- 切换到其他会话/标签、普通页面缓存淘汰、收起右栏或隐藏窗口不会暂停或回收终端；后台输出继续进入该标签的有限滚动缓冲，重新
  激活后显示完整的保留内容并重新适配尺寸。

### 8.2 输入、复制和尺寸

- 鼠标点击正文聚焦输入；中文输入法候选窗不能被右栏或 child WebView 遮挡。
- `Ctrl+C`、`Ctrl+D` 交给终端；只有原生确认 Shell 退出才关闭标签，前台程序或嵌套 Shell 收到 EOF 不直接关页。
  `Cmd+C` 在有选区时复制，无选区时不发送信号；`Cmd+V` 粘贴。
- 右栏拖拽、窗口缩放和标签恢复时重新 fit；终端字符不能因宽度变化被 CSS 拉伸。
- 大量输出时保持滚动；用户主动向上查看后不强制跳到底部，新输入或主动“回到底部”再恢复跟随。

### 8.3 关闭、Session 删除与退出

- 关闭运行中标签使用警告 Dialog：“关闭终端将终止其中正在运行的 Shell 和前台任务。”
- Shell 退出自动关闭标签，不确认；无论退出码是否为零，都回收原生句柄后移除标签。
- 删除所属 Session 且存在运行终端时，在现有删除 Dialog 增加全部关联终端数量和影响说明；
  确认删除会先关闭这些终端。
- 关闭窗口并隐藏到托盘不提示、不终止终端。
- 真正退出 Desktop 的确认 Dialog 增加“运行中的用户终端：N”；确认退出后等待清理，按钮进入忙碌态。

## 九、宽度、滚动与原生层协调

- 右侧分隔线命名从“当前上下文栏”更新为“资源栏”，键盘步长保持 8px，Shift 为 24px。
- 中栏会话区使用 `12..24px` 的常规响应式横向 padding；消息列表和 Composer 统一通过 `820px`
  `max-width` 居中约束阅读与操作宽度，中栏继续变宽时不再增加页面 padding。
- 双击分隔线恢复 `380px`；Home 到 `320px`，End 到当前动态上限。
- 标签栏、浏览器工具条和文件工具条不随正文滚动；各正文拥有独立滚动容器。
- 浏览器 WebView 不参与 DOM 滚动。任何改变正文矩形的操作都在下一 animation frame 同步原生边界。
- 右栏折叠、标签切走、窗口隐藏、Dialog/Popover 覆盖前先隐藏 child WebView，避免原生层级穿透。

## 十、状态与异常文案

| 场景 | 表现 |
| --- | --- |
| 资源首次读取 | 正文局部骨架或进度，不阻塞 Conversation |
| Runtime 断开 | Workspace/私有资源显示“Runtime 不可用，重试”；浏览器与已运行终端继续 |
| 文件被删除 | 保留标签，显示“文件已不存在”，提供关闭和 Finder 定位禁用态 |
| 文件过大/不支持的二进制 | 不创建 Monaco/Markdown/图片查看器，显示文件信息和系统打开动作 |
| 外链图片失败 | 保留替代文字和重试后的浏览器默认加载行为，不显示空白破图 |
| 浏览器创建失败 | 保留浏览器标签，显示重试和系统浏览器打开 |
| 浏览器页面加载失败 | 地址栏保留目标 URL，正文显示错误与重试 |
| Shell 启动失败 | 终端标签显示错误和重试，不出现假提示符 |
| Shell 已退出 | 回收原生句柄并自动关闭标签，不按退出码区分；后台退出不抢占当前页 |
| 终端关闭失败 | 保留标签和错误，Desktop 退出/Session 删除停止后续破坏性动作 |

错误文案只说明用户可理解的对象和恢复动作，不暴露 token、物理 Session 上级路径、内部 WebView label
或 Rust 错误链。

## 十一、验收口径

1. 资源栏在窄窗口、标准窗口和大窗口中遵守三栏最小宽度，右栏没有固定最大宽度。
2. 标签、`+` 菜单、关闭和右键菜单均可用鼠标与键盘完成，焦点返回正确。
3. ContextPanel 原有内容无回退，会话私有目录快捷入口状态准确。
4. 文本/代码 Monaco 只读；Markdown 与消息列表渲染一致且外链图片可正常加载；图片使用有界只读预览。
5. 文本、Markdown 和图片标签均显示路径面包屑；每个可枚举层级可查看同级目录和文件并正确跳转。
6. 图片之外的普通二进制文件不会误建查看标签，本地图片不会直接暴露 `file://` 给 WebView。
7. 浏览器工具条和网页区域边界稳定，任何 Dialog 或标签切换都不会被原生 WebView 遮挡。
8. 浏览器明确由用户操作，不出现 Agent 接管暗示，外部网页无法使用 Assistant IPC。
9. 终端输入法、复制粘贴、Ctrl+C、尺寸同步、滚动跟随和退出状态符合常见终端预期。
10. Session/资源标签切换、右栏收起与隐藏到托盘不终止或阻塞终端；标签关闭、Session 删除和 Desktop
   退出按设计确认并清理。
11. 所有加载、不可用、失败和恢复状态在资源正文内可理解，不阻断 Conversation 主流程。
12. A/B 会话的文件、浏览器与终端互不混入；A→B→A 恢复原活动标签。超过页面缓存上限后文件可重建、
    浏览器按最后 URL 重载，终端进程和输出保持连续。
