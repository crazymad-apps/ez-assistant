## 主要更新

- 右栏升级为按会话归属的资源标签区，统一管理工作空间、文件、浏览器与终端；切换会话后可恢复原有标签和查看状态。
- 工作空间目录树支持展开/收起、隐藏项过滤、Material 文件图标和可下拉的路径面包屑。
- 新增 Monaco 代码高亮、普通文本识别、Markdown 与 PDF 预览，图片支持缩放和拖拽；消息中的文件链接可直接进入资源栏。
- 内嵌浏览器使用系统 WebView，支持导航、网站登录状态保持；修复加载误判、超时隐藏页面及旧 URL 查询覆盖新导航的问题。
- 新增浅色 PTY 终端，支持中文输入和后台运行；Shell 退出自动关闭标签。
- 支持客户端重开恢复右栏快照，普通页面使用 20 实例缓存，运行中的终端不参与淘汰；标签支持横向滚动和鼠标中键关闭。
- 改善语音服务的配置隔离、并发预算、取消恢复和设备播放接纳；修复压缩后工具交换恢复问题。

## 使用边界

- 客户端重启或网页缓存淘汰后重新加载最后 URL，不恢复网页表单/脚本状态；终端重建 Shell，不恢复旧进程或重放命令。PDF 页码和缩放暂不恢复。
- 浏览器与终端供用户直接操作，本版不支持 Agent 接管，也不包含文件编辑或下载管理。
- Windows/Linux 和干净 Mac 首次安装尚未验收。本机 Gatekeeper 原本关闭，未修改该设置；独立分发检查已通过。
