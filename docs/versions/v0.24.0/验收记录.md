## 验收反馈修复闭环

| 问题 | 修复与实际验证 |
| --- | --- |
| iframe 跳转重启整页加载，超时后已显示网页被隐藏 | 导航许可只校验协议；主页面 Started/Finished 驱动状态。30 秒改为非阻断提示。WKWebView 验证延迟 iframe、慢资源期间点击及匿名斗鱼页面超过 60 秒保持可见 |
| 输错地址或系统打开失败隐藏当前网页 | 复用提示条；无效输入保留供修正。原生窗口输入 `https://[` 后仍可点击；验证宿主未注册系统打开命令制造可控失败后页面仍可点击 |
| 已回收实例的旧 URL 查询失败污染恢复页 | 成功与失败统一核验页面实例及查询有效性；受控 Promise 回归证明旧失败被忽略，而当前实例失败仍正常报告 |
| 旧 URL 查询回包覆盖新导航目标 | 导航使旧查询失效，原生页面事件到来前暂停同步；受控 Promise 验证旧回包丢弃、导航后同步恢复，原生窗口验证有效重定向正常 |

两项异步竞争由受控返回时序复现并回归，未声称在真实窗口制造了相同竞争时序。已报告的四类浏览器问题
均已修复；没有用单元测试替代网页可见性和点击的原生验证。

## 设计调整与保留边界

- 用户在开发中追加并确认：会话归属、20 实例页面缓存、终端免淘汰、跨客户端重启快照、图片缩放拖拽和 PDF 预览，均已同步最终设计。
- 页面缓存限制是实例数量，不是进程总内存字节限制；终端各自使用有界 scrollback。
- 浏览器被淘汰或客户端重启后重新加载最后 URL，不恢复表单/网页脚本状态；原生 PDF 不保存页码与缩放。
- 真正退出客户端后终端重建 Shell，不恢复旧进程或重放历史命令；主动脱离 PTY 的守护进程不在回收保证范围内。
- Tauri 公开接口不提供具体 DNS/证书失败回调；超时提示不猜测网络原因，不隐藏已渲染网页。
- 菜单维持当前系统原生方案；Agent 接管内嵌浏览器/用户终端、自定义透明 WebView 菜单、下载管理和文件编辑不在本版范围。

后续新增事项由下一活动版本承接；本记录归档后保留为历史事实。
