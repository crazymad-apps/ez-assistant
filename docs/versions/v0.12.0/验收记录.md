## 四、安全与数据边界

- 自动测试使用临时 Runtime Home、SQLite、Workspace、权限文件和 loopback Provider。
- 真实 LLM 测试只读模型配置，业务数据和输出位于隔离临时目录。
- 验证未修改用户默认业务数据库；诊断用户 Session 时只执行只读查询。
- 检查未发现 credential、Bearer Token、完整 Prompt、文件正文或模型完整回复进入普通日志。

## 五、已知边界与遗留

- Web Demo 是默认关闭的私有验收客户端，不构成正式桌面 UI 契约。
- Plan Shell 仍使用当前 OS 用户权限，不是强沙箱。
- pending approval 不持久化；Runtime 重启后不恢复审批，也不自动续跑中断 Run。
- Global 权限只能手工编辑并显式重载，审批不提供 Global 写入口。
- 真实模型服务和网络仍可能发生建流前失败或建流后空闲超时；建流后失败不透明重试。

以上均符合已确认功能设计，不构成本版本阻断项。

## 六、偏差与未执行项

  在隔离环境显式执行并通过，其余真实 API smoke 保持 `ignored`。
