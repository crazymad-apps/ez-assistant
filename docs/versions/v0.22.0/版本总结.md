# v0.22.0 版本总结

## 版本结论

`v0.22.0` 已完成会话创建、Workspace、标题、引用、Composer 附件与页面交互优化。用户于
2026-09-02 确认验收，并授权归档、提交、标签、推送与正式发布。

## 实际完成

- 新会话改为首次发送后物化；Desktop 按 Workspace 保留进程内草稿，发送前不进入会话列表。
- Workspace 支持固定名称、主目录和有序附加目录的统一编辑；既有 Session 持续使用创建时冻结
  环境，Runtime 直接提供冻结工作目录的缺省读/list 权限。
- 自动标题与 `/title` 复用同一旁路机制和最新 Conversation Snapshot，使用结构化 tool call 收集标题。
- Composer 支持附件/引用详情和粘贴图片附件。跨渲染元素的文本选区作为结构化引用提交，仅冻结
  exact、有界前后文和直接来源定位信息；来源高亮可回收且发送时强制清理。
- Desktop 弹窗、菜单、Popover 和 Collapse 统一可中断过渡。左右栏可即时拖拽并保存设备偏好，
  窄窗口按右栏、左栏的顺序隐藏，宽右栏使用两条独立纵向列。

## 验证结论

- Rust workspace `fmt --check`、全 targets/features Clippy `-D warnings` 和全量测试通过。
- Desktop lint、26 个文件 179 项测试、协议生成物检查、生产构建、隔离正式 Host Playwright 与
  Tauri release `build --no-bundle` 通过。
- 设备模拟器 lint、37 项测试和 typecheck 通过；Desktop 与模拟器 npm audit 均为 0 vulnerabilities。
- 旧 schema、首次物化幂等、历史权限清理、附件补偿、冻结 Workspace、标题旁路、结构化引用和分栏偏好
  均由隔离自动化或正式 Host 场景覆盖。

完整命令、环境、隔离边界与发布证据见[验收记录](验收记录.md)。

## 偏差与遗留

- 未发现相对已确认设计的重大架构偏差；引用、标题 tool call、Workspace 编辑入口与分栏响应式细节已在
  开发期间同步回写设计。
- Vite 仍有部分大 chunk 非阻断提示。
- 真实 Provider 未在归档验收中重复请求；标题、引用投影与旁路用量由 fake/deterministic ModelService
  和契约测试验证。
- macOS arm64 Developer ID 正式发布已通过 App/DMG 公证、staple、Gatekeeper 和独立挂载验证；
  DMG SHA-256 为 `aea7b94b7ed58a89d88110b137d98b5a42b30f4ce5683f25da17d53c37d75b32`。
- 干净 macOS arm64 设备的首次安装和启动仍需基于最终 DMG 另行验证。
