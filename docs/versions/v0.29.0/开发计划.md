## 三、F07 纳入评估与实施入口

- **必要性**：现有 replace_all 不能表达多组不同修改；扩展现有文件 edit 能减少重复工具调用，收益直接。
- **本版交付**：多个文件、每个文件多组精确替换；复用权限、路径锁和可靠工具记录，返回成功/失败/未知/未执行范围。
- **范围控制**：暂不增加补丁语言、模糊匹配、通用 batch 执行器或跨文件回滚；不改变 F06 当前里程碑。
- **进入条件**：按队列进入 F07 时，完成简洁功能设计、技术思路和独立开发计划，核清 Schema/历史调用兼容、顺序与重叠语义、写入保障及限额；不提前创建空白 Feature 文档。
- **独立验收**：覆盖单/多文件、多组替换、replace_all、混合权限、匹配失败、外部修改、取消、部分写入和重启未知状态；Windows/macOS 的 BOM、换行及符号链接行为保持明确。批量结果通过既有 UI 展示，并能进入 F06 续接上下文。
- **工作量与风险**：中等规模，重点在授权完整性及部分成功处理；独立计划按取消结果可靠保存、批量编辑完整链路、联合验收推进，不将能力扩展混入 F06。
