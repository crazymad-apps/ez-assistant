## 验证与制品

沿用各里程碑已执行的定向回归、静态检查、构建、隔离 Host/Center 和实际页面验证，结合用户的功能及联合实测确认验收；封版本身仅移动和同步文档，未重新运行产品测试。

Windows x64 通过 RustDesk 完成模拟 0.29.1 至 0.29.2 的应用内更新、自动重启和生产登录，实际 Desktop/Host 与发布 MSI 内容一致；数据库完整性、数据保留、原主控会话界面与实际 API 读取核验通过。模拟 0.29.1 遗漏迁移声明的问题已在隔离模拟 0.29.2 补齐；正式源码仍为 0.29.0，模拟制品不代表正式版本发布。

macOS arm64 内部 0.29.0 候选的 Developer ID 签名、架构与镜像检查已有通过结果；Apple 公证受账号协议缺失或过期阻断。已有隔离候选验证不替代本次明确暂缓的 macOS 升级实测。Windows MSI/EXE 未做发布者代码签名，应用更新签名与发布者代码签名分别记录。

## 暂缓与已知限制

- **macOS 升级暂缓**：2026-10-10 用户指定，不再阻塞本版封版。后续需核实签名/公证条件，并补齐实际安装替换、自动重启、同一 Runtime Home 数据接续及失败恢复；排期与版本归属另行确定。
- 原有自动化遗留继续保留：流中断旧断言与当前重试行为不一致、合并工作区测试中的 rustls 加密后端冲突等记录，本次未修正或复跑，不宣称全量测试通过。
- 未逐项执行的平台矩阵、原忽略用例，以及无支持路由可测的 OpenAI/百炼 HTTP 原生持久化 store 专项，按所属 Feature 原证据保留；用户实测确认不补造代理逐项验证记录。
- 批量编辑不提供跨文件回滚、外部竞态隔离或 fsync 崩溃安全；未知副作用不自动重放。历史数据回退仍按既有兼容与完整 Runtime Home 备份边界处理。
- 公开发布前仍须核实上述签名公证、候选制品及检查状态；封版与公开发布分开。
