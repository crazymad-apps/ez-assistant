## 三、文件预览与侧栏交互

### 3.1 普通文件

- Host 文件和原生本地文件的标题仅显示文件名及扩展名，沿用 `display_name`；不从客户端平台猜测路径分隔符。
- 文件名过长时单行省略，并通过标题提示查看完整文件名；更多按钮保留固定可用宽度。
- 本地文件已有同级文件切换保留在文件名菜单中，仅移除前面的目录节点。
- 完整路径复制、下载、系统应用打开和目录定位继续使用原资源身份及已有菜单。远端 Host/Web 不开放本机目录定位。
- Session 文件的工作空间面包屑、附件及工具产物的分组/同级菜单保持原语义。
- 标题简化不修改资源 key、locator、路径、查看位置或保存的资源索引，无数据迁移。

### 3.2 窗口与快捷入口

- Windows Desktop 左上角使用现有源 Logo，24px 图形、非按钮、无额外点击动作；侧栏收起时随现有导航进入中栏左上角。
- 客户端平台决定窗口装饰，远端 Host 不参与判断；macOS 保留红绿灯，Web/Linux 不显示新增 Logo。
- Logo 不参与焦点顺序、不阻挡拖动；导航按钮命中区及 Windows 右侧窗口按钮保持不变。
- “新建会话”“助理会话”“智能体管理”“插件管理”移除自定义 Tooltip 和原生 title；可见文字、无障碍名称、选中/禁用与点击行为保留。
- 搜索、侧栏开关等纯图标按钮保持原交互；项目添加等已有 Tooltip 不受影响。
- 2026-10-09 用户补充：归档当前会话成功后进入独立的新建视图，左侧恢复活动会话列表。归档失败保留原页面；等待期间用户已切换页面时不抢占导航。

## 四、交互终端

### 4.1 选择与切换

- 新标签默认选择“系统默认 Shell”；可靠解析到实际类型时补充名称。默认与显式 `/bin/sh` 是两个选择，即便某台 Host 恰好解析到同一个程序。
- 只展示所连接 Host 实际可用的固定 Shell；macOS 探测 zsh/bash/sh，Windows 探测 PowerShell 5.1/7、Git Bash、CMD。不显示未安装项，不提供任意程序路径输入。
- 默认 Shell 来源不可用时明确失败，不能伪装为其他类型或暗中使用 `/bin/sh`。非支持类型的系统默认仍可保留真实名称与默认入口，提示符不盲目适配。
- 切换先提示会结束当前终端及其运行命令，确认后复用现有关闭/回收，再按原启动目录创建新终端。失败不假称已选中目标；用户可重试或重新选择。
- 可以从显式 Shell 切回默认；重启保留本标签选择，新标签仍用默认。不增加跨重启 Shell 偏好。
- 目录加载失败显示可重试错误，不借用客户端或 Agent 的目录；迟到响应不能进入其他 Host/身份。

### 4.2 简短提示符

- 路径优先显示当前目录名，主目录显示 `~`，根目录保留 `/` 或盘符；超长目录名按 Shell 能力有界省略。完整目录始终通过 `pwd`、`Get-Location` 或 `cd` 查询。
- PowerShell 保留 `PS` 和 `>`；bash/zsh 保留输入标记及已有可保留的 Git 分支等信息。CMD 无可靠目录名钩子时使用盘符短提示符，不引入常驻辅助进程。
- 不改用户全局启动文件、不重写终端输出、不修改 cwd 或命令参数。用户主题动态覆盖提示符时明确记录支持边界，不通过反复输出控制序列抢占主题。
- 启动适配的具体边界见[技术方案](技术方案.md)；在 M2 核查真实启动顺序后实施，若无法满足已定边界，先收敛方案再扩大实现。

## 五、验收与平台限制

1. Windows/macOS 风格长路径显示同一规则；完整文件名可查看，复制仍为完整路径；工作空间面包屑可用，远端本地动作受限。
2. 四个文字入口悬停及键盘聚焦无重复提示；纯图标按钮提示仍在；禁用和原动作保持。
3. Windows Logo 在侧栏展开/收起、窄窗口及 100%/125%/150% 缩放不遮挡导航或窗口按钮；macOS 毛玻璃与红绿灯回归。
4. 默认 → 显式 sh/其他可用 Shell → 默认，选择、启动命令和实际回显一致；安装变化、连接切换、启动失败及取消不产生遗留 PTY。
5. 提示符覆盖深目录、中文/空格、根目录、Git 内外、Windows UNC 与窄终端；命令编辑、历史、换行、中断、退出及后台输出不退化。
6. 浏览器平台模拟只证明 DOM/CSS；Windows/macOS 原生拖动、Shell 与 WebView 验收必须区分。缺少平台环境时保留待验项，不以构建替代实测。

实现与验收顺序见[开发计划](开发计划.md)。


## 六、M2 用户补充：Agent Shell 同源选择

默认 Agent Shell、会话上下文和用户交互终端共用 Host 探测的可用显式类型，macOS/Linux 可选 sh/bash/zsh，Windows 保持已安装的 PowerShell 5.1/7、Git Bash/CMD。Unix 不再整组禁用。交互终端的“系统默认 Shell”仍表示登录 Shell 入口；Agent 未设置时保持既有 /bin/sh，不静默改变历史会话的解释器。Agent 默认变更只用于后续新会话，当前会话通过既有命令队列切换或刷新，成功后才显示新绑定。
