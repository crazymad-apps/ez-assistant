## 行为与边界

- 管理员从用户列表发起删除并确认账号及影响；物理删除 users 行，保留停用为独立操作。
- 禁止删除带超级管理员标记的用户及最后启用管理员；其他管理员可删除本人，成功后退出管理身份。
- 删除、成功审计共事务；提交成功后撤销目标全部 Token/key，复用现有主体失效通知关闭企业 WebSocket 链。失败回滚不撤销凭据，提交结果不明遵循既有全局失效规则。
- 保留调用、反馈、处理及审计历史的原身份 ID；序列不回退，同名重建使用新 ID，不继承原反馈权限或 Host 用户数据域。
- 009-user-deletion 仅解除审计 actor/target 外键；不删除、清空或重绑定历史 ID。历史用户名不存在时沿用现有 ID 展示，反馈/调用名称快照保留。
- 不删除 Host 文件、会话或快照，不自动重试删除；重复删除返回不存在。无新状态表、删除标记或兼容分支。

## 验收

覆盖旧结构升级保留审计、权限和管理员保护、审计故障回滚、Token/key 失效、并发重复删除、本人删除、历史保留和同名新身份隔离。生产迁移与删除必须单独遵循数据库确认、备份和核验规则，本次授权仅实现及隔离自测。
