## 六、安全、隐私与生命周期核对

- Conversation 只保存 Session 相对图片引用和 MIME，不保存图片 Base64/Data URL、
  Provider URL 或 Provider file ID。
- Runtime 每次使用工具图片和产品预览前都重新校验普通文件、哈希、MIME 和
  解码上限；稳定副本缺失或损坏时不回读外部源图。
- opaque payload 与图片 Data URL 不进入产品投影、stdout/stderr、普通日志、Recall、
  Memory 或摘要正文；wire/full trace 仍遵守既有高敏边界。
- 结构化文件工具对 Session `tool-images/` 的修改和删除继续拒绝；该限制不被
  表述为可限制当前用户 Shell 的操作系统强沙箱。
