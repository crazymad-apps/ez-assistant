## 数据库证据边界

此前 M0/M6 的数据库操作发生在本机测试 TempDir 的 `data/runtime.sqlite3`，SQLite 无网络端口。
源/目标是该隔离库，涉及 `providers`、`schema_migrations` 和版本账本；关键表
`providers/sessions/runs/inputs` 迁移前后精确数量为 `1/0/0/0`。新增目录三列值为 `NULL/NULL/0`，
`0.26.0` 迁移记录为 1。独立备份位于同一 TempDir 的 `backups/database/upgrade-*/runtime.sqlite3`，
当时已重新只读打开并核对数量，测试结束后随 TempDir 清理，不能作为当前生产回滚备份使用。
本次验收归档未操作任何数据库，也未执行用户数据清理或修复。
