# v0.26.0 发布说明（待公开发布）

2026-09-17 用户已确认验收并准备归档发布。本文件是发布材料；本轮未执行 Git 暂存、提交、标签、
推送、GitHub Release 或 npm publish。已有 macOS/Windows 安装包为正式应用配置，不是 Dev 配置。

## 主要变更

- 模型目录只在用户显式刷新时联网，选择模型和会话运行使用持久快照，减少初始化和执行阻塞。
- 修复启动失败后会话卡住、长会话 step/工具归属错乱，以及工具执行中参数不可见。
- 审批模式在同一轮后续工具请求实时生效，新会话记住上次审批模式和模型。
- 修复 Windows 还原图标与滚动边界弹动，简化默认 Agent Shell 设置行和模型冻结提示。
- 更新 DeepSeek Flash 模型模板，改善标题生成超时和错误提示。
- 修正上下文用量重复估算与前端显示滞后，区分阈值压缩和模型报告的上下文不足；继续使用原压缩方案。

## 升级说明

- Desktop、Host、Client 和共享协议软件版本均为 `0.26.0`，应用最低兼容版本为 `0.26.0`。
  Desktop 和连接的 Host 应配套升级，旧版应用协议不能混用。
- 安装前结束正在运行的任务，退出 Desktop 时勾选“同时停止本机 Runtime”，再安装新包。
  仅关闭窗口或退出 Desktop 不必然停止旧 Host。
- 数据库增加 Provider 目录快照列并记录 `0.26.0` 迁移；最低 Host 保持 `0.25.3`，但旧 Host
  对较新迁移账本仍会拒绝打开，不能据此直接降级。既有升级备份流程继续适用。
- 旧 Provider 目录初始为空，需要时到模型管理页显式刷新；无自动目录回填或后台刷新。
- 升级保留 Runtime Home 与桌面偏好。Shell detached 仍只在主 Shell 退出且输出管道关闭后交接，
  超时/取消清理行为不变。
