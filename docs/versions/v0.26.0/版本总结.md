## 实际完成

1. 模型目录持久化并仅显式刷新；选择器、会话和 Run 关键路径使用已有目录数据，刷新失败保留旧值。
2. Run 启动前失败与中断恢复原子收敛 Input，修复历史残留导致会话管理永久受阻的问题。
3. 长会话 live step 可靠封口，处理迟到事件和事件缺口；审批、执行中和历史工具参数统一安全投影。
4. 审批模式切换实时影响同一 Run 后续工具；Desktop 新会话按连接目标记住最近审批模式和模型。
5. 收口模型冻结提示、Windows 还原图标、macOS/Windows 滚动边界回弹、默认 Agent Shell 单行布局
   及 Shell detached 文案；保持既有权限优先级和进程清理语义。
6. 更新 DeepSeek Flash 模板并复核 GPT-6 Astra；标题旁路时限增至 120 秒，返回脱敏失败原因。
7. 上下文使用量统一为最近完成 step 的实际量加未计量增量；终态与临时态分开，真实 usage 到达后
   替换估算，不重复计入 ProviderState 密文字节，不额外调用 token 计数接口；展示自动压缩原因。
8. 拆分 Runtime 的模型管理和 volatile 存储大文件；开发启动脚本默认使用项目 `.runtime-test`，
   修正 Host 重启时实例身份核验问题。远程 Windows 构建流程保留为本地忽略工具，不作为通用产品接口。
