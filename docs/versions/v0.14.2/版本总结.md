# v0.14.2 版本总结：设置、原生生命周期与发布收口

## 一、版本结论

`v0.14.2` 于 2026-08-16 完成开发、验证与归档。本版本补齐桌面端设置、权限管理、原生生命周期、
安全与可访问性，并完成 macOS arm64 实际打包，使 `v0.14.0`–`v0.14.2` 共用统一设计基线的
桌面 MVP 连续实施阶段正式闭环。

- 统一范围：[`v0.14.0 功能设计`](../v0.14.0/功能设计.md)
- 统一方案：[`v0.14.0 技术方案`](../v0.14.0/技术方案.md)
- 本版计划：[`开发计划`](开发计划.md)
- 验收证据：[`验收记录`](验收记录.md)
- 过程记录：[`开发进度`](开发进度.md)

## 二、主要交付

1. **设置与模型管理**：形成 Runtime 诊断、模型新增/编辑/删除、默认模型、连接测试、配置冲突
   与 API Key 脱敏的完整闭环。
2. **权限管理**：支持 Session、Workspace 权限规则维护及 Global 只读投影；权限文件采用与
   Runtime Authorizer 一致的装配、校验与 revision CAS 流程。
3. **桌面生命周期**：统一窗口、系统菜单、托盘、关闭、退出、停止和重启 Runtime 的原生语义，
   保持桌面客户端与 Runtime 进程生命周期解耦。
4. **质量收口**：收敛 Dialog、DropdownMenu、SelectionPopover、Tooltip 等通用交互，补齐键盘、
   焦点、ARIA、缩放、窄窗口、流式渲染和按需 Markdown 能力加载。
5. **发布验收**：统一 workspace、Desktop、Tauri 和产物版本号，标题栏展示版本号，生成并验证
   macOS arm64 App 与 DMG，完成桌面 MVP 最终验收。

## 三、验证结果

- Rust workspace：`873 passed / 0 failed / 7 ignored`；
- `cargo fmt`、workspace Clippy、Rustdoc、Cargo metadata 与 `git diff --check` 通过；
- Desktop：16 个 Vitest 文件、73 项测试通过；正式临时 Host Playwright 场景通过；
- Oxlint、TypeScript、协议生成漂移检查与 Vite 生产构建通过；
- Tauri `--no-bundle` release 构建及实际 macOS bundle 构建通过；
- `EZ Assistant_0.14.2_aarch64.dmg` 完整性校验通过，App 版本为 `0.14.2`；
- 用户于 2026-08-16 确认打包应用可验收归档。

## 四、明确边界

- Linux 无当前目标实机，未执行窗口、托盘、安装和随包 Runtime 实机验收；
- Windows 本版本只保留兼容口，不进入正式开发、编译、打包或验收；
- macOS 产物为 ad-hoc 签名，Developer ID、公证、更新渠道和正式发布证书不在本版范围；
- 部分 Markdown 语法高亮、Math 和 Mermaid 动态 chunk 仍超过 500 kB，但不进入首屏入口；
- 真实 Provider 付费测试和显式系统能力 smoke test 按设计保持 ignored，未以离线结果冒充执行。

## 五、后续入口

下一目标版本暂定为 `v0.15.0`，状态为待启动。记忆、Skills/MCP、后台自动化等方向继续保留在
能力地图中，具体范围需在下一轮从输入池和现有架构事实出发重新确认，不由本次归档预先承诺。
