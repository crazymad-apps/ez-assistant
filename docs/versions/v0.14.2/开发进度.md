### M2：窗口、菜单、托盘与 Runtime 生命周期

- 目标：将所有桌面入口收敛到一致的原生生命周期，并保持 Runtime 与客户端进程解耦。
- 状态：✅ 已完成
- 实际结果：已建立单一 Tauri Rust 生命周期协调器及前端意图边界；macOS 使用原生 traffic lights，
  Linux 使用无边框窗口控件；应用菜单和托盘提供窗口、Runtime 状态、停止、重启与退出入口。关闭窗口、
  退出客户端、退出并停止 Runtime、停止 Runtime 和重启 Runtime 共享影响确认，默认退出不停止 Host。
  Runtime 停止/重启使用正式 shutdown 与 instance 发现协议，不按 PID 强杀；窗口状态和设备级关闭偏好
  独立持久化，危险的同时停止选项不保存。macOS 托盘使用独立的紧凑 template 图标，不再缩放带安全
  留白的 Dock 应用图标，并可自动适配菜单栏深浅色外观。macOS 隐藏到托盘时同步移除 Dock 图标；仅托盘
  “显示主窗口”等明确用户意图恢复 Dock 与主窗口，不再把打开任意托盘菜单误判为系统 Reopen。Runtime
  停止/重启的原生状态由命令结果直接收口，控制请求使用覆盖受控停止周期的独立超时，重启返回的
  bootstrap 由前端直接复用，不再发起第二次发现请求。托盘 Runtime 状态以原生 Host bootstrap 为准，
  Host 健康检查成功后直接进入“已连接”，且不会被 WebView 随后的临时“连接中”状态回退覆盖。原生
  菜单状态更新只在锁内复制菜单项句柄，实际 AppKit 菜单变更在释放协调器锁后执行，避免工作线程等待
  主线程更新菜单时，主线程又因 WebView invoke 重入同一把锁而启动死锁。托盘图标左键打开原生菜单，
  但不恢复 Dock 或主窗口；托盘“停止 / 重启 / 退出”改由原生确认框和 Runtime 协调器直接处理，不再复用
  会先显示主窗口的 WebView 意图入口。隐藏 WebView 只通过原生 Runtime mutation 事件暂停旧连接，并在
  重启完成后连接新实例；窗口恢复只由明确的“显示主窗口”菜单项触发。窗口关闭按钮与 Linux 自绘关闭
  按钮统一读取设备级关闭偏好；选择“退出客户端”时直接进入原生退出确认，不再先阻止关闭后依赖
  WebView 接收退出意图，因此隐藏或尚未就绪的 WebView 不会再造成关闭按钮失效。
- 自动验证：Desktop lint、67 个前端测试和生产构建通过；Host 73 个单元测试、8 个正式 Host 离线集成
  测试和 Desktop 11 个 Rust 测试通过；目标包 Clippy、fmt 与 Tauri `--no-bundle` release 构建通过；
  3 个真实 Provider 付费测试按设计忽略。
- 当前步骤：实现、自动验证与 macOS 人工交互验收完成；本轮缺陷修正后的 Desktop Rust 测试、
  目标包 Clippy、fmt、生产构建与 Tauri `--no-bundle` release 构建均通过；并已实际复现启动，确认修复前
  主线程阻塞于菜单状态锁、修复后正常进入 AppKit 事件循环且主窗口成功注册。

### M3：桌面安全、可访问性、视觉与性能收口

- 目标：把统一设计从功能可用收敛到可长期维护和可安全发布的桌面体验。
- 状态：✅ 已完成
- 实际结果：WebView capability 继续只保留基础窗口能力，外部 HTTP(S) 链接经前端和 Rust 窄命令
  双重校验；CSP 补充 `base-uri`、`form-action` 与 `frame-ancestors` 限制。Dialog、DropdownMenu、
  SelectionPopover 与 Tooltip 收敛为通用组件，补齐焦点陷阱、关闭后恢复、方向键/Home/End、Escape、
  外部点击和 ARIA 语义；Reasoning 与右栏 Disclosure 关联受控内容。设置页在高缩放产生的窄视口下改为
  顶部导航并取消固定最小高度，避免表单裁切。RootStore 改为只在 document 生命周期结束时释放，避免
  React StrictMode 的模拟卸载提前销毁原生监听和 reaction。
- 性能结果：Conversation 历史继续按 cursor 分页并在 prepend 后维持视觉锚点；仅在用户原本位于底部时
  跟随连续输出，live delta 使用 animation frame 合批。Streamdown 的 Code、Math 与 Mermaid 插件按内容
  能力懒加载且缓存 import Promise，不再随每个流式 token 重复触发插件装载；生产入口为 413.81 kB、
  gzip 119.52 kB，大型语法和图表依赖保持独立动态 chunk。
- 自动验证：Desktop lint、16 个测试文件共 73 个测试、真实临时 Host 的 1 个 Playwright E2E、生产构建
  与 Tauri `--no-bundle` release 构建全部通过。Vite 仍报告若干大于 500 kB 的可选动态语法/图表 chunk，
  它们不进入首屏入口，作为 M4 产物审计项继续记录。
- 里程碑确认：2026-08-16 用户确认交互验收通过。
- 当前步骤：已进入 M4。
