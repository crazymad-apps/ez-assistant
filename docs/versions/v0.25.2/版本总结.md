# v0.25.2 版本总结

当前状态：已完成。2026-09-11 用户确认版本验收所列限制并授权归档；M8 已完成。详细证据见[验收记录](验收记录.md)与[开发进度](开发进度.md)。

## 实际交付

- Node／TypeScript Client：start、status、stop、restart、web 命令与交互式 config，管理本机共享 Host。
- Client／Desktop／Host 使用软件版本及最低兼容版本双向准入；数据库独立设置最低兼容 Host，写前拒绝不安全库。
- 统一 Bearer、Cookie、CORS 与本机权限边界；Client 内部实现与 Host／Desktop 独立。
- npm 主包自动选择 macOS arm64、Linux arm64／x64 附件，Host 位于 node_modules，沿用共享 Runtime Home。支持 Node 22.12+（22.x）及 24.x；旧 Node 的私有 CA 通过 NODE_EXTRA_CA_CERTS 配置。
- Linux 自启默认关闭：root 使用系统级 systemd，普通用户使用用户级服务与 linger；直接运行 Host，拒绝隐式跨范围重复注册。
- 公司私有 npm 已发布 Client 0.25.2-9、Host 附件 0.25.2-1；应用软件版本仍为 0.25.2。本轮不公开发布，不另发 Desktop 安装包。
