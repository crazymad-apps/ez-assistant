## 交互范围

普通操作是 `start`、`status`、`stop`、`restart`、`web` 子命令；无参数显示命令说明。
`config` 是唯一交互入口，先展示当前设置，再选择密码、非本地访问、端口、协议与证书、
允许域名、预览、保存和退出。全部交互使用中文提示，密码遮罩，输入就地校验。

离线配置允许在 Host 未运行时修改并模拟保存。在线修改监听配置后提示重启生效，
密码独立保存，非本地访问需要先设置密码。退出有未保存草稿时默认返回继续配置；
Esc／Ctrl+C 取消流程，取消退出码为 130。

通过场景夹具覆盖未启动、运行中、待重启、双向协议不兼容、数据库兼容失败和端口占用。
不连接 Host，不读写真实配置、数据库或 Runtime Home，不保存密码，不检查证书文件，
不安装服务、不打开浏览器。场景参数和配置草稿不是正式应用协议或业务实现。

## 框架结论

Node.js 已由用户明确选定。当前演示使用 TypeScript 编译为 ESM，由 Node 执行；
开发入口使用 tsx，包管理和脚本使用 npm。无需引入完整 TUI 框架即可覆盖目前的命令与配置需求。

| 组件 | 原型锁定版本 | 作用与结论 |
| --- | --- | --- |
| Node.js | 本机验证 22.16.0 | 使用标准 Node API；当前依赖组合要求 ≥ 22.12.0 |
| TypeScript / tsx | 7.0.2 / 4.23.13 | 严格类型检查、编译及源码开发入口 |
| [Commander](https://github.com/tj/commander.js) | 15.0.0 | 命令树、参数校验、帮助和错误退出 |
| [Clack](https://github.com/bombshell-dev/clack) | 1.8.0 | 菜单、文本、密码、确认和结构化输出，适合本版 config 范围 |
| [Ora](https://github.com/sindresorhus/ora) | 9.4.1 | 步骤动画，配置 `discardStdin: false` 由应用处理取消 |
| Picocolors | 1.1.1 | 标题与状态配色，支持关闭颜色 |

实际 PTY 验证发现，当前 Clack spinner 的按键取消会直接结束进程并返回 0，
无法满足应用统一取消、清理和退出码要求。因此仅使用其提示组件，动画改由 Ora 负责。
SIGINT 监听保持到清理完成，避免光标恢复组件把信号误判为未处理而提前终止进程；
最终 Ctrl+C 验证返回 130，未出现成功提示。

这套组合足以继续评审本机 Host 管理交互。正式交互库与依赖版本仍须在技术方案中确认。
Node runtime 随包携带作为后续分发验证方向，具体版本、目标平台、启动包装及与随包 Rust Host
的装配尚未实现。当前 Demo 通过 npm 启动，不是正式安装包。

## 已执行验证

环境：macOS arm64，Node 22.16.0，npm 10.9.2。测试从空临时目录启动 Demo，未操作真实 Host。

| 验证 | 结果 |
| --- | --- |
| `npm run typecheck`、`npm run build` | 通过；产物为 Node ESM，构建前清理旧产物 |
| `node --test tests/commands.test.mjs` | 6 项通过；含帮助、无 TTY 命令、失败退出码及无文件写入 |
| `npm run test:terminal` | 6 项真实 PTY 流程通过 |
| 密码 | 遮罩、重复输入不一致提示、独立保存；输出未包含演示密码原文 |
| 配置 | 离线保存、在线端口校验、待重启提示、远程开关门槛、HTTPS 路径及域名输入 |
| 窄终端 | 48 列 PTY 下中文路径、HTTPS 配置、预览和放弃修改流程通过 |
| 取消 | Esc、配置 Ctrl+C、动画中 Ctrl+C 均返回 130 |

原生 Terminal 窗口的视觉复核未执行：工具明确禁止控制该应用；PTY 结果不替代用户的视觉体验反馈。
未执行 Linux／Windows 实机验证、正式分发包或真实 Host 集成。未修改 Rust／Desktop 业务代码，
因此未运行 Cargo workspace 和 Tauri 构建。
