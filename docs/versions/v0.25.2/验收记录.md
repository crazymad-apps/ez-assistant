## 回归中发现并修正的测试问题

- Desktop 两个错误路径断言使用 err().expect()，触发 Clippy；改为映射成功值后 expect_err，不改变生产行为。
- Cookie 版本声明夹具兑换登录缺少同源 Origin；补齐请求，不放宽 Cookie 校验。
- 原 v0.14.2 迁移夹具混入新版兼容表并删除现行基线必需业务表，不能代表当前支持的无账本旧库。修订为已知无账本结构、移除新版账本及兼容表，构造过程使用事务；保留迁移后会话、分支、子任务、附件和权限文件的断言。单项通过。缺失必需业务表的数据库仍按损坏处理，不增加生产修复或历史兼容分支。

- 工具图片预览集成用例遗漏兼容请求头，补用公共 compatibility_headers；不改变资源准入。
