# v0.23.0 版本总结

## 版本结论

`v0.23.0` 已完成 MCP Tools 的正式产品接入，并于 2026-09-04 发布。用户在进入 `v0.24.0` 后
明确要求补齐本版本归档，本版本据此记为 `已完成`。

GitHub Release、标签、Developer ID 签名、公证和安装包证据均已形成；此前没有执行的原生 WebView
人工清单、真实 Provider MCP 完整调用和干净 Mac 首次安装仍按验收记录中的边界保留，不倒推为通过。

## 实际完成

- 支持 stdio 与 Streamable HTTP MCP Server，并形成独立用户级 `mcp.json` 配置、脱敏管理、导入、
  连接测试、启停、删除和手动刷新闭环。
- 模型通过固定网关按 Server 发现和调用工具；用户也可通过 `/mcp` 为下一次输入选择 Server，避免
  将全部远程 Tool Schema 平铺进每次模型请求。
- MCP 调用复用现有权限、审批、审计、可靠 Tool Exchange、文本与图片结果链路；权限精确到实际
  Server 与 Tool，刷新可使旧身份失效。
- `/mcp refresh` 作为可靠 Session Command 排队，不创建 Run；连接候选、活动 Registry、连接 lease、
  超时、取消和失败保留旧连接均完成。
- 修复单次 MCP 工具超时误取消整个 Run、部分 Streamable HTTP 服务协议协商、技能测试受本机环境
  干扰、设置与产品展示等问题。
- Desktop 完成 MCP 设置页、Picker、标签、审批、工具详情和控制结果，并统一相关单行控件、输入焦点、
  选择列表及能力列表视觉行为。

- `cargo fmt --all --check`、workspace 全 targets/features 严格 Clippy 和全部非 ignored 测试通过。
- Desktop lint、251 项 Vitest、生产构建、5 项正式 Host Playwright E2E 通过。
- macOS arm64 App 与 DMG 通过 Developer ID 签名、Apple 公证、staple、签名和分发检查。
- GitHub Release：[`EZ Assistant v0.23.0`](https://github.com/crazymad-apps/ez-assistant/releases/tag/v0.23.0)。
- 标签 `v0.23.0` 指向提交 `5418b731a233210c633ee0f112312c53d43b83bc`。
- 正式 DMG：24,037,508 字节，SHA-256
  `122a1547c264826a62a4b85674eeeae80f3109a7eb578ca66f6b7befcdec65bc`。

完整环境、命令、隔离范围、自动验收矩阵和发布证据见[验收记录](验收记录.md)、
[验收准备](验收准备.md)与[发布说明](发布说明.md)。

## 已知边界

- 原生 WebView 的完整 MCP 设置、Picker、审批和详情人工清单未执行。
- 真实 Provider 通过真实 MCP 服务的完整调用未在最终归档阶段重复执行；正式 Host 确定性与隔离
  E2E 已覆盖产品链路。
- 干净 macOS 设备首次安装未验证；本机 `spctl` 存在系统级 assessments disabled，另以
  `syspolicy_check distribution` 通过分发检查。
- 本版只交付 MCP Tools；Resources、Prompts、交互式 OAuth、插件包、市场与远程安装留待后续版本。
