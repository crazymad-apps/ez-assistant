## 新增与改进

- MCP 支持本地 stdio 和远程 Streamable HTTP；设置页可新增、编辑、启停、删除、导入及测试服务。
- 模型按服务名称和业务范围选择 MCP，再发现该服务的工具；不将所有服务的工具定义平铺进每次请求。
  也可通过 `/mcp` 手动选择服务，让下一次任务直接获得其工具定义。
- `/mcp refresh` 通过会话队列更新连接与工具目录，遵守现有阻塞顺序，不额外启动模型任务。
- MCP 权限与审批显示实际服务、工具及参数；文本和图片结果沿用现有会话与工具详情展示。
- 工具调用默认超时为 120 秒；服务可配置更长或更短的值，清空后继承默认值，不再受固定的
  10 分钟业务上限约束。单次工具超时不会误取消整个 Run。
- 统一桌面单行控件尺寸：small 24px、默认 32px、large 40px，边框和内边距计入总高度。
  输入框只高亮边框，选择器复用统一组件，下拉选项不再叠加内层圆角与容器 padding。
- 优化 MCP/Skill 列表、输入标签顺序、控制结果层级、删除入口和菜单分隔线；修复上下文栏技能显示问题。
- 修复部分 Streamable HTTP 服务的协议协商问题；工具说明超过建议大小时报告警告，保留整体大小保护。

## 使用与升级说明

- 服务配置保存在 Runtime Home 的独立 `mcp.json`，可供所有会话使用；无需将主配置的
  `schema_version` 改为 2。设置保存只更新配置，使用会话中的 `/mcp refresh` 应用到活动连接。
- 新增 MCP 权限规则时权限文档使用 schema 2；这与主 `config.toml` 的 schema 无关。
  本版含会话输入与选择信息的持久化扩展，不能假定旧版程序可直接读取升级后的全部数据。
- 在真实用户数据上升级、回滚或恢复前，应按项目数据库安全规则另行确认并验证独立备份。
  本次提交准备没有执行真实数据库、权限文件或服务配置迁移，也没有安装应用。
- 本版不提供 Resources、Prompts、交互式 OAuth、旧 HTTP+SSE、插件市场或浏览器自动化专属界面。
