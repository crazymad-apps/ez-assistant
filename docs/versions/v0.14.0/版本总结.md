# v0.14.0 版本总结：正式主会话闭环

## 一、版本结论

- 版本：`v0.14.0`
- 状态：已完成
- 完成与归档日期：2026-08-14
- 功能范围：[`功能设计`](功能设计.md)
- 实现方案：[`技术方案`](技术方案.md)
- 开发过程：[`开发计划`](开发计划.md)、[`开发进度`](开发进度.md)
- 验收证据：[`验收记录`](验收记录.md)

本版本完成正式桌面端 MVP 的第一交付片：Tauri Desktop 可以启动或连接独立 Runtime Host，
通过正式产品协议观察 Workspace、Session 和主 Conversation，提交输入并处理流式执行、队列与审批。
Desktop 采用 React、MobX、Sass、TypeScript 和 Vite，不在 UI 建立第二份权威业务状态。

## 二、主要交付

1. 建立带 sequence/watermark 的产品事件和 Observed Snapshot，补齐 Application、Session、
   Conversation 分页、Tool Detail、Usage、Queue 与 Approval Queue 的正式投影和生成类型漂移检查。
2. Tauri 通过受控 bootstrap 连接或启动 release Runtime sidecar；token、discovery 和原生能力保持在
   Rust/Runtime Client 私有边界，正式页面铺满 WebView 并适配 macOS overlay title bar。
3. 完成 Workspace 分组、独立会话、搜索、新建与切换，以及三栏产品外壳和窄窗口布局。
4. 主消息按真实 Step 展示 Reasoning、正文和同批 Tool Group；支持分页、流式增量、详情、Turn 级
   操作、稳定贴底和 Streamdown 安全 Markdown 渲染。
5. 完成 Composer、Slash Command、模型/模式/权限共用选择器、输入队列和底部审批工作区；用户中断、
   排队恢复、审批最小化和权威快照回正形成完整闭环。
6. Workspace 缺少权限文件时生成可编辑的默认规则：Build 允许工作区内结构化读写，Plan 允许读取；
   Shell、工作区外调用和显式 Ask/Deny 继续进入既有权限与审批边界。
7. 正式 Desktop 和 Host 验收不再依赖主 Conversation 私有整量快照；子 Conversation 私有接缝保留到
   `v0.14.1` 产品子投影替代后删除。

## 三、验证结论

版本级门禁全部通过：

- `cargo fmt --all --check`
- `cargo clippy --workspace --all-targets --all-features -- -D warnings`
- `cargo test --workspace`：`832 passed / 0 failed / 7 ignored`
- `cargo doc --workspace --no-deps`
- `cargo metadata --format-version 1 --no-deps`
- Desktop `npm run lint`、`npm run test`：7 个文件、26 项测试通过
- Desktop `npm run test:e2e`：1 个正式临时 Runtime Host 场景通过
- Desktop `npm run build`
- Desktop `npm run tauri -- build --no-bundle`

所有自动化场景使用临时 Runtime Home、SQLite、Workspace、loopback Host 和离线 Provider，未修改
用户真实 Runtime 业务数据。

## 四、保留边界

- Windows 本版本只保留兼容边界，未做正式编译、打包或实机验证。
- 7 项 ignored 测试包含真实 Provider 付费调用或显式系统级测试，本轮未重复执行。
- 签名、安装器和发布级 bundle 由 `v0.14.2` 完成。
- 部分按需 Markdown/Code/Math/Mermaid chunk 仍超过 500 kB，作为 `v0.14.2` 性能观察项。
- Fork、持久化反馈、完整会话资源管理、附件和子 Agent 二级消息视图进入 `v0.14.1`。

## 五、后续方向

下一版本为 [`v0.14.1`](../v0.14.1/版本总结.md)，在本版本主会话闭环上完成
Session/Workspace 管理、Fork 与删除、附件和文件资源、右侧上下文、子任务树及子 Agent 消息视图，
并在正式主/子投影全部替代后退役 Host Web Demo。
