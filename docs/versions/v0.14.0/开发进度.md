### M1：Runtime/Host 观察快照与主会话产品投影

- 目标：让正式 Host 提供可从事件缺口恢复的应用/主会话组合快照、分页、工具详情和有序
  Queue/Approval 控制。
- 影响模块：`assistant-protocol`、`assistant-runtime`、`apps/runtime-host`。
- 状态：✅ 已完成
- 实际结果：
  - 新增统一 `ObservationCoordinator`、严格递增事件 envelope、带水位组合快照和聚合失效通知；
    Host SSE 在 lag 时继续发送 `stream_gap` 并断流，既有 Runtime 裸事件仅保留兼容订阅。
  - 正式实现 Application/Session View、主/子 Conversation Page、Run 定位、Tool Detail、主会话
    Usage、Queue 与 Approval Queue 产品投影，并启用对应 Command/Host 路由与 capability。
  - Conversation 分页由 Store Worker 按 User/Assistant 边界懒构建 JSONL 字节 offset，使用 32 项
    有界 LRU；cursor 绑定 generation，正文追加自动重建索引，generation 变化返回 stale。
  - 队列新增 revision、可靠 prioritize、用户中断暂停和指定恢复；SQLite additive 增加
    `priority_order`，重复提升保持非负顺序且跨 Host 重启恢复。
  - Approval Registry 增加 Session 级 revision 与队首 resolving lease；后到审批保持排队，拒绝并
    停止复用既有审计、取消和终态路径。
- 验证结果：
  - `assistant-protocol` 30 个测试、`assistant-runtime` 110 个测试通过；Runtime Host 58 个单元测试
    和 8 个正式 Host/恢复验收测试通过，3 个真实模型付费测试按设计忽略。
  - 三个 crate 的 Clippy `-D warnings`、Rust 格式和 diff whitespace 检查通过。
  - TypeScript 协议重新生成与漂移检查通过；Desktop Vitest 2 个测试和生产构建通过。
- 当前步骤：里程碑停止，等待确认。
- 续作点：确认后进入 M2，只实现 Tauri Runtime bootstrap、React/MobX/Sass 产品外壳及真实
  Application/Session 快照消费，不提前实现 M3 消息渲染或 M4 mutation UI。
- 里程碑确认：用户已于 2026-08-13 确认继续开发。
- 遗留/风险：M1 保留 Web Demo 私有接口供既有验收使用；按计划在主/子产品投影替代完成后删除。
- 关联版本文档：`docs/versions/v0.14.0/开发计划.md`

### M2：Tauri Runtime bootstrap 与 React 产品外壳

- 目标：让正式 Desktop 安全启动或连接 Runtime，并以真实 Application/Session 快照形成可恢复的
  React 产品外壳与会话导航。
- 影响模块：`apps/desktop`、`apps/runtime-host`。
- 状态：✅ 已完成
- 实际结果：
  - Tauri Rust 新增受控 Runtime bootstrap：只在受信任进程读取私有 discovery，校验 loopback、
    文件权限、PID、健康和 capability；token 仅短暂交给 Runtime Client 私有字段，不进入 MobX、
    URL、日志或偏好存储。
  - Runtime Host 新增 Unix `launch` 平台适配，随包 release sidecar 可派生独立 `serve` 进程；
    Desktop 优先连接已有实例，必要时有界启动并轮询，不把 Runtime 生命周期绑定 WebView。
  - Vanilla 页面替换为 React 19、MobX 7、Sass CSS Modules 产品壳；实现 Root/Error Boundary、
    Root/Projection/LiveExecution/Navigation Store、SSE 先订阅后取快照、watermark/gap/instance 恢复
    和显式 dispose 生命周期。
  - 实现亮色三栏 AppShell、连接状态、左右栏与窄窗口覆盖布局、本机展示偏好、Workspace 分组、
    Session 单行列表、展开收起、搜索、活动/归档切换、真实新建与切换会话；未提前实现 M3 消息和
    M4 Composer/Queue/Approval UI。
  - 正式 AppShell 铺满 WebView，不保留网页 Demo 的外层画布、圆角和阴影；macOS 使用原生
    traffic lights + overlay title bar，并由页面标题栏为按钮组预留安全区。
  - Playwright 使用临时 Runtime Home、Workspace 和正式 Host，真实创建 Workspace/Session 后通过
    bootstrap 边界验证页面读取、Workspace 展开、会话新建与切换；测试结束关闭 Host 并清理临时数据。
- 验证结果：
  - Desktop Oxlint、协议漂移检查、TypeScript/Vite 生产构建通过；Vitest 3 个文件 5 个测试、
    Playwright 1 个真实 Host 端到端测试通过。
  - Desktop/Runtime Host Clippy `-D warnings`、Rust 格式检查和全部目标测试通过；Host 59 个单元
    测试、8 个正式 Host/恢复验收测试通过，3 个真实模型付费测试按设计忽略；Desktop 4 个测试通过。
  - `npm run tauri -- build --no-bundle` 使用 release Runtime sidecar 构建通过；应用内浏览器核验
    1280px 三栏和 720px 覆盖布局均无横向溢出，断线与侧栏切换状态一致。
- 当前步骤：里程碑已确认，已进入 M3。
- 续作点：M3 只接主 Conversation 分页、Streamdown 内容、Reasoning/Tool 行和消息操作，
  不提前开放 M4 Composer、队列或审批 mutation。
- 里程碑确认：用户已于 2026-08-13 确认继续开发。
- 遗留/风险：Windows 仅保留平台边界，本版本未做正式编译、打包或实机验证；Web Demo 私有接口继续
  保留到 `v0.14.1` 子投影替代完成。
- 关联版本文档：`docs/versions/v0.14.0/开发计划.md`

### M3：主消息列表、流式内容与主投影替代

- 目标：以正式分页投影和实时事件完整呈现主 Conversation，移除正式 Desktop/Web Demo/Host
  验收对主会话私有整量快照的依赖。
- 影响模块：`apps/desktop`、`apps/runtime-host`、`assistant-runtime`。
- 状态：✅ 已完成
- 实际结果：
  - 主消息区消费 `ConversationPage`，支持最近页、向上 prepend、generation 失效恢复、视觉锚点、
    Run 定位和稳定 message/part key；长历史使用分页与浏览器内容可见性优化，不一次装载整份正文。
  - 按真实 segment 顺序展示 User/Assistant、灰色可展开 Reasoning、低干扰工具单行事件和按需详情；
    Assistant 支持复制、本地反馈态、折叠后单行占位，Fork 在正式 mutation 尚未进入协议前保持禁用。
  - 同一 Run 的连续 Assistant 消息在 UI 中按一个 turn 组织，消息操作栏和整体折叠只出现一次；
    工具行不展示 JSON 形态输出，长摘要使用单行截断且状态圆点保持固定尺寸。
  - Streamdown 区分静态与流式模式，Code/Math/Mermaid 只在内容需要时动态加载；关闭 raw HTML，
    仅允许 `http/https`，通过 Rust 受控 opener 打开外链，插件异常回退为不可信纯文本。
  - 实时 `text/reasoning/tool/usage/run_finished` 事件按 rAF 批量合并并保持
    `reasoning → text → tool group` 原始循环顺序；可靠 Assistant 提交后清理同 Run 临时投影，重连时
    使用活动 Run 快照保守恢复。
  - 右侧会话卡片增加主 Session 上下文环图、上一轮输入/输出/缓存命中和累计 Token；不聚合子任务
    Usage。应用以真实本地 Conversation 做过窗口内视觉核验。
  - 正式 Host 删除主 `ConversationSnapshot` 私有 Command/Result；Web Demo 和正式 Host 验收客户端
    改为分页产品投影。子 Conversation 私有接缝按计划保留到 `v0.14.1`。
  - 修复历史重写 generation 同步缺陷：Store 提交新 generation 后通过 `RewriteResult` 同步内存
    Session，最新页可立即读取，旧 cursor 继续返回 `SnapshotStale`。
- 验证结果：
  - `assistant-protocol` 30 个、`assistant-runtime` 110 个测试通过；Runtime Host 59 个单元测试和
    8 个正式 Host/恢复验收测试通过，3 个真实模型付费测试按设计忽略。
  - Desktop Oxlint、协议漂移检查、TypeScript/Vite 构建通过；Vitest 4 个文件 11 个测试、Playwright
    1 个真实 Host 端到端测试通过。
  - Rust 格式检查及 Desktop/Protocol/Runtime/Host Clippy `-D warnings` 通过；
    `npm run tauri -- build --no-bundle` 使用 release sidecar 构建通过。
  - 首屏主 JavaScript 为 `281.83 kB`（gzip `85.83 kB`），主 CSS 为 `27.80 kB`（gzip `5.71 kB`）；
    Code/Math/Mermaid 重资源已拆为按需 chunk，构建仍会报告部分延迟 chunk 超过 500 kB，作为后续
    性能门禁观察项，不影响首屏主包。
- 当前步骤：里程碑已确认，已进入 M4。
- 续作点：M4 实现 Composer、Slash Command、队列、审批和主会话端到端 mutation；不提前进入
  `v0.14.1` 子 Agent 页面。
- 里程碑确认：用户已于 2026-08-13 确认继续开发。
- 遗留/风险：Fork 与持久化反馈尚无当前协议 mutation，本里程碑只呈现布局与安全降级；Streamdown
  的 Shiki/Mermaid 延迟资源较大，M4 后性能收口时继续核验真实使用成本。
- 关联版本文档：`docs/versions/v0.14.0/开发计划.md`

### M4：Composer、队列、审批与主会话端到端回证

- 目标：完成从输入到真实 Agent 执行、排队、手动中断、恢复和审批决策的主会话闭环。
- 影响模块：`apps/desktop`、正式 Runtime Host 测试边界。
- 状态：✅ 已完成
- 实际结果：
  - 新增两行起始、最多八行自增高的 Composer；Enter 提交、Shift+Enter 换行、中文输入法组合态、
    空草稿时中断当前 Run，以及断线和 mutation pending 禁用均进入统一状态机。
  - `/model`、`/mode`、`/approval`、`/new`、`/help` 共用 Slash Command 入口；模型、Build/Plan、
    Ask/Auto 共用向上浮动选择器，支持键盘选择、跟随滚动、点击外部关闭和当前值短路。
  - 队列作为输入框上方二级抽屉展示，支持行级优先、移除以及用户中断后的指定恢复；不增加占空间
    的底部整队执行按钮，自动状态仍由 Runtime 按序串行。
  - 待审批事件默认抢占底部工作区，支持最小化后继续阻塞、恢复详情、一次/当前会话/当前 Workspace
    范围、拒绝和拒绝并停止本轮；主/子 Agent 审批继续使用同一 Session 队列契约。
  - Workspace 注册会在权限文件缺失时生成可编辑的默认规则：Plan/Build 允许 Workspace 内结构化
    读取，Build 允许结构化写入；恢复旧 Workspace 只补缺失文件，既有自定义文件保持不变，Shell
    和 Workspace 外调用仍进入原权限决策与审批流程。
  - mutation 统一显示 pending、结构化失败与权威快照回正；归档会话提供显式恢复入口。
  - 修复终态 Run 临时投影未回收导致“正在生成”残留；可靠 Conversation 仍是终态正文的展示来源。
  - 修复活动 Run 的多 Step 流式投影：Runtime 透传 `StepStarted` 分组边界并在新 Step 清空活动
    快照正文，前端按 Step 隔离复用的 part ID；上一 Step 可靠提交后从实时投影移除，工具切换到
    可点击详情的历史消息且不被累计 Run 快照重新堆入最新 Step。
  - 消息滚动改为显式贴底状态：用户停留底部时，流式 Markdown 和异步内容高度变化持续跟随；用户
    向上阅读后保持当前位置并显示回到底部按钮，禁用浏览器自身锚点与该策略相互争抢。
  - 按用户授权补充独立 macOS 图标兼容路径：full-bleed 源图标与专属 ICNS 只由显式脚本生成，
    `tauri.macos.conf.json` 仅在 macOS 合并该资源；默认跨平台图标源和其他平台生成文件不受此路径影响。

  - `cargo fmt --all --check`、workspace Clippy `-D warnings`、`cargo test --workspace` 全部通过；
