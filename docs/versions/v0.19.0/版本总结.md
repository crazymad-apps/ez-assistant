# v0.19.0 版本总结：本地技能与内插时间线

## 一、版本结论

`v0.19.0` 于 2026-08-25 完成开发、验证、用户验收与归档。本版建立了兼容 Agent Skills
格式的本地技能发现、冻结目录、用户/模型激活、持久恢复和中文 Desktop 闭环；同时以同一 Run
全局单调 step 与统一内部消息边界，修复 `read_image` 等请求期 user-role 内插后 reasoning、正文
和工具调用可能显示错位的问题。

## 二、主要交付

1. **确定性技能发现与启停**：只扫描工作区和用户根目录下 `.ez-assistant/skills`、
   `.agents/skills` 四个固定 Root，按已确认优先级确定同名 Winner；有界解析无效候选并生成诊断，
   SQLite 只以校验后的技能名称保存默认启用的全局开关。
2. **Session 冻结目录与共享资源**：新 Session 冻结精确 `SKILL.md` 定义、来源目录和模型可见目录；
   既有会话不因文件或开关变化被改写，Fork、归档恢复、Runtime 重启和 child 所有权可恢复；普通资源
   留在共享 Root 按需访问，不复制到 Session。
3. **单技能用户激活**：Composer 一次只保留一个待发送技能，再次选择直接替换；Activation 与完整
   Input 在 accepted 边界原子冻结，成功后清空草稿，失败保留；Queue、Goal held input、消息和恢复
   使用同一冻结事实。
4. **稳定 `load_skill` 与同 Run 续段**：工具始终使用普通字符串参数，不随目录变更动态改 schema；
   完整 Tool Result 批次、隐藏 InternalContext 和 Activation ledger 原子提交后，Runtime 在同一业务
   Run 的下一全局 step 继续执行，存储失败不发布伪成功，也不增加技能级权限门禁。
5. **统一内插边界与时间线**：Goal、WorkPlan、Skill、压缩 continuation 和委派共用规范内部消息及
   Runtime 边界协调器；Chat/Responses 图片信封只在 Provider 请求期生成。同一 Run 的 step 从 Core
   直接单调递增，Desktop 只按 `run_id + step` 和 `call_id` 对账，不再使用 segment 或消息数量映射。
6. **Provider 与恢复兼容**：Chat/Responses 图片、相同 PartId、多次内插、事件缺口、分页、断线、
   重启及 parent/child 均有结构夹具与正式 Host 离线回归；新增 VLLM reasoning 方言投影。模型配置丢失
   时历史会话仍可读取，空闲会话允许删除所用模型并回到未选择状态，重新选择前禁止发送。
7. **中文 Desktop 技能闭环**：设置提供技能范围、名称启停、诊断、详情和安全打开来源目录；
   `/skill`、单标签、Queue 右侧标签、加载技能工具行和当前上下文全部使用结构化快照。设置一级/二级页
   统一固定页头与单一内容滚动容器，返回按钮和紧凑页头操作由同一组件承载。
8. **输入与选择体验收口**：中文输入法通过统一 composition guard 避免确认回车误发送；会话和
   Composer 设置明确文本选择边界，避免 WKWebView 把标签、空白、工具栏或空 textarea 绘制为整块
   蓝色选区，同时保留正文、代码、思考正文和聚焦输入框的原生文本选择。
9. **版本同步**：Rust workspace、npm、锁文件和 Tauri 产品版本统一为 `0.19.0`。

## 三、验证摘要

- Rust workspace `cargo fmt --all --check`、全目标/全 feature Clippy `-D warnings` 和全量测试通过；
- Desktop lint、20 个 Vitest 文件共 118 项测试、生产构建、正式 Runtime Host Playwright E2E 和
  Tauri release `--no-bundle` 构建通过；
- 正式 Host + fake Chat Provider 验证模型调用 `load_skill` 后在同一 Run 继续，第二次请求读取冻结
  正文，SQLite 可靠 step 为 `[1, 2]`，Host 重启后恢复活动技能；
- 所有 SQLite、JSONL、共享文件与恢复核验均使用 TempDir、易失 Store 或隔离 Runtime Home，未读取
  或写入用户实际 Runtime 数据库；
- 验收期会话/Composer 选区修复完成后，相关 28 项组件测试、生产构建和 Tauri release 构建再次通过；
- 用户完成实机使用后明确表示“本版本没什么问题了”并要求归档，版本验收通过。
- macOS arm64 正式 DMG 已完成 Developer ID 签名、App/DMG 双阶段 Apple 公证、staple、
  Gatekeeper 与只读挂载复验；最终 SHA-256 及 submission ID 见验收记录。

详细命令、环境、人工结论和完成判定见 [验收记录](验收记录.md)。

## 四、偏差、遗留与非目标

- 未运行需要真实 Provider 的 `#[ignore]` 图片或 Skill 测试，未产生网络请求或模型费用；
  Provider-neutral 行为由 Chat/Responses 结构夹具、fake Provider 和正式 Host 离线测试覆盖。
- Vite 生产构建保留既有 chunk-size warning，未见功能或运行阻断。
- Windows Runtime Host、PowerShell 默认 Shell、Windows/Linux 安装包仍为既有非目标。
- MCP、插件市场、远程技能安装、文件 watcher、刷新已有 Session Catalog 和多技能草稿不属于本版。
