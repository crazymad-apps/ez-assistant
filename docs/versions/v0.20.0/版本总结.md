# v0.20.0 版本总结：主控会话、代理通信与上下文控制

## 版本结论

`v0.20.0` 于 2026-08-26 完成开发、验证、用户验收与归档。本版没有引入复杂任务编排或通用消息
总线，而是在现有 Session、Input、Run、Conversation 与 generation replacement 基础上建立了
主控会话和简单代理通信底座，并补齐会话 clear、用户主动 `/compact` 以及相关 Desktop 闭环。

## 主要成果

1. **主控会话底座**：配置可用时自动创建主控，产品层软性单例，角色与代理关系可迁移、持久化
   和重启恢复；Controller 生命周期限制由 Runtime 权威执行。
2. **统一工具装配流水线**：冻结预设工具和主控工具作为平行装配环节，按名称去重并校验冲突；
   为后续 Goal、Session 或插件式动态工具注入保留统一入口。
3. **简单代理通信**：主控可查询、切换和投递；普通会话启用代理后才接收工作消息，Queue 排空时
   只报告最新结果，用户直接输入原子接管且不产生取消噪声。
4. **主控能力隔离**：只有用户直接主控父 Run 获得跨会话工具；代理报告、Goal continuation 与
   child 均不能继承控制能力，主控处理报告后必须等待用户新指令。
5. **会话 Clear**：空闲门禁、System Context 重建、generation 原子切换、结构删除、物理清理和
   崩溃恢复形成完整闭环，同时保留附件文件、私有目录与稳定 Session 配置。
6. **手动 Compact**：`/compact` 作为旁路操作复用既有 rolling summary，不创建普通 Input/Run 或
   独立压缩实体；自动/手动共用易失状态、事件和取消入口，真实错误不再被统一吞掉。
7. **Conversation 与 Responses 兼容**：产品历史继续完整展示；wire 层兼容旧 Chat 历史缺失
   Responses state ID、reasoning 形状和 Tool Call 分组，不新增持久化兼容结构。
8. **Desktop 收口**：固定主控入口、代理 Switch、跨会话来源、长报告折叠、压缩摘要分割线、
   Todo 空列表清除和空闲 loading 隐藏全部落地。
9. **Queue 闪现修复**：待发送区由单一 presentation selector 从权威 Queue/Run 快照派生，消除
   自动交接队首短暂显示，同时保留真实排队、暂停和 Goal 暂存项。
10. **开发规范收紧**：明确如无必要勿增实体、不得滥用 revision/version/generation/sequence、
    公共复杂编排必须有真实消费者，并补充复杂 Rust 编排代码的注释要求。
11. **版本同步**：Rust workspace、npm、锁文件和 Tauri 产品版本统一为 `0.20.0`。

## 后续方向

主控会话已经具备应用内简单通信和控制底座。智能终端、IM 终端、通知、多主控产品策略、复杂任务
编排和通用插件 ABI 均未在本版预实现，应在出现明确产品需求和消费者后另行设计。
