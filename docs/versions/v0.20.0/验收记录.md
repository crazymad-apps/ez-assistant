## 四、功能与跨层证据

### 4.1 主控会话与工具装配

- Runtime 在配置可用时自动确保主控会话存在；产品层稳定选取第一条主控，Store/schema 不增加
  单主控唯一约束，旧 Session 可安全迁移并在重启后恢复角色与代理关系。
- Run 使用统一工具装配流水线；冻结预设工具与主控工具作为平行装配环节，最终按工具名去重并
  检查冲突。只有用户直接发给主控的父 Run 获得查询、切换和投递工具；代理报告、Goal
  continuation 与 child 不获得跨会话能力。
- Controller 的归档、删除、Fork 和代理绑定由 Runtime 权威拒绝，Desktop 只投影可用操作。

### 4.2 代理通信、Queue 与用户接管

- 普通会话必须先开启代理才能接收主控投递；代理状态切换本身不被活动 Run/Queue 阻止，Queue
  未排空时不执行投递或中间报告，排空后只报告最新终态。
- 用户直接输入会原子退出代理并静默移除尚未开始的主控投递，不生成“已取消”或“用户已接管”
  噪声；主控后续仍可按用户指令重新开启或关闭代理。
- 源 Run 结算与 ProxyReport 接受位于同一可靠结算边界；重启恢复不会绕过来源、代理状态或主控
  工具门禁。报告处理 Run 不能自主继续控制其他会话。

### 4.3 Clear 与 Compact

- Clear 仅允许空闲 Session，先准备新 generation/System Context，再原子切换权威历史；消息、
  Run、Queue、审批、Goal、WorkPlan 等产品历史被清除，附件文件、Session 私有目录、身份、标题和
  工作区绑定按设计保留。
- Host 测试覆盖 clear 的切换失败、准备中断、cleanup pending 与重启恢复；所有迁移、删除和故障
  注入均使用 `TempDir` 或隔离 Runtime Home，未读取或写入用户实际数据库。
- 手动 `/compact` 是会话旁路请求，不创建普通 Input/Run，不增加独立压缩消息实体；自动与手动
  共用 rolling summary 和 generation replacement。易失压缩状态不入库，取消复用 Composer 的
  终止按钮，失败保留原历史并透传实际模型错误。
- 历史消息继续作为产品记录展示，压缩边界只提供摘要查看入口；较早完整消息退出当前模型上下文，
  不在产品层复制第二份历史。

### 4.4 Desktop 与兼容修复

- 活动会话页展示固定主控入口，归档页隐藏；代理只保留 Switch，不重复展示无意义 Tag。
- Queue 由单一 presentation selector 决定可见性、计数和列表，消除自动交接队首在待发送区闪现；
  Todo 空列表按清空处理，空闲时不显示运行 loading。
- ProxyReport 长正文默认限制高度并以底部渐变表示收起，可点击展开或再次收起。
- 压缩前后 Conversation 继续展示同一产品历史，并提供可点击摘要分割线；没有为 UI 新增压缩指令
  实体。
- Responses 编码继续沿用既有 Conversation 数据结构；Chat 历史缺少 Provider state ID 时按规范
  内容重放，精确相容的原生 state 继续保真。Assistant Turn 在 wire 层稳定归一为
  `reasoning → text → tool calls → tool outputs`，未增加持久化兼容实体。
- `read_file` 工具说明明确调用无状态，续读必须由模型显式使用上一页 `next_offset`。

## 五、故障、恢复与数据边界

- 正式 Host/Store 自动化覆盖 session role/proxy migration、投递与接管、Run settlement、
  ProxyReport、append、generation replacement、cleanup receipt、旧 WorkPlan 清理、重启恢复和
  删除级联。
- clear/compact 的故障注入不会重放历史工具副作用；未发布 generation 会被清理，已提交的新
  generation 保持权威。
- 数据库、JSONL、文件、Runtime 内存状态和 Desktop 投影分别验证；“产品不可见”“逻辑删除”与
  “存储介质安全擦除”未混为一谈。

## 七、未执行项与风险

- 未运行会产生网络请求或模型费用的 `#[ignore]` 真实 Provider 验收；正式 Host fake Provider、
  wire Adapter 测试和用户实际 Desktop 使用作为替代证据。
- 干净 macOS arm64 设备上的首次安装和启动验证尚未执行；本机签名、公证、Gatekeeper 与只读
  挂载验证不能替代该项分发后验收。
- 本版只软性限制一个主控；多主控选择、智能终端、IM、通知和复杂任务编排继续留待后续版本。
- Vite 大 chunk 警告为既有非阻断问题，本版未扩大范围处理。

## 八、偏差与验收结论

- 功能范围无未说明缩减。实现过程中删除了不必要的关联状态、revision 字段和压缩 UI 实体，遵循
  “如无必要勿增实体”原则，以现有 Session、Input、Run、Conversation 和 generation replacement
  完成闭环。
- M7 回归修复了 Harness 对有效截断摘要的旧断言，以及斜杠菜单陈旧 effect 在并行负载下关闭新
  弹层的竞态；两项修复均通过全量门禁。
- 是否达到版本完成门槛：是。
- 用户验收结论：通过；用户于 2026-08-26 明确要求归档。
