# v0.30.0 版本总结

2026-10-13 用户审阅验收条件后确认“可以验收了，把文档整理干净”。版本状态为 **已完成**，按 F01 实际交付与已有验证结果收口；不补写未执行的逐项实测或全量复跑。本版未公开发布。2026-10-13 用户再次要求归档验收，并明确将 Goal 超限恢复修正合并到 v0.30.0，不单列 v0.30.1 归档；以下按最终交付更新。

## 完成范围

- 模型配置选择本地摘要或服务端原生压缩，自动/手动统一机制、串行提交，不跨机制回退。本版由 Agent 按 90% 阈值或模型超限触发，手动不受比例限制。
- 本地轮内回收已闭合工具交互，保留用户原文、近期交换与必要记忆，支持连续压缩后续跑。
- 本体统一 HTTP compact；企业中心转发 API 上游或转换订阅 WS V2，完整保存和回放返回窗口，可靠提交、费用去重、重启/旧 ID 失效重建及后续增量续接贯通。
- 原始历史与有效上下文分开。新操作接纳最新模型参数；模型、入口或临时绑定变化保留最近有效窗口，临时 ID 独立校验。Agent 文本摘要通过原有 message item 复用。
- 窗口占用与累计消耗分开，计量不可用时沿用 usage 与增量估算，展示“约/待校准”，等待正常响应校准；父子上下文独立。
- 修复历史会话输入排队/内部状态故障、固定压缩总时限、带图完整窗口大小门槛、旧 MCP 刷新结果 deferred 加载，以及读取失败被加载页遮挡的问题。
- Goal 累计 token 仅统计，不再作为停止条件；运行次数、连续失败保护及旧暂停目标显式恢复保持。修复累计运行次数超过上限时恢复校验误判损坏、阻止整个会话读取的问题，保留原统计和暂停状态。Windows/Web 导航靠左，Web 增加 Logo。

原 F02 Computer Use 已移出本版，独立分支 `codex/f02-computer-use` 继续开发，目标版本与回并时间待定。本版不携带其专用协议、随包 MCP、Driver 或预览，也不等待该分支验收。

设计、契约及验收结果分别见[总体设计](总体设计.md)、[F01 功能设计](features/F01-上下文管理与压缩优化/功能设计.md)、[技术方案](features/F01-上下文管理与压缩优化/技术方案.md)和[开发计划](features/F01-上下文管理与压缩优化/开发计划.md)。

## 验证与内部交付

M0 先通过真实接口核实协议，再进入产品开发。后续定向回归、协议导出、静态检查、应用构建、隔离 Host/Center 及正式企业链路已执行，覆盖连续压缩、工具/图片回放、取消、可靠恢复、费用分类和历史读取。真实验证的原生路径为本体 HTTP → 企业中心 → 订阅 WS V2；旧会话加载问题使用隔离历史副本通过正式 Host 复现并验证修复。

修正版企业中心已部署并完成健康、协议、管理页面与配置保留核验；macOS arm64 内部包已完成 Developer ID 签名、Hardened Runtime、镜像内容及随包 Host 核验。安装后的本机 Runtime 与最新候选一致，原问题会话已重新执行。上述事实不替代未逐项执行的其他场景证明。

Goal 超限修正通过恢复、投影、存储往返及运行次数门禁回归；真实历史隔离副本经正式 Runtime 完成会话视图与分页读取，原历史内容保持一致。相关静态检查、协议导出和 Desktop 构建通过。最新 macOS arm64 内部修复包实际软件版本为 0.30.1，签名、镜像、版本及随包 Host 内容核验完成；应用最低兼容版本和存储准入仍为 0.30.0，企业协议为 3，无需新增数据迁移或企业中心重新部署。修正按用户要求并入本版归档，不构成独立版本台账。

本次归档仅整理文档、链接和已停用的本版隔离测试环境，未重新运行产品测试，未修改产品代码、生产配置或运行数据；未提交、推送、重新部署或公开发布。

## 保留限制与后续

- 普通生成请求内的服务端自行触发自动压缩本版不开放；服务端压缩机制与自动触发方是两个配置概念。
- 当前真实路由不支持输入计量接口，估算和正常响应校准为已确认行为。其他 API/账号、状态排列及任意图片规模不默认支持。
- 全工作区合跑存在 Rustls 双加密 Provider 冲突，相关套件分开执行通过；最后修复后未重新完成整版全量回归，不宣称全量合跑全绿。
- Windows 本轮实机及 Client 各平台分发/安装组合未完整复验，后续公开发布前按实际目标补核，不补写为已通过。
- macOS 内部包已签名、未公证；Apple 团队协议问题仍须处理。用户取消本次自动升级测试，前版 macOS 升级补验继续暂缓。
- 上游 WebSocket 心跳超时仍是独立风险；移除专用窗口门槛不保证消除网络或上游故障。必要输入超窗、无进展和协议不相容仍有界失败。

后续事项见[版本管理](../../版本管理.md#后续能力地图)。下一版暂定 v0.31.0，总体设计草案待确认；验收归档与公开发布分别处理。
