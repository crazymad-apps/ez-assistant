# v0.15.0 版本总结：记忆与长期助手

## 一、版本结论

`v0.15.0` 于 2026-08-18 完成开发、验证、用户验收与归档。本版本把 `v0.5.0` 的候选记忆契约
正式装配到 Runtime、应用协议和 Desktop，形成 Persona、Pinned Memory、冻结 System Context、
Workspace 根 `AGENTS.md`、Conversation Recall 与历史来源导航的产品闭环。

## 二、主要交付

1. **长期偏好与显式记忆**：Runtime 持有单份全局 Persona 和 Pinned Memory 权威状态，提供
   CAS 管理、正式 Agent 工具、权限审批、审计及 Desktop 设置闭环；Pinned Memory attributes
   保持为 Runtime 业务字段，不由 Agent 重复结构化正文。
2. **冻结 System Context**：新建 Session 一次装配 Persona、Pinned Memory、Runtime 目录信息和
   Workspace 根 `AGENTS.md`，持久化最终原文；恢复、压缩、Fork 和子 Agent 不被后续全局修改
   静默改写，Desktop 可用 Markdown 或原文模式只读查看。
3. **Conversation Recall**：Conversation JSONL 继续作为正文权威，SQLite FTS5 只承担可重建的
   派生索引；Agent 可按 `session`、`workspace`、`global` scope 搜索并使用签名引用有界续读，
   全程复用既有工具、权限、审批和可靠 Tool Exchange。
4. **搜索与来源导航**：Desktop 支持历史会话搜索、只读预览、来源消息定位及内存式后退/前进栈；
   Recall 工具详情使用结构化结果，并通过 Runtime 校验后的导航目标进入来源会话。
5. **恢复与性能**：完成 `v0.14.2` 数据的增量迁移回归、损坏 Conversation 启动恢复、索引懒重建、
   Provider 工具 Schema 方言降级和可复现的本机性能基线。

## 三、验证结论

- `cargo fmt --all --check`、workspace Clippy 与 workspace 全量测试通过；
- Desktop lint、19 个 Vitest 文件共 88 项测试、生产构建及 1 项正式临时 Runtime Host
  Playwright 场景通过；
- Tauri `--no-bundle` 构建通过；
- 隔离真实 Provider 的 Pinned Memory + Global Recall 最小闭环 1 项通过，耗时 7.86 秒；
- release 性能基线使用 24 个 Session、每个 12 轮、共 576 条消息：Runtime 启动 14.858 ms，
  首次 Session 搜索 3.265 ms，增量一轮提交 11.941 ms，100 次批量搜索平均 1.359 ms；
- 用户于 2026-08-18 确认产品行为与版本边界可以验收归档。

## 四、明确边界与偏差

- Recall 首版是本地词法正文检索，不包含 Embedding、向量数据库和语义排序；
- `AGENTS.md` 只读取 Workspace 根目录，不做运行期子目录级发现；
- Session 创建后 Workspace 不可重绑定，切换目录通过新建 Session；
- UI History 只存在于 Desktop 内存，不属于 Runtime 权威状态，也不持久化；
- Windows 只保留兼容口，未进行严肃开发与正式验收；
- 真实 Provider 和手工性能用例继续保持 `ignored`，仅由显式验收命令在隔离环境执行。
