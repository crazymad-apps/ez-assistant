### M5：真实本地文件 Adapter 与 ripgrep 搜索

- 目标：在 `agent-tools-local` 实现可取消、边界明确的真实文本文件能力，并将名称和
  内容搜索委托系统 `rg`。
- 状态：✅ 已完成
- 实际结果：
  - `LocalFileSystemConfig` 与 `LocalFileSystem` 已实现，真实 read/list/write/edit/delete
    全部使用 M4 冻结的绝对逻辑路径，不重新解析 workdir 或加入授权规则；
  - read 严格限制 UTF-8、NUL、文件类型和最大字节数，支持 BOM、显式分页及
    `next_offset`；list 按稳定绝对路径排序，并正交返回目标 kind 与 symlink 标记；
  - write/edit 正常跟随 symlink，edit 保留 BOM，分别处理纯 LF、纯 CRLF 和 mixed
    换行，并在写前复核源字节；delete 只删除文件、symlink 或空目录，不递归删除；
  - 新增按逻辑路径共享的 mutation lock，同一 Adapter 实例内的 write/edit/delete
    对同一路径串行，等待锁后再次检查取消；
  - 按技术方案补齐 `FileToolError::ConcurrentModification`，用于 edit 写前复核失败；
  - find/search 只通过 program + args 直接启动 `rg --no-config`，名称结果使用 NUL
    协议，内容结果解析 JSON；不传 hidden/no-ignore/follow，不自行递归遍历；
  - 搜索支持结果上限与 truncated、非文本 JSON 跳过、exit 0/1、后端缺失、解析失败、
    运行中取消和清理；Unix 使用独立进程组、Windows 使用 Job Object，均带
    kill-on-drop 兜底，终止后显式 wait；
  - 全部常规文件测试只使用 `tempfile`，没有读取用户真实项目，也没有递归删除。
