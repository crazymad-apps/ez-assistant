# v0.21.0 版本总结

## 版本结论

`v0.21.0` 已完成多终端 Gateway、智能终端安全接入、Host 语音识别与播报、PC 输出托管、
Node/H5 模拟终端以及统一 Session 输入和同 Run 多 Loop 编排闭环。用户于 2026-09-01 确认
验收并要求正式发布，版本文档据此归档。

## 实际完成

- Runtime Host 增加受控子系统生命周期、mDNS、WSS、候选配对、六位配对码、SPAKE2、
  Ed25519 长期设备身份、能力协商、重连、撤销和有界背压；设备临时连接状态仍归 Host，
  注册、来源、Conversation、托管和投递事实仍归 Runtime/Store。
- Desktop 与可信 Channel 统一进入 Session 输入；所有显式输入和最终 Assistant Output 只保存于
  既有 Conversation。Desktop 始终展示完整正文，智能终端和未来渠道作为零到多个附加投递目标。
- Desktop 提供设备配对、详情、重命名、解除配对和输入框内唯一频道托管入口；设备来源标签保持
  低干扰并可查看详情。
- Host SpeechService 通过平行 ASR/TTS SPI 接入 DashScope；正式设备协议支持 PCM16/16 kHz/mono、
  连续输入聚合、分段确认、跨 WSS 去重、多段 `speak` FIFO、播放取消与 PTT 抢占。
- Node 24/H5 模拟终端覆盖文字、浏览器录音、播放、协议监控、能力形态和故障注入；项目已与
  `agent-robot` ESP32-S3 正式终端完成 S3.1 联调。
- Code Review 阶段增加附件 E/M9：Goal 自动推进、压缩和缺失播报统一进入同一产品 Run 的
  AgentExecution 门禁，不再建立后继 Input、Run、Queue 或 continuation 表。

## 验证结论

- Rust workspace `fmt --check`、全 targets/features Clippy `-D warnings` 和全量测试通过；Runtime
  248 项、Host 183 项默认单测通过，正式 Host 离线集成测试通过。
- Desktop lint、22 个文件 143 项测试、协议生成物检查、生产构建、正式 Host Playwright 与 Tauri
  release `build --no-bundle` 通过。
- Node 24.19.0 下模拟器 lint、typecheck、9 个文件 37 项测试、生产构建、H5 Playwright 与正式
  M8 E2E 通过；连续语音只提交一次 Runtime Input，跨 WSS 重传去重和 PTT 抢占均有跨层证据。
- Release 默认不保存调试音频的定向回归通过；Desktop 与模拟器 npm audit 均为 0 vulnerabilities。
- device protocol 1.0 三份跨语言 fixture 未漂移，`agent-robot` compatibility manifest 已按最终
  工作树和 Release Host 反向核验。

完整命令、环境、故障矩阵和人工证据见[验收记录](验收记录.md)。

## 偏差与遗留

- 原计划 M0—M8 后增加 M9，目的是删除开发期形成的平行输入与后继 Run 管道；最终实现比原方案
  更简洁，没有改变冻结的 device protocol 1.0。
- 语音 Provider 继续使用 Runtime Home 最小配置；Desktop 不提供 Provider、模型、音色或密钥编辑。
- Vite 仍有部分大 chunk 非阻断警告；大量图片与上下文 I/O 的耗时专项测试及优化留待后续版本。
- 正式 DashScope 已由用户在开发阶段验证，归档验收未重复发起可能产生费用的请求。
- macOS arm64 Developer ID 正式发布已通过 App 与 DMG 两次 Apple 公证及独立挂载验证；DMG
  SHA-256 为 `7346533a5ada18aa10db003354d075f29216ba4fdfe6a313266e76ec259450fe`。
- 源码提交、Git tag 与远端推送不属于本次发布授权，均未执行；完整产物与公证证据见验收记录。
