## 三、形成的核心能力

- SQLite 保存 Session、Input、Run、关联和派生状态；每 Session generation JSONL 保存唯一规范
  Conversation，消息顺序由文件位置表达，不建立 Message/Part 正文关系表。
- Runtime 成为持久会话与执行的唯一业务所有者；Host Store 只实现基础设施端口，Protocol 不暴露
  SQLite 表、文件路径、generation 或 staged/pending 细节。
- 用户输入可靠落账后才唤醒执行；同一幂等 key 返回首次 Input/Run，同 Session 按接收顺序串行，
  不同 Session 可并发。
- 重启不自动续跑：排队输入等待显式 Resume，非终态 Run 收敛为 interrupted，Retry 创建新 attempt
  且不重复 User Message。
- 工具执行前保存短生命周期 pending 事实；完整 Tool Call/Result 批次进入正文后清空，崩溃恢复
  不自动重放副作用，也不产生孤立或部分 Tool Result。
- Session 可严格归档并恢复，只读历史始终保留；空闲时可切换 model key；历史重新输入通过新
  generation 销毁目标及尾段，不建立隐式分支或通用 undo。
- Core execution observer、RuntimeTasks、Store worker 和 Host connection owner 分层观察本层任务，
  panic/JoinError、取消和有界关闭均形成稳定结果。

## 四、偏差与边界

- 实现未偏离已确认功能范围；Review 中补齐的 panic/JoinError、fail-closed 和有界关闭属于第 13
  条验收标准，不是额外产品能力。
- M5 将手写 raw HTTP fake 替换为 Axum loopback 测试夹具，以消除连接竞态；Axum 仅为 Host
  dev-dependency，不进入产品运行依赖。
- 本版本没有正式桌面会话页面；Ratatui Demo 仍是私有验证客户端，不构成产品协议或 UI 契约。
- 未实测真实 Provider、Linux 或 Windows；备份、导入导出、通用 schema migration、完整性治理、
  持久事件重放、任意消息编辑、分支和 undo 均不属于本版本。
- `v0.9.0` 及以前没有正式持久化 Session 数据，因此本版本不迁移旧会话；既有配置继续由配置兼容
  层处理。
