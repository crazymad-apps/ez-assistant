# v0.33.2 模型模板维护

- 来源：2026-11-18 用户要求为静态模板添加 OpenAI 6.2 系列参数。
- 范围：当前版本的独立模板维护，不启动后台运行管理或定时任务的实现，不调整软件版本及兼容下限。

复用 [共享静态模板](../../../packages/assistant-protocol/resources/model-templates.json) 和现有协议覆盖机制，增加 `gpt-6.2-astra`、`gpt-6.2-sol`。Runtime 编译时内嵌，企业中心构建时复制；查找继续按服务商类型与原始模型 ID 精确匹配，只补在线未知参数，不覆盖用户固定配置。

两款模型均配置 1,050,000 上下文、922,000 最大输入、128,000 最大输出，支持图像输入和流式输出，必须开启推理。沿用项目标准推理档位 `low`、`medium`、`high`、`xhigh`、`max`，按官方迁移建议将模板默认值设为 `medium`。未单独公布的推理模式输入／输出上限保持未知。Responses 支持工具调用和原生工具图片结果；Chat Completions 覆盖为不支持工具调用及工具图片结果。

参数依据：[Astra](https://developers.openai.com/api/docs/models/gpt-6.2-astra)、[Sol](https://developers.openai.com/api/docs/models/gpt-6.2-sol)、[迁移说明](https://developers.openai.com/api/docs/guides/latest-model#update-api-and-model-parameters)、[推理参数](https://developers.openai.com/api/docs/guides/reasoning#reasoning-effort)。核对日期为 2026-11-18。
