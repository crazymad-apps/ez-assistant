# v0.33.2 版本总结

2026-11-23 完成验收归档，同日通过企业中心发布 macOS arm64 和 Windows x64 客户端。

## 交付范围

- **后台运行管理。** Shell 可显式启动后台命令，单轮会话结束后仍可查看输出或停止。右侧「当前上下文」只显示活动进程，退出后自动清理条目及临时日志。运行记录、技能、子任务、附件和产物支持分页。[F01 验收结论](features/F01-后台运行管理/开发计划.md#三feature-验收与完成结论)
- **定时任务。** Agent 型在独立临时会话中完成任务，脚本型直接执行 Shell 命令。两者均支持一次、每日、每周调度，结果可从执行记录回查，也可交由主控会话汇报。删除计划会停止活动执行并清理历史，已送达主控的文件仍可打开。[F02 验收结论](features/F02-定时任务与自动化/开发计划.md#三feature-验收与完成结论)
- 共享模型模板新增 GPT-6.2 Astra 与 Sol 的静态参数及协议能力声明。[模型模板维护](模型模板维护.md)

## 联合验收

同一计划连续三次到点，依次验证了后台命令跨 Agent 回合继续运行、重叠周期跳过，以及手动停止后下个周期恢复。重启正式 Host 后，三次执行记录与重启前一致。设备及用户隔离、迁移和旧客户端拒绝已覆盖。[版本开发计划](开发计划.md#三版本验收与发布门禁)

## 2026-11-23 正式发布补记

- macOS 正式包通过签名、公证和 Gatekeeper 检查。使用正式更新包在隔离目录将 0.33.1 替换为 0.33.2，随包 Host 启动并回报正确版本。
- Windows 使用最终 MSI 提取的客户端和 Host，在原生界面新建脚本计划并立即执行。执行记录显示退出码 0，标准输出与脚本一致。Windows MSI 有客户端更新签名，无 Authenticode 签名。
- 按用户确认的验收范围，两端保留现有系统安装，本轮跳过系统安装和原地升级。客户端和 Host 需配套升级，应用与存储的最低兼容版本均为 0.33.2。[用户更新日志](../../site/changelog/v0.33.2.md)
- 企业中心已发布两个平台的安装包，并同步手册和模型模板。模型目录补齐六项，与随包的 48 项一致。本次发布无需中心数据库迁移或服务重启。
- 从公网下载的文件与发布清单逐一比对，哈希和两平台更新签名均通过。0.33.1 可发现新版本，0.33.2 的检查返回无更新。官网手册与更新日志均已回读核对。

下一版本待规划。子任务后台运行、异常退出后追踪未登记的后代进程和设备离线补跑均未纳入本版。[总体设计](总体设计.md#四不纳入范围)
