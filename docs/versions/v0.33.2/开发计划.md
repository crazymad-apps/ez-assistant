## 三、版本验收与发布门禁

2026-11-23 用户确认本版本收尾，F01、F02 及版本联合验收通过。

- 在隔离的正式 Runtime Host 上，对同一 Agent 计划连续设置三个到期时间。首次到点启动后台命令，Agent 回合结束后进程继续运行。第二次到点记录跳过，原进程仍在。手动停止首次执行后，第三次到点正常启动并完成交付文件归档。Host 重启后，三次记录及状态一致。
- 定时脚本、Agent 结果交付、删除回收、错过时点及设备隔离已通过正式 Host 回归。结合两个 Feature 验收，覆盖企业用户隔离、旧端拒绝及用户库迁移。
- 发布前仍需验证最终候选包在 macOS 和 Windows 上的安装与升级，以及 Windows 原生定时任务界面。此前交付的 macOS 测试包早于模型菜单 Esc 焦点修复，该修复已在 Host Web 和 macOS WKWebView 复验。

归档结果见[版本总结](版本总结.md)。
