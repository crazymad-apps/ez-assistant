# F01 功能设计：后台运行管理

- 版本：v0.33.2；更新：2026-11-18；状态：已确认。确认记录见[版本台账](../../开发计划.md#二feature-台账)。
- 依据：[总体设计](../../总体设计.md)、[原始问题](../../../../inputs/260826-shell后台进程存活机制调研.md)。影响 Shell、Runtime、应用协议及 Desktop／Host Web 右栏。

## 一、目标与范围

Shell 工具返回后，长命令或服务继续运行，Agent 和用户能查询、查看输出及停止。复用现有 Shell、Runtime 和右栏，不建设独立任务中心。

本版支持主会话后台运行；子任务仅允许 `managed`，拒绝后台及脱管模式，不装配后台管理工具。子任务目录随任务结束释放的问题留待后续处理。

## 二、Agent 操作

通过 Shell 的显式后台模式启动，短暂等待后返回后台标识、状态、临时日志路径和限量输出；期间已结束则直接返回退出结果与限量输出，并清理条目和日志。等待时长与命令运行时限分开，等待结束不杀进程；启动成功不代表服务就绪。

新增三个工具：

| 工具 | 作用 |
| --- | --- |
| `list_background_runs` | 分页查询状态、找回标识和日志路径，也可按已知标识查询。主要兜底上下文压缩造成的信息丢失，读取输出前无需先查询列表。 |
| `read_background_output` | 按后台标识、指针、相对偏移和字符上限读取输出；返回下一指针及已丢失字符数。未给指针时读取最近一页，续读直接使用返回的指针。 |
| `stop_background_run` | 停止该运行当前可管理的进程组／Job Object，返回真实结果并清理；已移除的标识返回不存在或已清理，失败保留重试入口。 |

输出读取始终按字符限量，超长单行也不能绕过上限。日志超限丢弃最旧内容，保留内容的逻辑字符编号不变；旧指针已被淘汰时从现存起点读取，并明确提示缺失。Runtime 处理滚动和定位，Agent 不需要读取索引文件或换算日志分段。

Shell 预览与输出工具返回同类指针，详情见[技术方案](技术方案.md#三工具与输出契约)。

后台标识区别于 Run ID 和系统 PID。工具只管理当前用户、当前主会话的登记项，归属由 Runtime 绑定；调用结果未知先回查，不通过新调用重复启动。

## 三、右栏与分页

在“当前上下文”增加“后台运行”区块：

- 列表只保留未结束任务，展示命令简述、来源 Run、状态和时长；点击任务打开输出弹窗，显示完整命令、目录及输出，不在列表中展开。
- 后台行沿用运行记录的状态点、两行文字、行间距和底色。左侧显示命令与运行信息，右侧是独立的“停止”按钮。整行共用 hover／键盘聚焦底色。点击命令打开输出，点击“停止”执行停止。
- 运行中可“停止”；任何方式结束后自动移除条目并清理日志，不保留终态列表或“关闭”条目操作。停止／进程清理未确认时保留条目和重试入口。
- 弹窗内只保留可滚动的输出区域，打开时显示最近内容并定位底部；上滚接近顶部自动懒加载更早内容，补入后保持原阅读位置，不设手动翻页或“回到最新”入口。上翻暂停跟随，滚回底部恢复跟随新输出；加载中、读取失败及滚动丢失在输出区内提示。关闭弹窗仅停止读取；任务结束则自动关闭弹窗并提示结束，列表同步移除。

后台运行、运行记录、技能、子任务、附件和产物按页加载，各区块独立翻页。后台运行仅列未结束项，子任务优先待处理／活动项，技能优先已激活项，运行记录最新在前，其他沿用现有顺序。刷新保留当前页，删除后页码越界则退到最后有效页；失败保留已有内容，切换会话丢弃旧响应。

扩展已有列表接口；分页单列实施里程碑。页外审批、介入、消息定位及完整技能装配继续使用各自权威数据，不以当前页判断对象是否存在。页大小等建议值统一见技术方案。

## 四、生命周期与清理

| 场景 | 行为 |
| --- | --- |
| 工具返回、Run 结束／停止／介入、会话编辑／清空 | 已交接的后台进程继续运行；交接前取消仍清理。 |
| 关闭页面、客户端断开／崩溃，或仅退出客户端并选择保留后台 | Runtime 仍运行时，后台任务继续；重连可查询。 |
| 手动停止或命令自然结束 | 收敛当前可管理后代及输出，确认后立即移除运行条目并删除日志；失败不虚报已停止。 |
| 进程被应用外终止，包括 Agent 通过 Shell 执行 `kill` | 自动识别退出并收尾，移除条目、释放活动名额并立即清理日志；无需用户或 Agent 查询、再次停止。进程清理未确认则保留错误和重试依据。 |
| 删除会话或移除工作区 | 有活动后台运行时提示先停止，再重试。 |
| 注销、身份失效、正常停止／重启 Runtime | 拒绝新启动，终止受管进程并等待回收，再退出；失败或超时明确报告。默认退出流程若停止 Runtime，也适用此规则。 |
| Runtime 崩溃／强杀后重新启动 | 仅核对旧登记的主 PID、所属用户和创建时间；匹配则终止并复查，不恢复任务、不追踪残留后代。不存在或身份不符时清理本程序的旧记录和日志，不操作其他进程。查询／停止失败则保留清理依据供重试。 |

不论自然结束、停止、异常退出或外部终止，确认任务结束后都立即清理运行条目及临时日志，不设置结束后的读取保留期。仅日志删除失败时保留必要清理依据供重试，不让已结束任务继续占用活动列表。Host 异常退出后的启动补清仍先核实进程结果；进程清理未确认时保留有界日志和身份记录。进程名只辅助诊断，不作为强制匹配条件。

活动运行不得静默淘汰，运行期间日志有容量上限。临时日志不登记为产物；已返回的工具结果沿会话历史保存，任务清理后后台标识与日志路径不再可用。

不承诺异常退出时立即回收或找全所有后代，不新增守护、全局进程扫描、跨重启接管、自动保活、stdin／PTY 或完成后自动唤醒模型。

## 五、职责与验收

Runtime 持有归属、状态和监督任务，本地 Adapter 管理进程及滚动日志；UI 与 Agent 共用查询、读取和停止能力。F01 向 F02 提供关联标识、活动状态及退出结果，不实现定时调度，不新增执行数据库或永久日志仓库。

1. 工具返回及 Run 结束后进程继续；等待到期不误杀，交接前取消不遗留已知进程。子任务后台／脱管请求被拒绝。
2. 输出按字符限量；覆盖 Unicode、超长单行、追加、滚动、旧指针缺失和末尾续读。Shell 返回的指针能直接续读。
3. 压缩后可由列表找回同一运行并停止；重试不重复启动，权限和归属隔离有效，右栏与工具状态一致。外部终止后无需查询即自动更新状态并清理，与停止请求并发时不重复结算。
4. 各列表真正按页请求；刷新、失败、切换会话正确，页外介入／审批／定位及技能装配不回退。
5. 正常停止 Runtime 实际回收，选择保留后台不误停；重启仅清理身份匹配的登记主进程，覆盖 PID 消失／复用、改名、查询／停止失败。
6. 任意方式结束后条目和日志立即清理，列表自动移除、已打开的输出弹窗自动关闭并提示；仅关闭弹窗不停止进程。删除日志失败保留清理依据，启动补清不误删活动日志，清理后的查询不虚报退出结果。
7. 后台列表按确认页大小加载，整行 hover／键盘聚焦包含停止按钮；输出弹窗上滚自动加载更早内容并保持阅读位置，离开底部暂停跟随、回到底部恢复，不保留手动输出翻页入口。
