## 三、Feature 验收与完成结论

四个里程碑均获确认后，逐项核对[功能验收 1～7](功能设计.md#五职责与验收)，并验证总体设计中的后台管理、生命周期及分页边界。

联合场景：后台启动 → 工具／Run 结束 → 列表找回并追读 → 外部终止或手动停止 → 条目、弹窗与日志自动清理；另覆盖客户端断开重连、正常停止 Runtime、异常重启补清和分页后的页外操作。正式 Host、Desktop／Host Web、个人／企业归属及适用平台按技术方案收口，F02 调度联合场景留在版本验收。

- 2026-11-19 完成 F01 验收验证，用户确认结项。
- 正式 Host 验证了后台交接、审批与子任务权限、压缩后找回及字符分页。Runtime 与原生 Adapter 回归覆盖并发停止、外部退出和滚动日志。macOS 原生 WKWebView 验证关闭弹窗、重连和停止，Desktop 原生停止与重启回归通过。正常关闭和异常重启补清已核对进程及日志，Windows 和 Linux 的原生进程回收也已复核。
- 正式 Host Web 验证六类列表分页、失败重试、跨会话旧响应丢弃、页外定位及输出跟随。验证了 0.33.1 客户端版本拒绝、Windows 客户端直连 macOS Host、隔离企业账号间的访问控制和注销回收。
- Web 登录回归已按工作台和账号入口修正断言，Chromium 与 WebKit 均通过。正式发布的 0.33.1 Web 资源连接新版 Host 时收到版本过旧提示，刷新加载新版资源后可正常登录。
- 正式企业中心和两个正式 Host 在本机隔离环境完成设备网关联验。经中心中转的列表分页、Unicode 输出分页、启动和停止事件、同组织用户隔离及目标日志回收均通过。
- 向 F02 交付：后台标识与归属、活动状态、退出结果及停止能力；不要求 F01 保留终态列表或永久日志。
