## 三、Feature 验收与完成结论

全部里程碑确认后，在项目 `.runtime-test/` 下新建独立 Runtime Home，使用正式 Host 与客户端逐项核对[功能验收 1～7](功能设计.md#五验收)，覆盖以下两条完整路径。

- 脚本按时执行 → 回读原始输出和退出状态 → 关闭汇报时仅留执行记录。
- Agent 生成日报 → 等待后台写完文件 → 主控收到当次汇报和附件 → 清理任务会话 → 删除计划后仍可从主控打开附件。

- **2026-11-23 通过 F02 验收。** 用户试用 macOS 测试包后回复「好像没啥问题了，验收」，M0 至 M4 均已确认。
- 隔离正式 Host 验证设备本地时间规则、无人值守触发、错过跳过、并发防重叠、权限失败、取消回收和重启恢复。企业夹具验证不同用户间的计划及执行隔离。升级保留既有计划和记录，交付回执去重，删除计划后仍可访问已送达主控的文件。
- Host Web 验证界面修改、聊天审批、执行分页、主控整理及原文折叠。模型菜单按 Esc 关闭时的焦点恢复已修正，Host Web 和 macOS WKWebView 定向复测通过。
- F01 与 F02 的完整跨周期联合场景、版本候选包的升级和平台覆盖列入[版本验收](../../开发计划.md#三版本验收与发布门禁)。
