# F02 界面交互设计指导 · 定时任务与自动化

v0.33.2 · 2026-11-19 · **方案已确认**

用浏览器打开[交互原型](交互原型.html)，可切换 Agent 型和脚本型，试用计划编辑、立即执行、结果汇报与删除。原型使用示例数据模拟执行。

## 入口与列表

左侧「助理会话」旁提供「定时任务」入口。沿用侧栏设备选择，每行展示计划名、类型、时间规则、启停状态和下次执行时间。两类计划共用列表。

点击计划进入二级详情页，从顶部导航返回计划列表。编辑页的顶部返回键回到详情。列表、详情和编辑页与会话正文共用页边距和最大宽度。详情沿用编辑页的字段排列，以只读方式展示配置，任务指令渲染为 Markdown，Shell 命令按代码显示。任务操作位于配置上方，删除需经确认。暂停时仍可立即执行一次，执行后仍显示「已暂停」。

## 创建与编辑

创建时先选「Agent 型」或「脚本型」。Agent 型填写任务指令，选择智能体、模型和工具权限模式。脚本型填写可多行输入的 Shell 命令，例如 `python scripts/report.py`。切换为脚本型时，表单收起智能体、模型和权限模式。保存时只提交脚本和公共配置，再次编辑也直接显示脚本表单。

两类共用名称、项目（可选）和执行时间。支持一次、每日、每周多选，按执行设备本地时间预览下一次触发，界面省略时区。表单提供「将执行结果返回主控会话」，新建时默认开启，关闭后在本计划的执行记录查看所有结果。保存后的变更从下一次执行生效。

一次性计划使用主题化中文日历，周一为首列，可用方向键选日。翻月时日历保持展开，选定日期后收起。各频率共用 24 小时时间字段，可直接输入 `HH:mm`，也可从浮层分列选择小时和分钟。执行设备仍负责按接收的 `YYYY-MM-DD` 和 `HH:mm` 计算触发时间。

## 一次执行

执行记录倒序分页。点开一行时在该行下显示结果，同时收起上一条。再次点同一行可收起结果，翻页时收起当前记录。「立即执行」自动展开本次记录。

| 看到的状态 | 用户可以做什么 |
| --- | --- |
| 运行中 | 打开本次执行查看进度，或停止本次执行。 |
| 已完成、执行失败、已停止 | Agent 型显示任务会话撰写的汇报、声明文件或失败原因。脚本型分列标准输出、标准错误及退出状态，空输出和截断有明确提示。 |
| Agent 已完成 · 后台仍运行 | 查看关联进程，沿用 F01 的输出弹窗和停止操作。最后一个进程收尾后再展示执行结果和交付状态。 |
| 已跳过 | 在记录中看原因。手动触发遇到冲突则直接提供「查看进行中的执行」，不新增一条手动记录。 |
| 保存或投递失败 | 显示失败原因。重试只补结果保存或已开启的投递。 |
| 结果去向 | 开启且投递成功时显示「前往助理会话」。关闭时显示「仅保存在执行记录」，可直接查看正文和已保存的文件。 |

一次性计划错过时间后显示「已错过」。切换设备或连接失败时，用设备名和错误原因提示当前范围。写请求结果未知时先刷新核对，再开放相应操作。

主控整理后的正文以正常助理回复展示。定时任务来源显示一行任务名和状态，展开后以 Markdown 展示原始汇报。附件区顶部用细线与前文分开，四边留白一致，收起时也可直接下载。受控会话汇报同样默认折叠，展开后以 Markdown 展示。

## 删除计划

确认框说明将清除全部执行记录、仅保存在记录中的文件及计划专属空间。已送达助理会话的消息和文件仍可打开。有活动执行时说明会立即停止当前脚本，或 Agent 及其关联后台进程。默认焦点在「取消」，Esc 返回详情。

确认后禁用重复操作。Runtime 确认停止并清理成功后返回列表，移除计划及全部历史；停止失败时保留详情，显示原因和重试入口。助理会话里的消息直接打开已交付文件，避免留下指向已删除执行的链接。

功能边界见[功能设计](功能设计.md)，删除与交付并发时的归属见[技术方案](技术方案.md#四删除与交付同时发生)。
