## 升级停止修复

Linux 私库验收暴露的问题已修复：新 Client 停止不兼容旧 Host 时，仅对固定 `shutdown_runtime` 复用运行中 Host 自身的有效兼容声明。普通业务命令仍拒绝不兼容 Host；无效声明在写请求前拒绝，原地址、实例、凭据、单次写、回执与停止后核验均保留。

家庭私库 `@ez-assistant/client@0.25.3-1` 及未变更的 `@ez-assistant/client-linux-x64@0.25.3` 在隔离容器完成真实 registry 升级闭环；用户随后在 Linux 实机确认无问题。验证通过后，以正常软件版本 `0.25.3` 装配并发布官方主包和三个平台附件；官方 `next`、`latest` 均已提升并回读为 `0.25.3`。家庭私库标签保持原有边界，不用私库修订号代替官方版本。

## 接受的限制

- MSI 未签名，Windows 可显示 SmartScreen／未知发布者提示。
- WebView2 Runtime 为必需项；缺失时安装器需联网获取。
- 本版不发布 Windows Client/npm 包，不提供 Windows 自启、系统级安装或 Credential Manager 远程密码保存。
- 上述未单独留存日志的组合以用户本轮整体手工验收为收口，不作为细分回归证据复用。
