# v0.25.3 版本总结

当前状态：已完成。2026-09-14 用户确认 Windows 两架构最终包已手工验证，Linux 升级停止修复验证无问题，并授权归档、提交和发版。详细证据与限制见[验收记录](验收记录.md)。

## 实际交付

- macOS Apple Silicon Desktop：Developer ID 签名并经 Apple 公证的 arm64 DMG，内含同版本 Runtime Host 与 Web；公证票据、Gatekeeper、DMG 完整性和挂载内容验证通过。
- Windows Desktop 首版：x64 支持 Windows 10 1809+，arm64 支持 Windows 11 ARM；当前用户 MSI 内含同架构 Runtime Host 与 Web。
- Host Windows 平台层：Runtime Home/ACL、单实例、discovery、原子写、路径与 reparse point 防护、文件打开、进程来源与安全退出。
- Windows 交互终端：ConPTY、PowerShell 5.1/CMD/pwsh/Git Bash 目录、类型切换、UTF-8/Ctrl+C/resize 及 Job Object 进程树回收。
- Agent Shell：全局默认、Session 持久绑定、FIFO 切换／刷新、Run 环境冻结、Fork/Clear/归档恢复，并保证模型上下文与真实 launcher 一致。
- MCP stdio Windows 启动与清理、外部依赖诊断、Desktop Windows 自绘标题栏、图标、托盘与生命周期适配。
- 可重复的 Windows x64／arm64 发布脚本，校验 PE 架构、GUI 子系统、静态 CRT、Host Web、MSI 范围／版本与 SHA-256。
- Client 升级停止修复：新 Client 在普通业务命令仍拒绝不兼容旧 Host 的同时，仍能固定原实例受控停止它。家庭私库先用 `@ez-assistant/client@0.25.3-1` 验收，随后正式发布官方 `@ez-assistant/client@0.25.3` 及 macOS arm64、Linux arm64、Linux x64 三个平台附件；四包的 `next`、`latest` 均为 `0.25.3`。

## 验证与限制

macOS 上 Rust fmt/clippy/workspace tests、Desktop 55 文件 439 项、Client 24 项、生产前端构建与 Tauri release `--no-bundle` 均通过；最终 arm64 DMG 的 Developer ID、Apple 公证、Gatekeeper、完整性、挂载内容和 GitHub 回下载复核通过。Linux x64 完成家庭私库真实 `0.25.2 → 0.25.3-1` 升级停止闭环，用户实机复测通过；Linux arm64 Host 在 glibc 2.17 环境构建并运行。官方 npm 四包 dry-run、摘要回读和默认安装通过，macOS 隔离 Host 达到 Ready、Web 返回 200、受控停止成功，SQLite 与独立 Backup 均为 43 表且完整性通过。Windows x64／arm64 最终 MSI 由用户手工验收；用户要求不再重复 Windows 验证。

本版 MSI 未签名，可触发 SmartScreen；缺失 WebView2 时需联网引导安装。Windows 不发布 Client/npm、不注册自启、不提供系统级安装或 Credential Manager 密码保存。无 WebView2 且断网、终端全操作、浏览器全遮挡和注销／关机等组合没有独立日志，不追加表述为逐项自动化通过。

测试数据只位于临时目录和隔离容器，未访问或修改用户 Runtime Home 与生产数据库。
