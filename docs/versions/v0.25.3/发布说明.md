## npm Client 安装

支持 macOS arm64、Linux arm64 glibc 和 Linux x64 glibc；Windows 使用上面的 Desktop MSI，不提供 Windows npm 附件。Node.js 支持 `^22.12.0 || ^24.0.0`。

```sh
npm install -g @ez-assistant/client --registry=https://registry.npmjs.org/
ez-assistant config
ez-assistant start
```

`@ez-assistant/client` 和三个平台附件的 `latest`、`next` 均已回读为 `0.25.3`。从官方 registry 无版本安装已确认选择主包及 macOS arm64 附件 `0.25.3`；CLI、Host build-info、Host Ready、Web 访问和受控停止通过。

## 主要变更

- macOS arm64 Desktop DMG，完成 Developer ID 签名、Apple 公证、staple、Gatekeeper 和只读挂载验证。
- Windows x64／arm64 当前用户 MSI，内置同版本 Runtime Host 与 Web。
- Windows Runtime Home、单实例、安全 discovery、文件、路径、进程与 Desktop 生命周期适配。
- ConPTY 交互终端，支持 PowerShell 5.1、CMD、已安装的 PowerShell 7 和 Git Bash。
- Agent Shell 全局默认、Session 绑定、切换／刷新、Run 冻结与恢复语义。
- Windows MCP stdio、外部依赖诊断、独立图标与自绘标题栏。
- 修复 Client 升级后无法受控停止旧 Host 的兼容门禁问题；该修复先经家庭私库和 Linux 实机验收，再作为 `@ez-assistant/client@0.25.3` 发布到官方 npm。

## 安装限制

- MSI 当前未签名，Windows 可显示 SmartScreen 或“未知发布者”提示。请在确认文件 SHA-256 后安装。
- WebView2 Runtime 是必需组件；若系统缺失，安装器需联网下载引导程序。
- 本版为当前用户安装，不提供系统级安装，不注册 Windows 自启。
- 卸载和升级默认保留 Runtime Home 及其中的会话、Workspace、模型、MCP、Skills 和附件数据。
- Windows 不保存远端 Host 密码；本版不提供 Windows npm Client。

完整验收边界见[验收记录](验收记录.md)。
