# v0.25.3 发布说明

v0.25.3 是 EZ Assistant 的首个 Windows Desktop 发布版本，包含同架构 Runtime Host 与 Web。最终 x64／arm64 MSI 由用户在 Windows 环境手工验证通过。

## 下载与校验

| 平台 | 文件 | SHA-256 |
| --- | --- | --- |
| Windows x64（Windows 10 1809+） | `EZ-Assistant_0.25.3_windows_x64.msi` | `f3096d873f2912dc9a542c9728bac20f35f3db01fbd37a2c67f223c3571aa603` |
| Windows arm64（Windows 11 ARM） | `EZ-Assistant_0.25.3_windows_arm64.msi` | `6b1d7ffa859823bd78b24d45c455d1f55de05fe8968f388f56806fd7e9310f90` |

每个 MSI 同时提供同名 `.sha256` 附件。GitHub Release 链接和远程附件复核将在发布执行后补记。

## 主要变更

- Windows x64／arm64 当前用户 MSI，内置同版本 Runtime Host 与 Web。
- Windows Runtime Home、单实例、安全 discovery、文件、路径、进程与 Desktop 生命周期适配。
- ConPTY 交互终端，支持 PowerShell 5.1、CMD、已安装的 PowerShell 7 和 Git Bash。
- Agent Shell 全局默认、Session 绑定、切换／刷新、Run 冻结与恢复语义。
- Windows MCP stdio、外部依赖诊断、独立图标与自绘标题栏。
- 修复 Client 升级后无法受控停止旧 Host 的兼容门禁问题；该 Client 修订已发布到家庭私库侜 Linux 验收，不是本次 Windows MSI 附件。

## 安装限制

- MSI 当前未签名，Windows 可显示 SmartScreen 或“未知发布者”提示。请在确认文件 SHA-256 后安装。
- WebView2 Runtime 是必需组件；若系统缺失，安装器需联网下载引导程序。
- 本版为当前用户安装，不提供系统级安装，不注册 Windows 自启。
- 卸载和升级默认保留 Runtime Home 及其中的会话、Workspace、模型、MCP、Skills 和附件数据。
- Windows 不保存远端 Host 密码；本版不包含 Windows Client/npm 产品。

完整验收边界见[验收记录](验收记录.md)。
