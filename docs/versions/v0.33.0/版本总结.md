# v0.33.0 版本总结

2026-11-06，用户确认本版本可以收尾，按已交付的本地范围完成验收归档；尚未发布。

## 实际交付

- **F01 多组织与完整隔离**：全局账号、多组织成员、系统／组织管理员、统一范围选择、JWT 固定 7 天、组织业务资源及本地域隔离。切换组织先确认终止任务，Host 全部收尾后换发 Token；旧数据归默认组织。
- **F02 企业多模型**：组织可用集合、默认与选择策略，复用 Provider 级代理 URL；客户端可选择企业模型或配置个人模型，来源分组且配置按组织保存。
- **F03 插件界面与卡片**：MCP Apps／轻量插件卡片、右侧内置及外部应用、受限宿主通信、页面工具授权、卡片快照恢复及换域收尾。
- **F04**：按用户要求暂时废弃，未实施，后续版本未定。

## 验收与兼容

中心、后台、正式 Host Web 和 macOS 的既有联验覆盖升级恢复、组织隔离、两类模型、卡片与应用联动、撤权及重启。收尾修正静态检查和历史测试夹具问题后，Rust 全工作区回归已覆盖，失败项修正后定向复验通过；严格检查、Desktop 全量单元测试、中心／后台单元测试、各端构建及协议核验通过。各 Feature 结论见[开发计划](开发计划.md)。

客户端与 Runtime 版本及最低兼容版本均为 0.33.0，企业协议统一为 6。企业中心与客户端需配套升级；实际部署前备份库、文件及 Runtime 数据，按默认组织迁移规则处理旧数据，不把新组织绑定到旧历史。

## 保留限制与后续

- Windows 原生页面隔离及完整产品验证按用户要求延后；正式 Windows 发布前仍需复核 Wry 修复在最终依赖与产品中的效果。
- 模型联验使用受控上游，实际服务商和其他未测原生平台未记为通过；安装包下载／安装、自动更新及签名公证留发布验证。
- 本次未执行生产迁移、部署、打包、Git 提交／推送或发布。v0.32.2 的独立封版事项保持原归属。
- 已清理核实停用的本版隔离测试数据；在用开发场景、挂载文件及共享恢复资料保留。下一目标版本待定、待启动，未自动恢复 F04。
