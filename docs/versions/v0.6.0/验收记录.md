## 五、架构与范围边界

- `agent-model` 只增加 provider-neutral 结构化错误、attempt 事实和可装配建立重试；
  Core 仍只看到一个逻辑 Model Step。
- OpenAI-compatible Adapter 只提供 wire 观察与安全请求快照，不直接落盘、不管理
  Trace 生命周期。
- Collector、JSONL、Complete/Incomplete、Replay、Timeline、Host 事件和 CLI 全部
  保持在 `tools/reliability-demo` 私有边界，不是产品持久化或协议契约。
- 正式 Runtime 未获得 Session/Run Trace 编排、持久化或续跑代码；Protocol 与 Desktop 无
  Trace DTO、命令或 UI 变更。
- Timeline/Replay 不装配历史副作用入口；Shell、File、Memory、Approval 和 Journal 均不会
  在回放时重新执行。

- 实现与已确认功能设计和技术方案无范围偏差。Demo 真实闭环的默认运行未启用
  retry；真实瞬态错误不可稳定制造，重试边界由暂停时钟、gate 和 scripted failure 矩阵
  确定性验证。
