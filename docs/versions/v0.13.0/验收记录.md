## 五、安全与数据边界

- 本轮全量回归只使用临时 Runtime Home、SQLite、Workspace 和 loopback Provider；没有修改
  用户 `~/.ez-assistant` 业务数据库。
- 真实 LLM smoke 只读既有模型配置，把 credential 复制到隔离临时 Runtime Home；Session、Run、
  Conversation、Workspace、权限文件和输出均位于临时目录。
- Host 输出检查未发现 API Key、Bearer Token、完整 Prompt、文件正文或完整模型回复泄漏。
- 子任务临时目录使用 OS 临时根和 lease，终态后释放；异常进程遗留交由 OS 临时目录策略处理。

## 七、已知边界与遗留

- 委派保持单层、同步；不支持递归、后台 child、重启自动续跑或直接对用户输出。
- 共享 Workspace 不提供文件冲突追踪、锁、陈旧读取检测或自动合并。
- Web Demo 是默认关闭的私有验收客户端，不构成正式桌面 UI 契约；正式交互属于后续桌面版本。
- Plan Shell 仍以当前 OS 用户权限执行，不是强沙箱。
- child 完整 Conversation 仍使用 Host-private 查询，不提前承诺为公共 Protocol DTO。
- child list 当前按任务加载最终正文；`Cancelling` 观察事件、存储单行查询优化和更大规模列表性能
  可在出现实际需求后处理，不阻塞本版本。
- 常规回归不会自动执行可能产生费用的真实 Provider 测试；v0.13.0 主真实 LLM 验收入口已在
  隔离环境显式执行通过。
