- 版本内修复与交付：模型目录兼容、随包搜索工具、Markdown／代码高亮、网页版外链默认新标签页、置顶运行指示的焦点／悬停布局，以及售前助理实际目录规范配置。配置变更经用户确认完成，已有冻结会话不被强制改写。
