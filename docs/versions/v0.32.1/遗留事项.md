### 会话快照与加载恢复缺陷（2026-10-21）

- **状态与范围**：本项机制修复已随 F02 于 2026-10-22 获用户验收；以下保留 2026-10-21 的问题来源与修复目标记录，不能将其理解为当前仍未实施。历史现场未知根因不因验收而补造定位结论，不重开 F01。
- **已确认机制**：`crates/assistant-runtime/src/runtime/product.rs` 的 `get_session_view` 在读取前后比较全局事件序号，最多尝试四次；无关会话的事件也可能使快照失效。`apps/desktop/src/stores/RuntimeLifecycleCoordinator.ts` 的 `loadSession` 遇到 `snapshot_busy` 直接返回，没有安排重试或展示失败；普通会话读取请求还缺少应用层超时兜底。这里重试的是快照读取，不是重新排队或执行 Agent 任务。
- **现场与未确认项**：用户确认多个会话等待后一起恢复；检查时 Host 健康接口可响应、存储线程在等待命令，未捕获到此次卡顿请求的错误及阶段耗时。健康响应和线程空闲不能排除异步等待；全局快照干扰是已确认的设计缺口，但不是本次卡顿已证实的根因。企业中心身份核验、用户域等待、请求通道及存储队列仍需根据同一次请求的阶段耗时区分，不能直接登记为死锁。
- **修复目标**：快照一致性只受当前会话、相关子任务及实际共享依赖的变化影响，无关会话的事件不能使当前读取反复失效；保留共享配置变化的正确失效与恢复语义。Desktop 对暂时繁忙执行有界重试，耗尽或读取超时后显示可重试的失败状态；切换会话、连接更换及取消后，旧请求不得覆盖新选择，不自动重放有副作用的命令。
- **验收要点**：A 会话持续输出事件时，首次打开 B／C 会话仍能完成加载；相关状态变化时快照保持一致；覆盖 `snapshot_busy` 后恢复、持续繁忙、读取超时、快速切换与断线重连，不能无限显示加载。对多个会话同时等待的场景补请求阶段耗时定位，分别给出已修复机制与尚未证实原因的结论。

### 长会话发送后启动处理迟缓（2026-10-23）

- **状态与现象**：用户反馈越来越卡，特别是长会话；进一步明确为“界面能操作，但消息发出后很久才开始处理”。用户要求先记录问题，本次仅检查代码，不实施性能修正，不重开或改写 F02 的验收结论。
- **代码已确认的成本**：普通输入接纳在分配身份前调用 `load_identity_history`，队列准备及 Store 实际领取又读取会话历史事实；历史事实读取会解码其所在提交帧。`stage_target_append` 在追加前通过 `scan_append` 扫描已有文件；文件长度变化使位置索引失效，下次读取重新建索引。`get_session_view` 在展示分页窗口前还读取会话历史与完整正文，发送后的视图刷新会触发此路径。
- **并发边界**：不同会话的 Agent 执行任务可并发，但同一用户域的 Store 命令由一个专用阻塞线程串行处理；耗时的文件读取／扫描会让后续存储请求排队。部分读取同时持有目标 Session mutation gate，会延长同会话的准入／领取等待；不能据此表述为整个 Host 的 Agent 全局串行。
- **尚未证实**：未对本次现场执行分阶段计时或隔离数据复现，尚不能量化接纳、存储等待、执行准备、模型请求及视图展示的各自耗时；代码瓶颈不能替代本次现场根因证明。此前长会话复制分支的计时仅适用于复制场景，不挪作发送耗时。
- **后续定位与修正方向**：在新建隔离场景区分短／长会话、单／多会话及冷／热读取，计时覆盖接纳、领取、持锁、存储等待、首次模型请求和前端刷新；优先收窄接纳所需身份查询、减少重复历史装配、增量维护可重建位置索引、按窗口投影视图，并依据残余阻塞评估存储读写并发边界。仅记录方向，不视为已确认技术方案或已授权实施。
- **必须保持**：历史结构只存会话文件，数据库仅保留相应执行控制及临时输入；入队仍是可撤销暂存，实际领取时才创建 Run，不提前显示处理过程。性能修正不得引入数据库历史副本或历史工具副作用重放。
- **源码依据**：[输入接纳](../../../crates/assistant-runtime/src/runtime/input/submission.rs)、[队列准备](../../../crates/assistant-runtime/src/runtime/input/mod.rs)、[实际领取](../../../apps/runtime-host/src/storage/run_state.rs)、[追加校验](../../../apps/runtime-host/src/storage/recovery.rs)、[位置索引](../../../apps/runtime-host/src/storage/conversation.rs)、[会话视图](../../../crates/assistant-runtime/src/runtime/product.rs)、[Store 分发](../../../apps/runtime-host/src/storage/worker/thread.rs)。
