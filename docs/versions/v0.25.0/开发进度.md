  扩选和右键复制。引用按钮独立保留，选区折叠同步关闭气泡；去掉 mouseup 中未管理的延迟读取。
- 验证：原生 WKWebView 中跨段拖选后点击空白，rangeCount 为 0；普通正文拖选、点击引用成功加入
  ComposerQuoteStore、右键 Copy 菜单均正常。Chromium 同场景通过；正式前端 build、定向 oxlint、
  既有 ConversationView / quote-selection 共 23 项通过。未新增样式断言或运行无关 Rust 全量测试。
