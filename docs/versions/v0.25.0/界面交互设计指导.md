本指导将已确认功能转换为页面、状态与操作规则。用户明确要求入口页在简洁的同时具有设计感和

不视为原生 WebView 或产品功能验收。

## 二、页面与入口

| 页面／位置 | 用户能做什么 | 去向 |
| --- | --- | --- |
| Desktop 入口页 | 选择本机／其他 Runtime，查看启动与连接状态 | 连接成功进入当前 Host 工作台 |
| 设置 · Runtime | 当前连接摘要与二级设置入口 | 左侧统一选中 Runtime，详情通过返回按钮回概览 |
| Runtime · 切换 Runtime | 选择并切换本机／其他 Runtime | 成功后回新目标的概览，失败保留连接页 |
| Runtime · 访问设置 | 设置／修改密码，配置非本地访问，查看可用地址 | 保存到当前 Host，结果以 Host 返回为准 |
| Runtime · 状态与诊断 | 当前 Host 的连接、配置与诊断详情 | 不混入本机启停操作 |
| Runtime · 本机与客户端 | 本机目录、启停与桌面行为 | 只作用于这台电脑，Web 隐藏 |
| 标题栏状态左侧 | 点击“打开 Web 端”图标 | 系统浏览器打开当前 Host，并通过 token 快速登录 |
| Web 登录页 | 输入访问密码，或处理快捷链接 token | 登录成功进入页面所属 Host |
| 工作区编辑 · 选择目录 | 浏览 Host 目录、确认当前位置 | 填入工作区主目录或附加目录 |
| 既有资源栏 | 查看文件、使用用户终端 | 内容来自当前 Host；Web 隐藏内嵌浏览器 |

三类设置合并到同一个 Runtime 一级入口，通过二级页面区分当前 Host 的服务配置和本机客户端操作。
当前连接摘要显示 Host 名称／地址；本机页以明确的本机操作命名和远程连接时的提示区分操作归属。
Web 不提供本机 Runtime 启动或 Desktop 式目标切换，用户通过浏览器地址访问其他 Host。
产品组成只有桌面级（Desktop + Host + Client）与服务器级（Host + Client）。本指导中的
Desktop 入口属于桌面级应用；两类应用均由各自 Host 提供 Web，不存在独立 Host 产品入口。

## 三、Desktop 入口页

### 3.1 信息结构与布局

页面全宽占据应用内容区，保留与工作台一致的 42px 标题栏原生窗口安全区；不伪造 macOS 红绿灯。顶部只显示
产品名和弱化版本号，与原生红绿灯按同一垂直中心对齐。主体为居中的单列连接区，建议宽度 `min(384px, 可用宽度 - 48px)`，
垂直略高于内容区中线。较矮窗口允许页面滚动，禁止裁掉输入框和主按钮。

内容顺序：

1. 现有产品图标，使用原始源图标，不生成新 Logo。
2. 主标题“连接你的工作空间”；辅助句“选择一个 Runtime，继续你的工作”。
3. 本机 Runtime／其他 Runtime 两个等宽选择项，图标、文字和选中背景共同表达状态。
4. 所选目标的内容区：本机就绪状态，或远程地址与密码输入。本机卡片按内容自适应，上下各 14px 内边距，不再用 106px 最小高度撑开。
5. 唯一主按钮“进入工作空间”或“连接 Runtime”。
6. 连接阶段／错误反馈区域。保持稳定占位，不因错误或启动结束推动整页跳动。

底部仅弱化显示本机 Runtime 启动状态；不新增主机列表、功能介绍、最近任务或营销文案。
星链背景是分布式协作的品牌意象，不显示实际主机名称、数量或在线状态，不承担网络管理功能。
完整交互区高度可为本机和远程模式保留相同预算，表单本身不堆套卡片。

### 3.2 视觉与流动感

沿用当前 `--ez-*` 主色、文字、边框、背景与控件体系：主操作 `#496cf2`，内容白色，入口背景使用银蓝底色与分布在视口边缘的淡青／淡紫色层，
主文字 `#252932`。正式实现的字号沿用 12／14／16px 三档；标题用 16px、字重 600，正文 14px，
版本与状态 12px。单行输入及主按钮用 large 40px 档，普通图标按钮 32px；不新增近似高度。

连接、登录与 Host 设置的文本字段聚焦时只改变边框颜色，不叠加阴影或外圈，不改变尺寸；
本机／其他 Runtime 的选中态使用浅色填充与文字颜色，不使用悬浮阴影。

常驻流动只发生在入口背景与加载标记；成功进入的单次转场见 3.6：

- 背景采用“星链”意象：稀疏透视点阵与行列网格自然铺满背景，位置独立于表单，不绕主体排列成圈，
  不为主体挖出中心空洞。星点代表平等的 Agent 节点；不画唯一中央控制节点，也不使用真实卫星地图或外部品牌标识。
- 节点以细小光点和少量柔和光晕表达层次；连线用低对比度蓝灰色。保持当前浅色／深色体系，
  不强制切换到深色宇宙场景。通过整体低对比度和原有控件表面保证阅读清晰，背景可自然延伸到主体后方。
- 点阵与网格同步小幅、缓慢起伏，保留倾斜视角与远小近大的纵深。避免全网同时发亮、密集闪烁、
  常驻烟尘或大幅缩放；不增加沿连线流动的光点或中心放射状圆球。
- 鼠标移动可带动背景相机小幅、平滑偏移，保持已选定的倾斜构图；表单不跟随位移。移出入口预览后
  相机缓慢归中；触摸操作及减少动态效果模式不触发该跟随。
- 窄窗口保持点阵稀疏与网格连续，以表单可读性优先；星链不提供点击、悬浮详情或业务状态反馈。
- 切换本机／远程时使用约 160ms 的轻微位移与透明度变化；不弹跳，不让输入区高度弹性抖动。
- 加载在主按钮或状态行使用小旋转环，文字按真实阶段改变，不展示伪造百分比。
- `prefers-reduced-motion` 下保留静态点阵与网格，关闭起伏和相机跟随；后台不可见时停止装饰动画。
- 进入工作台后结束入口页装饰动画；不把这套流动背景扩散到会话区或设置表单。

本次星链背景是用户对入口页的明确要求，不改变通用设计语言对工作台持续动画的限制。密度与
可见度可在 Demo 的外部审阅控件微调，正式实现以用户审阅结果为准；不据此将后续 Runtime
组网、节点发现或 Agent 协作功能提前纳入 v0.25.0。

当前视觉基准为已获用户认可的 Vanta.js DOTS Demo，适配现有浅色／深色配色。镜头采用俯视并
略微侧转的斜视角，让远端点阵延伸到页面上方，网格沿对角方向延伸；点色偏淡、间距较大、
浮动振幅较小。DOTS 本身没有规则网格开关，Demo 在原生点阵上补充同步起伏的行列连线。
正式依赖接入、性能与降级见[技术方案](技术方案.md)，视觉认可不计为产品功能已实现。

### 3.3 本机 Runtime

- 入口页出现即静默发现／启动本机 Runtime；已有实例时沿用，不重复启动。
- 默认显示本机选项，但这只是视图选择，不自动连接工作台，也不恢复上次目标。
- 准备过程中显示“本机 Runtime 正在启动”；其他 Runtime 的选择和输入始终可用。
- 本机就绪显示状态点与“本机 Runtime 已就绪”，不要求密码、不暴露本机 token。
- 点击“进入工作空间”后才进入本机连接流程；若仍在准备，显示“等待本机 Runtime…”并在就绪后继续。
- 本机启动失败就地显示错误和“重试启动”，仍允许选择其他 Runtime；不得以全屏错误遮挡其他连接。

### 3.4 其他 Runtime

同一位置显示两个输入框：

- 地址：占位“Host 地址，例如 http://192.168.1.20:7240”，保留可访问名称“Host 地址”，同时接受 HTTPS 地址。
- 密码：默认隐藏，提供可访问名称明确的显示／隐藏按钮；Enter 提交。

地址包括 HTTP／HTTPS 协议、IP／主机名和必要端口；错误定位到字段或其下方。HTTP 可直接输入
并连接，无需证书或额外确认页。选择 HTTPS 时，证书错误展示“无法验证此 Host 的证书”，
不自动改为 HTTP；用户可主动修改地址协议。按技术方案由 Host 配置 HTTPS 证书路径，
客户端预先信任其签发链；HTTPS 错误提示可以说明检查访问地址与系统证书信任。

“记住密码”使用默认关闭的 checkbox，作用于对应地址。已确认的技术方案采用 macOS 系统
Keychain；成功登录才保存，不可用时继续本次连接并提示未保存。Demo 仅展示视觉，不写入浏览器
存储。该选择不代表自动连接上次目标；Keychain 的技术选择已确认。

主按钮为“连接 Runtime”。填写有误时不进入连接；失败保留地址和当前输入，提供修正与重试。
不增加“取消连接”按钮，选择另一目标即表达切换意图。旧目标的迟到结果不能令界面跳转。

### 3.5 连接与加载

| 状态 | 页面行为 | 可用操作 |
| --- | --- | --- |
| 入口就绪 | 当前选择与输入可见 | 选择目标、填写、连接 |
| 本机启动 | 底部显示本机准备状态 | 选择本机等待或直接连接其他 Runtime |
| 连接中 | 保留选择与输入布局，主按钮 loading，显示“正在连接…” | 切换另一目标；同目标重复提交禁用 |
| 认证／加载 | 显示“正在验证…”或“正在加载工作空间…” | 状态来自实际过程，不伪造时间进度 |
| 失败 | 恢复主按钮，错误持续可见，字段值保留 | 修改、重试、换目标 |
| 成功 | 得到初始状态后播放一次火箭转场，进入工作台并移交键盘焦点 | 转场期间不重复提交；以后通过设置切换，不返回入口页 |

输入有焦点时不被背景状态更新抢走。初始化不自动聚焦主按钮或触发提交；状态用礼貌播报区域，
错误使用 alert，动画每帧不触发辅助技术播报。

### 3.6 火箭发射与主页显露

用户期望的是一段连续的场景转换：火箭向上发射，入口现有内容渐隐并上移；尾焰带起的烟尘
向两侧展开、向上推开，主页从烟尘后显露。

火箭与烟尘由独立动画素材承载，可交付为透明背景视频或带透明通道的序列帧；入口与主页继续
使用真实界面，不录入素材。旧 Demo 的程序烟尘效果未获认可，不作为正式视觉基线。
用户确认使用当前 Blender 火箭模型继续制作动画：火箭从画面底部缓慢出现，镜头同时下移，
火箭加速向上飞行；镜头到达下方后停止，烟雾继续扩散、消散。
素材层固定在应用内容视口内，不跟随入口页上移；入口页独立位移和渐隐，避免重复叠加镜头运动。
层级依次为主页、入口内容、透明火箭／烟雾素材；页面衔接统一跟随素材播放进度。
实际时长、分辨率及关键帧随新素材审阅确定；以下只定义页面衔接关系，不代表真实连接耗时：

| 素材阶段 | 页面衔接 |
| --- | --- |
| 底部入画、点火 | 火箭从底部出现，镜头开始下移；入口表单连同品牌区向上淡出，星链背景随入口退场 |
| 升空、镜头下移 | 火箭加速升出内容区，镜头扫过箭体与发动机；入口逐渐完全退出 |
| 镜头停止、烟尘展开 | 镜头固定，烟尘继续从底部向两侧扩散；页面按烟尘覆盖进度衔接到主页 |
| 烟尘带出主页 | 主页轻微上移并逐渐显露，关键显露位置与素材对齐 |
| 烟尘消散 | 主页稳定，焦点移到消息输入框；移除转场层并释放播放资源 |

- 本机与远程连接均在认证、初始数据就绪后开始转场。失败留在入口显示错误，不先发射再回退。
- 火箭、尾焰和烟尘都是无交互装饰；转场期间入口与尚未显露的主页不接收点击或键盘输入。
- 使用低对比度蓝灰／浅色烟尘、克制的暖色尾焰，不加入爆炸、闪屏、音效或无限粒子循环。
- `prefers-reduced-motion` 下直接显示主页；切到后台或转场期间开启减少动态效果时直接收束到主页。
- 设置内切换 Runtime 不重复发射、不回到入口页；采用现有加载到新目标的简单交接。
- 素材未就绪、加载或解码失败时直接进入已经就绪的主页，不阻塞连接。正式素材的透明通道、
  缩放裁切、体积、解码性能与原生 WebView 兼容由技术方案及实现验证确定。
- 动画播放完成不代表连接或数据加载成功；素材制作与页面接入分别审阅。

## 四、工作台内连接与 Host 设置

### 4.1 设置 · Runtime 概览与切换

沿用现有设置框架与导航，左侧仅保留“Runtime”。概览顶部为当前 Host 名称／地址、连接状态与
版本摘要，右侧“切换”进入二级连接页；下方用三行入口展示“访问设置”“状态与诊断”“本机与客户端”。
采用紧凑单行入口和轻背景连接摘要，入口与二级页标题均不附加副标题；状态、版本和目标信息保留在
连接摘要及相应详情字段。不将所有表单堆入概览，也不复制入口页动效或品牌展示。

二级页面统一使用现成的 `InlineIconButton`，与标题同行对齐，保持无圆角底色、悬浮只变图标颜色，
不覆盖组件尺寸或另造按钮样式；返回 Runtime 概览，
左侧始终选中 Runtime。访问表单未保存时，
返回、换设置项和关闭设置沿用现有放弃修改确认。Web 隐藏切换及本机与客户端，仅管理当前 Host。

“切换 Runtime”页复用入口页的本机／其他 Runtime 选择、远程输入与主按钮：

- 当前目标无需切换时显示“当前连接”；目标改变后按钮为“切换 Runtime”。
- 用户提交切换时直接丢弃未发送草稿与临时附件，不弹保存确认；选择项的视觉切换尚未提交时
  不视为已经切换 Host。原 Host 的 Agent Run 继续。
- 切换期间主工作台不接受旧目标的新业务输入；设置区域保留 loading／错误，不导航回入口页。
- 成功后整体替换目标工作台，设置回到新目标的 Runtime 概览；失败保留连接页，允许重试或选其他目标，不静默回退本机。
- 退出应用、停止本机 Runtime、停止目标 Runtime 的入口与文案按实际目标区分，不从“切换”推导停止。

### 4.2 Runtime · 访问设置

沿用一页紧凑表单，作用于 Runtime 概览中的当前 Host。页头仅保留标题和返回操作，按下列顺序组织：

1. **访问密码**：密码状态“未设置”或“已设置”，输入新密码后“保存密码”；不回显已保存密码，
   不增加找回、重设、验证码或多账号表单。失败保留编辑内容，成功清空输入并更新状态。
2. **非本地访问**：开关；未设密码时不可开启，邻近显示“先设置访问密码”。Host 拒绝开启时保持关闭。
3. **允许的域名**：可选、每行一个，不含协议或端口；仅使用 IP 时留空。本机与其他设备共用服务端口。
4. **Host 服务**：显示当前实际连接地址、HTTP／HTTPS 和端口（默认 `7240`），不再分别输入本机／外部监听地址。
   开关和域名即时生效；端口、协议和证书先关闭远程访问再修改，保存后明确提示重启生效。
   待重启时不能开启远程访问；本机 Desktop 提供复用原有生命周期确认的“重启本机 Runtime”，不自动重启。
5. **HTTPS 证书**：只在 HTTPS 下显示 Host 上证书链／私钥路径，不回显正文；说明证书覆盖
   `127.0.0.1` 及使用的 IP／域名，客户端需信任。无效证书不保存，不自动退回 HTTP。
6. 远程客户端关闭接入前提示当前连接会断开；本机客户端不会因此断开。端口占用明确提示，
   不默默换成随机端口；监听配置保存成功与重启后已生效分别展示。

配置成功以 Host 回执为准；设置密码后不自动打开非本地访问。本机原生认证仍能进入设置直接
修改密码，Web 登录失败页面不提供未认证密码修改入口。
改密立即使普通登录失效：保存前在密码区说明需重新登录，成功后 Web 回密码表单，
远程 Desktop 在当前连接设置请求密码，本机原生连接继续可用；不是返回 Desktop 启动入口页。

#### 状态与诊断、本机与客户端

“状态与诊断”复用现有连接与配置状态、配置路径、问题列表和复制诊断；读取与重连均指向当前 Host。
“本机与客户端”集中本机运行时目录、重启／停止及关闭窗口行为，继续走原生生命周期确认流程。
远程连接时不能将远端会话数量当成本机启停影响范围，也不能在诊断页混放本机的启停按钮。

### 4.3 标题栏“打开 Web 端”

图标按钮位于连接状态胶囊左侧，32px 命中区，使用现有线性浏览器／外部打开图标，悬浮提示与
可访问名称均为“打开 Web 端”。使用系统浏览器打开当前 Host URL，链接可带 token 快速登录。
不把 URL 展开成长按钮，不使用资源栏内嵌网页；Web 自身隐藏此入口。

准备链接时只在本按钮体现忙碌；失败就地反馈或简短 Toast，不改变 Runtime 连接。无 Web 地址时
禁用并提供原因。token 不显示在 Tooltip 或诊断文本；清除链接 token 与认证机制由技术方案落实。

## 五、Web 登录与能力兼容

### 5.1 登录页

与 Desktop 入口共用同一页面布局、渐变色层、DOTS 点阵动效、源 Logo、标题和页脚。通过 `children`
分别传入 Desktop 连接内容与 Web 登录内容，Web 不再使用独立的带阴影卡片。Web 显示当前 Host
地址、单个密码框和“进入工作空间”，输入框及按钮沿用客户端的尺寸、边框和颜色；原生窗口
的标题栏安全区仅在 Desktop 保留。Web 不提供本机／其他 Runtime 选择、用户名、注册或忘记
密码入口。错误密码就地提示并保留重试能力，快捷登录的 loading 同样显示在共享布局中。

快捷链接到达时显示“正在登录…”，Host 校验成功进入工作台；token 无效时显示正常密码表单。
HTTP 与 HTTPS 使用相同登录页面和快捷登录体验；不把未加密连接显示为已加密，也不强制跳转 HTTPS。
本机来源仍需要认证。退出登录返回该 Host 的登录页，不停止 Agent Run；清理当前身份的业务展示。

### 5.2 文件与原生操作

- Web 上传使用浏览器文件选择；附件标签、预览和发送状态复用现有布局，不让用户看客户端物理路径。
- 工作区目录选择使用第六节的 Host 浏览器；“上传文件”和“选择工作目录”入口、目标不同。
- Web 隐藏“浏览器”新增资源项、Finder、系统打开、托盘及桌面专属设置，不渲染空的禁用占位区。
- 文件有支持的查看器时直接预览，不支持时提供下载；远程 Desktop 不把 Host 文件路径交给客户端 Finder。
- 资源面包屑的最后一项使用剩余可用宽度，不设置固定最大宽度；空间不足时允许收缩并省略文字，右侧操作保持可用。
- 复制路径时文案／上下文指向当前 Host；预览获取失败显示可重试状态，不能误用客户端同名文件。

## 六、Host 目录选择

由工作区新建／编辑中的主目录或附加目录字段打开，沿用统一 Dialog，建议宽 640px，窄窗口
缩至可用宽度。标题“选择工作目录”，其下以弱化文本标明当前 Host。

- 顶部为返回上级按钮、当前位置面包屑／可编辑路径；起点可为 Host 用户主目录，能回到文件系统根。
- 内容只列可进入目录，行含文件夹图标、名称和进入指示；单击进入，底部“选择此目录”明确选中当前路径。
- 根目录禁用上级按钮；空目录仍可选，路径不存在或无权限时保留位置与错误，并允许返回上级／修改路径。
- 读取中保留路径，显示列表加载态；旧目录响应不能覆盖新的当前位置。
- 按技术方案提供隐藏目录开关与完整路径输入；单层列表超限显示截断提示，可输入完整路径
  前往未列出的目录，不能为了界面便利限制为已注册工作区。
- Footer 为“关闭”“选择此目录”；这里的关闭是文件选择对话框操作，与连接流程的“无取消连接”无关。
- 确认后由 Host 校验并返回路径，填入原字段；工作区原有保存／会话冻结规则保持。

## 七、资源、终端与恢复状态

### 7.1 资源与查看状态

保持既有资源标签、文件查看器和右栏布局。Web 保存轻量布局／标签描述，按 Host 与会话隔离；
刷新重新获取文件，不保存文件正文或终端输出，不同步其他客户端标签。浏览器存储不可用时使用
当前页面状态与默认布局；只在保存失败影响用户预期时给简短反馈，不常驻技术说明。

刷新后未上传 File 不恢复，失效附件标签不伪装成可发送；切换 Host 直接丢弃未发送草稿。
HTTP 浏览器若不支持异步剪贴板复制，显示可选中文本供手动复制；文件选择与用户触发的粘贴保持
可用。录音等受浏览器限制的能力就地提示，不阻断聊天、目录选择和文件上传。

Desktop 内嵌网页遇到实际相交的浮层时，以最近网页截图保留背景；设置遮罩覆盖全窗口，菜单或
提示只有与网页区域相交才触发。设置内部滚动不反复显隐，关闭最后一个遮挡浮层后恢复原网页，
保留页面状态。截图是静态占位，暂不可与网页交互；不可用时显示中性占位。Web 不提供内嵌网页。

### 7.2 用户终端

沿用 xterm 及现有终端工具栏，所执行位置为当前 Host。打开后显示该目录终端，不新增远端机器
管理面板；路径或目标在存在歧义时可查看，避免大段常驻解释。

- 创建时显示“正在启动终端…”；失败提供“重试”。Host 返回 Shell 退出后显示实际结果并按既有关闭行为收口。
- Web 刷新结束该页面所有终端，刷新后不恢复标签中的旧 PTY 或自动启动新 Shell。
- 关闭终端只影响所属终端；不清理其他客户端的终端，也不停止 Agent 任务。
- 连接丢失时禁用终端输入并就地显示“终端连接已断开”。已确认的技术方案在断线后回收且不恢复旧 PTY，
  用户可显式新建终端；一般业务 SSE 重连不能伪装成原 Shell 恢复。
- 打包样式验证使用正式 CSP，检查等宽字体、颜色、光标、中文输入与 resize，不复用放宽策略的夹具结论。

## 八、键盘、缩放与动效检查

- 所有展开类组件默认展开时直接显示最终布局；进入页面、切换会话或重新挂载时不补播展开动画。
  后续展开／收起保留原有过渡，Desktop 与 Web 共用 `Collapse`，不影响独立页面转场。

- 所有操作使用原生按钮／输入或既有公共交互原语，提供正确可访问名称；选择项支持键盘操作和可读选中态。
- Tab 顺序跟随视觉顺序；错误关联字段，密码显隐操作保持输入焦点与位置。Dialog 管理焦点并在关闭后返回触发项。
- 主按钮与输入在 loading／错误态尺寸不变；长地址、错误文案自动换行或截断并可查看完整内容。
- 正式 Desktop 至少检查常用窗口、最小可用窗口与 100%／125%／150% 缩放；Web 增加窄宽检查，
  不以移动浏览器适配代替原生手机 App 计划。
- 入口背景非必要动画必须支持 reduced-motion；装饰不拦截点击、不提供焦点、不发起业务请求。
