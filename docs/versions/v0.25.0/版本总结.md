## 实际交付

1. Host 共用唯一 HTTP／HTTPS 监听，默认端口 7240；非本地访问默认关闭，空密码禁止开放。
   设置中可直接修改密码；Web Cookie 登录与普通 token 快捷登录共用既有认证。
2. Desktop 入口兼作加载页，静默启动本机 Runtime，由用户选择本机或远端；同时只连接一个 Host，
   设置中切换并丢弃草稿。可选 Keychain 记住密码，标题栏可打开当前 Host 的 Web。
3. Desktop/Web 共用入口背景和火箭转场。Runtime 设置整合为概览及二级页面，默认展开不补播动画。
4. Web 通过 Host 浏览任意有权限的目录、选择工作空间、上传／预览／下载文件；PTY 迁至 Host，
   两端共用认证 WebSocket，刷新／断线回收终端。Web 隐藏原生内嵌浏览器能力。
5. 原生浏览器按浮层实际遮挡使用截图占位；修复滚动显隐闪屏、关闭标签音频残留、Monaco 图标、
   PDF CSP、面包屑截断及消息选区等验收反馈。
6. `/skill`、`/mcp` 和资源栏读取最新目录；普通／主控会话均可 `/skill refresh`、`/mcp refresh`，
   插入不触发 Run 的 user role 消息，冻结系统提示词不变，Session 不保存技能目录快照。
7. 历史会话按需加载，列表使用有界摘要页；启动不全量加载历史 Input／Run 或检查图片。
   历史执行显示中断，未决审批重启丢弃，只有用户显式操作才准备目标会话执行。
8. MCP 初始化移出启动关键路径，交给 Host Supervisor 管理；目录就绪后更新客户端。
   同目录开发构建一次实测从创建进程到健康就绪 64.7 ms，MCP 在后台用时 3681 ms。
   这是本机单次实测，不代表安装包全平台冷启动保证。

## 验证与边界

- 最终前端单测 363 项、内嵌 Web 8 项、全目标／特性 Clippy、fmt、lint、协议生成检查及构建通过。
- Rust 最终全量为 1,394 passed／1 failed／24 ignored；唯一失败为 32 PTY 场景等待 Shell PID
  超时，未修改产品或放宽用例，单独复跑通过。保留这次波动，不表述为单次全量全绿。
- macOS 原生、Chromium、Safari 及同机双 Runtime 有记录中的实际覆盖。真实跨机器、系统受信
  HTTPS/WSS、部分 Safari 人工矩阵未完整执行，用户整体确认不替代这些证据。
- 目标会话的 Input／Run 仍按会话整组加载，不代表单个超长会话内部已完全分页。
  损坏的既有历史数据保留并隔离，没有直接批量修复用户数据库。
- Host/Desktop 按同版本交付，不新增旧 Desktop 兼容层。CLI、Runtime 组网／中继／P2P、
  原生手机 App 不在本版；服务器级完整装配由后续版本推进。
- 独立 agent-robot S3.2 实机联调保持原待办，未随本版归档关闭。
