# v0.31.0 版本总结

2026-10-14 用户确认基本功能已测试，并在获知安装包差异和未测范围后明确“可以验收了归档了”。本版按实际交付范围验收通过，状态为 **已完成**。

## 完成范围

- F01：企业中心提供免登录首页、下载、更新日志与操作手册；复用发布记录维护日志，首页与手册独立维护，官网、管理后台与接口同源部署。
- F02：登录页可选择个人／企业模式及企业中心地址，支持受控重启、配置保持、失败恢复和登录焦点修复。
- F03：异常模型调用保留请求体及实际收到的响应证据，提供消息、事件与原文阅读，明确完整性、来源和权限边界。
- F04：四套配色统一覆盖工作台、代码、图表及终端，支持保存与恢复偏好。
- 临时优化：企业登录自动刷新模型、智能体及插件，并将同中心已安装插件升级到最新兼容版本；修复 macOS 图标留白、会话空正文占位、图片预览缩放与控件及宽度适配，隐藏智能终端菜单入口。

范围与实施记录见[总体设计](总体设计.md)、[开发计划](开发计划.md)和各 Feature 计划。Computer Use 保持独立分支，不属于本次验收范围。

## 验证与发布事实

相关定向回归、静态检查、前端与原生构建、隔离 HTTP／WS 集成、浏览器以及 macOS Release 主路径验证已完成；公开页面与私有调用证据隔离、登录配置与四主题联动已有核验。用户完成基本功能实测；本次归档不重复运行产品测试，不把基本功能测试扩展为全平台或全部异常组合通过。

软件版本为 0.31.0，应用与存储兼容下限保持 0.30.0，企业协议保持 3。企业中心已按用户授权升级并部署到企业及公网环境，更新说明从本版开始。企业默认配置三平台包已有发布记录；个人默认配置三平台包已本地交付，线上各包是否替换以实际发布记录为准。

## 已接受限制与交付收尾

- 最终源码与已交付安装包尚有差异：隐藏智能终端菜单尚未打包；两个 Windows 包还未包含最后的空正文和图片预览修复。最新 macOS 手动安装 ZIP 已包含这两项 UI 修复。
- 最新 Mac App／ZIP 已完成签名公证；该次 DMG 公证最后查询仍在 Apple 处理中。此前已发布的 Mac DMG 公证已通过，两者不能混为同一产物。
- Windows 原生界面及其他平台差异、真实 Provider／正式 Host 企业路由异常矩阵未完整覆盖；Windows ARM64 原生运行已获用户明确跳过，不记为已通过。
- macOS 自动升级实测按用户要求仅保留提醒，不作为本版验收阻塞。Runtime 独有失败、未收到响应、历史未采集等证据覆盖边界继续保留。

后续根据实际发布安排统一安装包与更新说明；未确定下一版本号或新增功能。后续入口见[版本管理](../../版本管理.md#后续能力地图)。本次归档不提交、推送、重新打包或部署，不修改生产数据库。
