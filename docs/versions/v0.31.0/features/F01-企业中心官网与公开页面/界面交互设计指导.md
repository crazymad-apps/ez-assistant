## 二、页面、入口与导航

| 入口 | 主要任务 | 进入／离开行为 |
| --- | --- | --- |
| `/` | 了解插件能力、个人与企业模式，进入下载或手册 | Logo 返回首页；首页内导航定位对应内容区 |
| `/download` | 比较平台并下载安装包 | 直接访问与刷新可用，复用下载弹窗内容组件 |
| 下载弹窗 | 在当前页面快速选择安装包 | 顶部导航、首页主按钮与页尾按钮打开；关闭回到原页面和原滚动位置 |
| `/changelog` | 阅读用户更新说明 | 稳定版本锚点 `/changelog#vX.Y.Z`，不以日志存在推定安装包可下载 |
| `/manual` | 进入操作手册 | 有目录时进入第一篇；目录为空时展示空态 |
| `/manual/:articleId` | 阅读一个主题及段落 | URL 标识文章，`#heading-id` 定位段落；前后文章按目录顺序 |
| `/admin/` | 进入现有管理后台 | 普通链接进入，沿用已有身份恢复和登录行为 |
| 后台安装包列表与版本详情 | 直接编辑该版本更新日志 | 继续使用原有后台 Hash 路由，不新增官网管理菜单 |

公开页顶部导航顺序保持“插件能力、使用模式、下载、更新日志、操作手册”，右侧为管理后台。
首页不带锚点进入时保持整页顶部；异步内容加载完成不触发主标题滚动。只有显式区块链接才定位对应区块。
从日志／手册点击前两项，先进入首页再定位区块；缺少该可选区块时隐藏对应锚点入口，保留下载、
日志、手册和后台。普通站内链接在当前标签页打开，支持浏览器返回、前进及另开标签页。
后台顶栏在用户菜单左侧提供“首页”入口，新标签页打开 `/`，保留当前后台页面和未保存内容。

弹窗属于页面短期状态，不生成伪路由；从弹窗进入安装说明时先关闭弹窗再导航，返回不强制重开。
未知页面／文章明确显示“页面不存在”及返回入口；合法文章中不存在的段落保留文章并提示定位失败，
不悄悄切到其他文章。路由服务端匹配及 HTTP 状态边界以技术方案为准。

## 三、视觉与公共布局

### 3.1 设计基线

官网记忆点集中于点阵背景下的真实客户端工作台演示，以及库房布局、三维预览、Excel 报价的成果
展示。阅读页保持安静的白底正文，不为每个段落增加卡片和装饰。正式内容可以调整现有区块的文案、
图片、显隐与顺序，不能通过静态内容更换组件或注入布局代码。

| 视觉项 | 沿用基线 |
| --- | --- |
| 品牌／操作色 | `#2e81d8`，主按钮、选中态与链接 |
| 主要文字 | `#26303c` |
| 次要文字 | `#687389`，只用于辅助信息，正文不降低对比 |
| 页面／容器底色 | 白色 `#ffffff`，轻背景 `#eff4fa` |
| 细分隔 | `#e6ecf3`，仅在导航、阅读层次及必要分区使用 |
| 字体 | 现有系统字体栈；不加载外部字体 |
| 公开控件 | 默认字号 14px、控件高 38px、大按钮 48px，沿用 Demo 的 9px 基准圆角 |
| 标题层级 | 首屏响应式约 34–68px，内容页标题约 32–48px，手册标题 34px、节标题 22px；窄屏按 Demo 收缩 |
| 阅读正文 | 14–16px、行高约 1.8–1.95；连续中文正文一般控制在每行约 30–45 字，随可用空间自然换行 |

正式代码通过官网 ConfigProvider 与语义变量表达这些值，后台仍使用自身 Token；SCSS Module 负责
页面布局。状态色沿用成功／警告／错误 Token，不能全部涂成品牌蓝。以上尺寸是正常缩放的基线，
不得用固定高度裁切放大字体或较长的实际内容。

### 3.2 悬浮与吸顶导航

沿用 [SiteNavigation](../../../../../apps/enterprise-admin/prototype/site/SiteShell/SiteNavigation/index.tsx)：
桌面初始距顶部 18px、内部最大宽约 1176px、高 68px，半透明背景、柔和边界与圆角；首页背景
延伸到导航后方，不恢复一整条突兀的纯白占位。滚动超过原型阈值后贴到顶部，背景铺满，内部
Logo、导航与按钮保持原对齐线，圆角收起；滚回顶部恢复悬浮。

窄屏初始顶部和两侧留 12px，品牌／后台入口一行、导航自然占第二行；必要时增加高度，不把文字
压到不可读。滚动吸顶与菜单高度变化不能让正文跳动。页内锚点、手册右侧粘性目录及焦点滚动的
顶部偏移按导航实际高度加留白计算，避免沿用原型较小的锚点偏移而遮住标题。

过渡约 180ms，只改变位置与背景，尊重减少动态效果偏好；无 backdrop-filter 时使用可读的浅底
降级。Logo 保持原比例；工作台工具图标维持用户确认的小尺寸，不连带缩小 Logo。

### 3.3 响应式与焦点

桌面遵循 Demo 的宽度和分栏；约 1050px 以下手册收起右侧段落目录，约 760px 以下转单列。
至少验证 390px 常见手机宽度及 320px 最窄布局；不能因平台标签、长文件名或代码撑宽整个页面。
表格、代码块在自身区域横向滚动，按钮可换行，页面主体只纵向滚动。

菜单、场景选择、弹窗关闭、手册目录和重试入口必须能用键盘操作，并有可见焦点。页面导航后
更新标题并把焦点移到主内容标题；浏览器返回保留合理阅读位置。弹窗捕获焦点，关闭回到触发按钮；
Esc 关闭公开下载弹窗。后台提交中的关闭行为沿用现有离开／取消守卫。

## 四、首页

信息顺序沿用已确认 Demo：

1. 首屏：产品定位、企业统一分发说明、下载及阅读指南入口、支持平台提示。
2. 工作台演示：五个场景可切换，展示客户端侧栏、会话与文件预览关系。
3. 核心插件能力：库房 CAD 绘图、CAD 转三维、通用报价三项主要成果。
4. 企业统一分发及个人／企业模式对比。
5. 更新日志／手册阅读入口及页尾下载区。

首页文案以用户收益和专业场景为主，突出方案成形、直观沟通与团队统一分发；
详细操作步骤、格式要求与技术限制留在操作手册。工作台对话自然简短，并保留演示标识。

首屏的动态点阵沿用客户端登录页装饰；只作背景，不拦截操作。减少动态效果或图形能力不可用时
显示静态浅色背景，导航、正文和下载不依赖动画加载成功。

工作台演示是可切换的合成示例：右侧素材保持“示意”性质，处理过程展开只改变演示展示。
不运行插件、不执行真实任务、不虚构用户客户数据。首版不恢复用户已要求删除的下方“企业知识库／
通用辅助”两个次要大块；它们可以继续作为工作台场景出现。插件说明保留实际安装／启用前提。

个人模式强调自行配置模型、插件和智能体；企业模式强调账号连接中心、统一配置和分发、成员按需
使用。插件安装及升级按实际行为描述，不将“统一分发”画成无需操作的强制推送。

页尾沿用左文字、右成果组合图的构图，左栏约占 1.1 份、右栏 1 份，保留用户确认的较宽文字区域，
标题不被挤成连续短行。手机先说明与按钮、后配图；装饰可缩减但主操作保持可见。

初次加载只在内容区放低动效占位，固定导航即可使用；不能用演示文案闪现后替换正式内容。
无静态内容时展示“内容暂未发布”，提供下载和后台入口；读取失败显示“暂时无法加载内容”与重试。
不要显示空白巨大首屏，也不回退源码内旧宣传文案。某个可选区块被清单隐藏属于正常布局，不显示错误卡。

## 五、下载弹窗与下载页

### 5.1 沿用紧凑样式

基线为 [DownloadDialog](../../../../../apps/enterprise-admin/prototype/site/DownloadDialog/index.tsx)：
弹窗桌面宽 560px、居中，窄屏最大宽为可视宽减两侧边距，内容超高时在弹窗内滚动。
标题行使用 38px Logo、“下载 EZ Assistant”及一行选择提示，不恢复之前的大标题和巨型设备卡片。

```text
Logo  下载 EZ Assistant                         关闭
      选择与你的系统和芯片匹配的版本。
[ macOS / Apple Silicon | Windows / x64 | Windows / ARM64 ]
平台及架构                               DMG / MSI
最新可用版本、文件大小、发布日期
适用设备说明                         查看安装说明
[                 下载对应平台版                  ]
文件详情（文件名、SHA-256，可展开与复制）／就地状态
```

正式信息以轻量文字补入当前版本说明区，不再套一层大底色卡片。文件详情默认折叠，展开时长摘要
可换行并有复制反馈。下载页采用同一选择与信息结构，作为常规内容页展示，避免整屏放大弹窗。

### 5.2 平台选择和下载

首页主下载按钮和页尾按钮根据当前设备显示对应系统名称；点击仍打开下载弹窗，允许检查版本与手动切换。
macOS Apple Silicon、Windows x64、Windows ARM64 始终有明确标签。浏览器提供明确的系统、架构与
64 位提示时自动选中对应包；只有系统信息时仅显示对应系统名称，等待用户确认芯片。
不能将 UA 中的 Intel Mac／Win64 兼容标识当作芯片证据；iPad 桌面模式、手机和其他系统不自动匹配桌面包。
缺少设备接口或读取被拒绝时保留手动选择；迟到的识别结果不能覆盖已选平台。只在浏览器内读取，
不上传或保存设备提示。macOS 仍明确 Apple Silicon 适用范围，不暗示支持 Intel Mac；无 Linux 选项。

每个平台可对应不同的“最新可用版本”。切换平台立即更新选择样式，并让该平台的读取状态、版本与
按钮一起切换，禁止短暂保留上一个平台的可点击下载按钮。当前弹窗会话内保留手动选择，重新进入
可重新推荐，不需要浏览器持久化偏好。

| 状态 | 呈现及操作 |
| --- | --- |
| 查询中 | 保留选择控件，版本区显示加载状态，下载暂不可点 |
| 可下载 | 实际版本、大小、发布日期，按钮为“下载 macOS 版”或明确的 Windows 架构 |
| 当前平台无可用包 | 下载按钮显示“暂无可用安装包”并不可点，允许切换平台；不重复展示底部提示 |
| 查询失败 | “暂时无法获取安装包”及重试；不能展示为暂无版本 |
| 仅部分平台可用 | 可用平台正常下载，其他平台单独说明 |
| 指定版本已撤回 | 指定版本没有可用结果时由禁用按钮显示“暂无可用安装包”，提供查看最新版本入口；不由空结果臆测撤回原因 |
| 文件缺失／协议不兼容 | 按服务端结果说明该版本当前不可下载，不编造发布状态 |

用户点击后复核目标可用性，再通过现有 installer 地址交给浏览器原生下载，不把大文件整体加载成
浏览器内存 Blob。发起前复核失败可就地提示、刷新列表；复核与实际下载之间仍可能发生撤回，不能
以预检保证文件一定下载成功。原生下载开始后由浏览器管理完成或失败，页面不显示“下载完成”或
虚构进度；仅提示已发起，可查看浏览器下载列表，异常时返回刷新再试。不自动改下另一个版本。

安装说明链接指向有效手册文章；手册尚未发布时显示不可用说明，保留当前平台／芯片的简短选择提示。
公开下载弹窗可以随时关闭；关闭不宣称取消浏览器已开始的文件下载。

## 六、更新日志与操作手册

### 6.1 更新日志

沿用 [Changelog](../../../../../apps/enterprise-admin/prototype/site/Changelog/index.tsx) 的左侧版本目录、
右侧时间线，桌面内容最大宽约 1128px。按规范版本倒序，日期取该版本最早首次发布时间；一条日志由
版本、日期、标题／正文和可用的版本下载入口组成，不展示内部 Feature 或里程碑。
页面直接呈现版本目录与时间线，移除占据首屏的大标题和宣传说明；安装包入口置于正文后的独立操作区，
使用分隔线与带下载图标的浅蓝按钮，避免混入正文链接。版本号仅在时间线顶部显示一次，并作为该版本的标题。

目录点击改变版本锚点并定位；窄屏目录变为可换行的版本选择，正文单列。已定位版本有选中提示，
但“目录当前项”不能被标作“最新安装版本”。不默认引入分页、搜索或分类筛选。

没有已发布的非空日志时显示“暂无更新日志”，保留手册与下载入口；请求失败提供重试。
未找到锚点版本时显示“未找到该版本的更新说明”，其他日志仍可阅读。每条日志下载信息按需读取，
某条查询失败不遮住已加载的正文。没有对应制品只说明“此中心暂无该版本安装包”，不能说版本未发布。

Markdown 表格使用浅色表头、细分隔线与交替行底色；内容顶端对齐并自动换行，窄屏仅表格横向滚动，
不撑宽整页。横向区域可通过键盘聚焦操作，表头保留列标题语义；官网正文与后台更新说明预览共用样式。

### 6.2 操作手册

沿用 [Manual](../../../../../apps/enterprise-admin/prototype/site/Manual/index.tsx) 的三栏布局：
左章节目录约 205px，中正文自适应，右段落目录约 150px，桌面栏间距约 42px。
正文展示章节路径、文章标题、适用版本及维护日期；底部为上一篇／下一篇，不人为增加文章摘要字段。
维护日期与适用版本来自内容源，不取访问时间或平台版本代替。

左章节目录与正文共用页面纵向滚动，不独立吸附或设置内层滚动区域；右段落目录在导航下方吸附。
中等屏幕隐藏右目录；手机显示“章节目录”折叠按钮，选文章后
收起目录并把焦点交给文章标题，按钮包含展开状态语义。文章内可直接点击标题锚点。
切换文章默认平滑滚动到整页顶部；带段落链接则在对应正文就绪后平滑定位到段落，
避免先跳页顶再定位或滚动到旧文章。系统启用“减少动态效果”时直接定位。

正文通过受限节点渲染：表格／代码单独滚动，图片保持宽高比、有用途明确的替代文本；装饰图使用
空 alt。外链可识别，复制代码或文章链接只在真实成功后反馈。文章不存在不自动显示第一篇；
目录为空和网络错误使用不同提示。正文图片故障保留可读文字及占位，不无限重载。

首次进入手册或显式刷新时读取当前静态内容；章节、上下篇与正文内站内链接使用前端导航，
共用同一静态内容快照，只更新文章与选中状态，不重复请求、卸载目录或先跳整页顶部。
图片 URL 使用内容哈希，已打开页面仍保留原正文与图片。
更新删除文章时转为不存在状态，删除段落时保留文章并提示。持续失败显示重试，不无限刷新。

## 七、版本详情中的更新日志

### 7.1 编辑位置

复用版本详情原有更新说明表单，标题调整为“更新日志”，支持 Markdown 编辑、预览与保存。
提示“官网与客户端共用此说明；仓库保留对应版本 Markdown”。不新增第二个日志编辑框。
仓库的版本／日期元信息不粘贴进正文；版本由详情身份确定，公开日期来自首次发布事实。

安装包上传弹窗恢复为只选择安装制品和签名文件；移除“官网内容包”选择、双份上传进度、内容摘要
和当前官网来源。版本详情不出现手册、首页文案、内容包预览或替换入口。

### 7.2 保存、发布和撤回

未保存的修改保留在表单，预览渲染当前草稿；不会将浏览器草稿当成已经公开的说明。
保存沿用现有离开确认、权限和旧值冲突核对；失败保留草稿，未知结果先重读。
冲突时让管理员核对服务器当前说明再保存，不自动覆盖；回读失败与保存失败分开反馈。

| 版本事实 | 简短说明 |
| --- | --- |
| 尚未发布 | “保存为本版本的更新日志，发布后公开。” |
| 曾经发布 | “保存后更新官网与客户端中的版本说明。” |
| 全部平台已撤回 | “日志仍可阅读，安装包下载保持不可用。” |

首次发布可提示该版本日志将公开；撤回提示对应平台停止下载。两者都不提首页或手册版本切换。
保存按钮本身就是提交动作，不叠加不必要的确认弹窗；直接纠错后提示维护者同步仓库即可，不强制增加审批。

## 八、首页与手册维护体验

采用独立固定静态目录，首版不增加后台上传入口。维护者在仓库修改首页配置、手册 Markdown 和
配图，经校验／本地预览后更新公开目录。预览有“本地内容预览”标识，不显示目标安装版本。
下载保持占位，不连接真实安装包；校验失败定位相对文件与原因，不部署部分内容。

维护步骤为“修改 → 校验／预览 → 更新静态目录”，不要求打开安装包管理。
静态目录尚未部署时提供明确空态；正文或图片故障如实显示，固定导航、下载和日志仍可使用。
维护要求见[内容维护说明](../../../../site/README.md)，日志写作遵循
[开发流程规范](../../../../specs/开发流程规范.md#用户向更新日志与操作手册)。

## 九、验收口径与后续

后续实施的交互验收以可观察行为为准，不为静态文案、CSS 或组件树增加脆弱快照：

- 已确认的首屏、工作台、模式对比、宽文字页尾、紧凑下载弹窗保留，两个已删除次要大块不恢复。
- 悬浮／吸顶对齐、长页面滚动与锚点不遮挡；手机、200% 字体／页面放大及键盘路径可用。
- 三平台选择、空结果、读取失败、部分可用和原生下载反馈正确，不报虚假下载完成。
- 日志深链接、手册章节／段落、前后文章及返回行为正确；缺内容、缺文章、缺图片与请求失败可区分。
- 正式界面不存在示例版本或假下载提示；本地预览／Demo 的模拟提示不混入正式内容。
- 版本详情直接编辑／预览日志，冲突、未知结果和回读失败可恢复，草稿不提前公开。
- 安装包管理没有手册或官网包操作；静态内容独立更新，安装发布／撤回不切换手册。
- 官网日志与客户端说明一致；公开页无法读取后台草稿或身份。
