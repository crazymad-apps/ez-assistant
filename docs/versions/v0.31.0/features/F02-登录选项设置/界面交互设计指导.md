# v0.31.0 F02 界面交互设计指导：登录选项设置

## 一、设计信息

- 所属版本：`v0.31.0`，整体为 **开发中**；Feature：F02 登录选项设置。
- 本指导：**已确认**；2026-10-13 用户在精简表单、自动清除绑定修订后要求继续，进入 F02 开发计划编制。
- 已确认依据：[功能设计](功能设计.md)、[技术方案](技术方案.md)。用户补充的模式切换保留企业地址规则纳入全部状态。
- 用户修订（2026-10-13）：编辑态说明收敛到 placeholder，移除绑定信息和清除选项，保存身份配置变更时自动清除旧绑定。
- 上位依据：[总体设计](../../总体设计.md)，用户已授权按当前总体方向启动 F02 M0。
- 实施约束：[前端规范](../../../../specs/前端编程规范.md)、[Desktop 模块](../../../../modules/desktop.md)。

沿用现有登录背景、表单宽度与基础组件，细化入口、表单、确认、进度和恢复。颜色使用现有语义
Token，F04 负责四套主题的统一覆盖。本文件不引入新的配置权威、持久草稿或通用设置框架。

## 二、页面与入口

### 2.1 登录页布局

```text
                 [Logo] ez-assistant

           [ 本机 Runtime | 其他 Runtime ]

           ┌────────────────────────────────┐
           │ [设备] 这台电脑     ⚙ 登录选项 │
           │        ● 本机 Runtime 可连接   │
           └────────────────────────────────┘

           企业账号
           [ 输入企业账号                   ]
           账号密码
           [ 请输入                         ]
           [ 进入项目                     → ]
```

- 表单内容区沿用现有最大宽度 384px，保持整体居中。Logo 和名称作为一个整体居中，名称始终在右侧。
- 常规 Logo 52px，图文间距 12px，品牌行下方间距 24px；高度不超过 620px 时 Logo 40px、下方间距 16px。
  名称使用 `--ez-font-large`、偏粗字重、主文字色；不重复显示版本、标语或副标题。
- 本机卡片沿用现有设备图标与卡片外观。状态点移至状态文字前，与文字共同换行；右侧为轻量文字按钮
  “登录选项”，带现有齿轮图标，垂直居中。只允许按钮点击，不把整张卡片设为操作区。
- 卡片内容放不下时，按钮换到下一行右对齐，左侧名称和状态可自然换行；不覆盖文字或压缩成无标签齿轮。
- 矮窗口或放大后内容超出视口时允许纵向滚动，品牌、表单、错误和主按钮均可到达；不以居中定位裁掉顶部内容。

品牌组合适用于 Desktop／Web 共用入口。仅 Desktop 选中本机目标时显示登录选项；选中其他 Runtime
继续使用既有远程表单，普通 Web 无此管理入口。企业登录失败或初始化失败不隐藏本机卡片与登录选项。
本机启动中允许打开弹窗等待真实配置，不能显示一份看似可保存的默认表单。

### 2.2 完整设置与账号操作

首页账号菜单移除“设置”，账号触发器采用账号菜单语义，不再以完整设置齿轮提示可用功能。
必要的改密、退出与重试沿用已有可用条件。进入工作区后才可打开完整设置；离开工作区立即关闭
已打开的完整设置。未完成初始化、有残留身份、断线返回首页均适用，其他已有唤起路径使用同一条件。

卡片内“登录选项”仅打开本指导的对话框，没有设置分类侧栏或跳往完整设置的链接。

## 三、弹窗布局与编辑规则

复用现有 `Dialog`，建议宽度 480px，最大宽度为视口减去两侧各 16px；沿用组件的留白、圆角、
遮罩与进出动画。正文可独立滚动，标题和操作区保持可达；窄窗口允许页脚按钮换行，完整显示标签。
编辑、确认及执行结果在同一弹窗内替换正文，不叠加第二层确认弹窗。

### 3.1 编辑态

```text
┌──────────────────────────────────────────┐
│ 登录选项                               × │
│                                          │
│ 使用模式                                 │
│ [ 企业模式                           ▾ ] │
│                                          │
│ 企业中心地址                             │
│ [ 输入企业中心地址，如 https://…       ] │
│                                          │
│                 [取消] [保存并重启]       │
└──────────────────────────────────────────┘
```

1. **使用模式**复用 `SelectionPopover` 的 `field` 形态，选项为“个人模式”“企业模式”，不复用首页
   的本机／其他 Runtime 标签。直接展示已保存的选中值，不加字段描述或常驻副标题。
2. **企业中心地址**仅在企业模式显示，必填。placeholder 为“输入企业中心地址，如 https://center.example.com”；
   允许粘贴，提交时仅去除首尾空白。支持现有 HTTP(S)、端口和合法路径；不自动补协议或删改路径。
3. 不显示中心绑定信息或“清除旧中心绑定”复选框。保存实际模式／地址变更时自动清除旧绑定，
   包括保存个人模式；后续企业登录成功时重新建立。编辑草稿或普通初始化不触发清除。
4. 保留短字段标签和可访问名称；placeholder 只承载输入提示，不替代标签。已填地址时不另显示常驻说明。
5. 字段错误放在字段下方并关联输入框；点击主操作后聚焦第一个错误。修改相关字段后更新提示，
   输入法组合输入时不提交。格式校验不显示“中心连接成功”，真实可达性由后续连接与登录判断。

### 3.2 地址保留与草稿生命周期

| 操作 | 必须呈现的结果 |
| --- | --- |
| 企业 → 个人 → 企业，未关闭弹窗 | 原地址或本次编辑后的地址完整恢复，不受隐藏控件卸载影响 |
| 保存个人模式 | 不提交隐藏地址修改，保留 Host 中原已保存企业地址；实际模式变更保存时自动清除旧绑定 |
| 保存个人模式并重启 Host／退出应用后，再切企业 | 自动填回 Host 已保存地址，不要求重新输入，不用构建默认值替代 |
| 编辑新地址后切个人并保存 | 新地址草稿不随个人模式保存；之后重新打开使用原已保存企业地址 |
| 取消、关闭或按 Escape 离开编辑 | 丢弃本次未保存编辑；下次打开重新读取实际配置 |

个人模式的运行中中心为空，不得据此清空草稿或已保存地址。地址只由用户在企业模式下明确修改并保存。
草稿仅在当前弹窗存活，不新增 localStorage、历史中心列表或其他持久副本。

### 3.3 已保存与运行中状态

打开时表单初始化为**已保存配置**。若存在待重启变化，在正文顶部显示“已保存，待重启”，并以
“运行中”“已保存”两列说明模式和企业中心的差异；个人模式显示“未使用企业中心”，不把它解释为地址已删除。
没有差异时不常驻展示重复信息。首页账号字段始终按实际运行中的模式显示。

| 表单状态 | 主操作 |
| --- | --- |
| 有有效模式或地址修改 | “保存并重启”，进入影响确认 |
| 无修改且存在待重启配置 | “重启并应用已保存配置”，进入影响确认；不重复保存 |
| 无修改且无待重启配置 | “保存并重启”禁用，不发送请求 |
| 配置尚未读到或已确认不可管理 | 主操作禁用，提供真实状态及适用的“重新读取” |
| 更新正在下载／安装 | 显示“更新正在进行，完成后可应用登录选项”，禁止保存或重启；不取消更新 |

## 四、影响确认与执行

### 4.1 确认态

弹窗标题改为“确认应用登录选项”，正文展示本次实际变化：模式由何值变为何值、中心地址由何值
变为何值。没有变化的行不重复展示；企业切个人时明确“企业中心地址保留”。
长地址完整换行，不以省略号隐藏目标地址或只显示域名。

确认内容包括：

- 作用对象为这台电脑的 Runtime；重启将中断其全部用户任务并断开所有客户端，任务不会自动续跑。
  无法取得任务数量时显示“当前任务数量未知”，不显示空闲或零任务。
- 仅在本次身份配置变更需要关闭且非本地访问当前已开启时，说明“保存后将关闭非本地访问，现有远程连接会断开；
  重启后需在工作区访问设置中重新开启”。单纯应用已有待重启配置时，按实际保存状态描述，不虚构一次关闭操作。
- 本次将自动清除已有绑定时，用一句话说明“旧中心绑定将自动清除，下次企业登录重新绑定，原数据保留”；
  不增加绑定详情、复选框或额外确认步骤。
- 已有其他待重启配置时，说明本次重启也会应用这些已保存配置；不承诺只改变本弹窗字段。

页脚为“返回修改”与“确认保存并重启”；仅应用已有配置时，主按钮为“确认重启”。首次进入确认
聚焦“返回修改”，必须再进行一次明确激活才执行，避免同一次回车连续提交。返回编辑使本次确认失效，
之后需重新展示最新影响；关闭或取消确认不产生写入或停止副作用。

### 4.2 执行态与成功返回

依真实阶段显示“正在保存”“正在重启”“正在重新连接”；保存结果不确定时显示“正在核对保存结果”。
使用无百分比的现有等待指示，不模拟进度。执行期间字段只读，关闭按钮及 Escape／遮罩关闭禁用，
禁止登录、切换目标、重复保存和更新操作。应用被系统关闭仍可能中断等待，重新打开必须回读实际状态。

只有核对新进程已就绪、运行中模式／中心与目标一致且无需再重启后，才关闭弹窗并在本机卡片下方
显示“登录选项已生效”。提示使用可被辅助技术读取的行内状态，不单靠短暂 Toast 表达成功。
企业模式焦点进入账号输入，个人模式进入“进入项目”；清除旧密码及失效身份，不自动发起登录。
如随后企业登录失败，保留真实登录错误与登录选项入口，不将已应用配置改称保存失败。

## 五、异常与恢复

失败后恢复可关闭状态，正文先说明已知结果，再给出下一步；不把所有异常合并为“操作失败”。
后台仍在执行有界核对时保持相应等待态，核对结束才展示可操作的恢复选项。

| 事实与提示 | 可用操作与限制 |
| --- | --- |
| 尚未取得配置：“无法读取登录选项” | “重新读取”“关闭”；未读到前无可提交的默认表单 |
| 字段或前置校验明确拒绝：“配置未保存” | 保留草稿，定位字段；改正后重新确认，不执行重启 |
| 配置或实例变化：“配置已变化，请重新核对” | 保留草稿用于比较；“重新载入”前说明将放弃未保存修改，由用户明确选择；不偷换编辑基线 |
| 响应丢失：“保存结果尚未确认” | 有界回读，之后提供“重新检查”“关闭”；不自动补发保存或重启 |
| 回读值符合目标：“当前配置已保存，尚未确认重启” | 明确展示已保存值，允许重新确认后重启；不声称原请求已成功，也不重复保存 |
| 配置已保存，旧进程仍运行：“已保存，待重启” | 原因明确可重试且来源可核实时，提供经确认的重启；更新占用时等待更新结束 |
| 原进程已停止、新进程未就绪：“配置已保存，Runtime 启动失败” | 仅已核验原启动来源且现有协调器支持时显示“重试启动”；否则“重新检查”和既有本机维护指引 |
| 新进程存在，最终读取失败：“Runtime 已启动，生效状态尚未确认” | “重新检查”“关闭”，不为刷新状态再次重启 |
| 最终模式、中心或实例与目标不符：“实际配置与本次确认不一致” | 展示可核实差异并重新核对；不回滚、不再次清除绑定 |

关闭失败结果后，本机卡片继续表达真实连接状态；已保存待重启或尚未确认生效的提示仍可在登录选项
中回读呈现。保留数据不等于保留任务执行，恢复旧中心仍须按当前配置和绑定规则重新保存、重启和登录。
错误文案使用已脱敏信息，不回显凭据、原始响应或本机私有路径。

## 六、组件、键盘与视觉规范

- 使用现有 `Dialog`、`SelectionPopover`、`Button`、`Icon` 和字段样式；不另造弹层、选择器或焦点陷阱。
- 正文和主要交互使用 `--ez-font-base`，标题和品牌使用 `--ez-font-large`，辅助元信息使用
  `--ez-font-small`。弹窗输入／选择／按钮统一默认 32px 高度档；首页表单保留现有 40px 高度档，
  卡片文字按钮使用默认高度档。多行提示和确认摘要自然增长，不塞入固定单行高度。
- 颜色、边框、阴影、层级使用已有语义 Token；错误同时有文字，状态点不单独承担状态语义。
  焦点沿用字段 focus-border 与按钮可见焦点样式，不新增叠加描边或导致尺寸跳动。
- 打开后先聚焦对话框标题／读取状态，完成读取后聚焦使用模式；Tab 在弹窗内循环。
  下拉展开时 Escape 先关闭下拉，再次 Escape 才关闭可关闭的弹窗，使用既有原语的事件归属。
- 切到个人模式后焦点保留在模式选择，不落到消失的地址控件；切回企业模式不自动跳走。
  校验错误聚焦对应字段；错误及阶段变化使用合适的 alert／status 语义，不让持续动画重复朗读。
- 取消或关闭恢复焦点到卡片“登录选项”；若原入口已不存在则回到当前可用的目标选择。
  成功返回按第四节进入下一项登录操作。图标无重复可访问名称，按钮名称使用完整文字。
- 尊重 reduced-motion；四套主题使用同一结构与状态语义。实际覆盖由 F04 集成验证，不提前宣称通过。

## 七、验收口径与后续

1. 首页与断线返回状态都无法打开完整设置，必要账号操作正常；工作区完整设置正常。
2. Desktop／Web 品牌图文整体居中；只有 Desktop 本机卡片提供登录选项，位置、状态点与键盘顺序一致。
3. 企业地址覆盖同表单来回切换、取消后重开、保存个人后重启 Host／应用再切企业四种路径；
   隐藏地址不清空，个人模式不保存未提交的企业地址草稿，实际保存模式／地址变更才自动清除旧绑定，普通初始化与表单切换不清除。
4. 无修改不保存；已有待重启配置可以只重启；草稿字段与实际运行中的登录方式不会混淆。
5. 编辑态仅有模式和地址字段，简短提示置于 placeholder；自动清除绑定、关闭非本地访问与重启影响
   统一放在保存确认中，取消无副作用，不再提供单独清除绑定操作。
6. 连续点击、回车、输入法、Escape、关闭、旧请求及更新竞争不会重复写入或重启；结果未知不自动补发。
7. 读取失败、冲突、未保存、已保存未生效、最终状态未知、已生效但登录失败可区分，恢复动作与事实匹配。
8. 窄窗口、矮窗口、长地址、100%／125%／150% 缩放和键盘操作下，文字完整、焦点可见、所有控件可达。
   macOS／Windows 目标 WebView 需实测；浏览器预览不能替代原生焦点、拖拽区及重启验证。

本指导与[开发计划](开发计划.md)已确认，M0、M1 已确认；M2 本机集成验证完成、待确认，实际结果见开发计划。
原生窗口与跨平台表现继续在 M2 验证，本指导不替代实现和验收记录。
