## 三、真实 Provider 验收

三个用例均复制现有可用模型配置到临时 Runtime Home，通过正式 Runtime Host 执行；API Key 未进入
Host 日志、fixture 或本文档。

| 组合 | 链路 | 结果 |
| --- | --- | --- |
| Kimi K3 | 原生双图输入 | 通过，23.42 秒 |
| Qwen 3.8 Max | 原生双图输入 | 通过，9.66 秒 |
| DeepSeek 主模型 + Qwen 辅助模型 | `inspect_images` 工具识图 | 通过，16.84 秒 |

Qwen 首次用例中图片已经进入模型，但 Build 模式下模型又主动选择了文件工具；验收提示随后限定为
“直接看图且不调用工具”，用于隔离验证原生视觉链路。DeepSeek 组合首次等待超时是测试会话沿用
`Ask` 权限且无人响应审批；设为 `Auto` 后工具链正常通过。这两次失败均不是图片协议或工具 Schema
故障。调用产生少量 Provider 费用，未查询精确账单金额。
