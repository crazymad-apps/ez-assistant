## 二、主要交付

1. **统一多模态图片链路**：图片继续归属现有文件与附件引用；Host 统一完成 MIME 检测、安全解码、
   方向与色彩处理、尺寸限制、JPEG 预处理和同名缩略图派生，Conversation/SQLite 不持久化 Base64
   或像素尺寸。原生视觉模型通过协议 Adapter 接收图片 Part，历史、重试和 Fork 按引用重建。
2. **辅助识图工具**：文本主模型可调用普通 `inspect_images` 工具，由已配置的默认视觉模型执行一次
   无工具识图；复用权限、审批、取消、超时、有限重试、审计和 usage，直接返回文本结果，不隐藏
   嵌套 Agent 或二次总结。
3. **模型目录与 reasoning/effort**：随包静态目录按 `(provider, protocol, model_id)` 提供能力和
   effort 方言映射，用户 override 优先；thinking 默认开启，reasoning 能稳定流式解码与回放，
   Session 保存五档稳定 key、Run 启动时冻结，模型切换只向下降级。
4. **队列可靠性修复**：用户中断暂停与 Runtime 重启恢复门禁成为正交事实；新输入只解除用户暂停，
   `resume_queued_input` 统一整体恢复和指定输入置顶，旧 `resume_session` 只保留一版兼容转发。
5. **Desktop 完整体验**：用户消息图片以右对齐缩略图流显示并复用现有预览弹窗；Composer 展示
   原生识图、工具识图或不可识图状态和会话 effort；模型设置提供默认识图模型；会话列表搜索收敛为
   当前列表标题匹配。
6. **usage 与缓存指标**：成功模型请求形成可靠记录并增量更新 Session 汇总；右侧上下文直接展示
   最新输入/输出/缓存命中、最新命中率、会话累计 Token 和综合命中率，无需反复扫描日志表。
7. **macOS 可信发布**：建立独立 `release:macos` 和 `verify:macos-release` 流程，完成 Developer ID、
   Hardened Runtime、App/Runtime/DMG 签名、Apple 公证、staple、Gatekeeper 与只读挂载验证；发布
   前强制校验 Tauri、npm 与 Rust workspace 版本一致。

## 四、明确边界

- 本版本只处理用户消息附件图片；Agent 工具或浏览器在中间流程生成的图片回传以及
  `openai_responses` 协议进入 `v0.17.0`；
- 所有 Provider 共用一套图片预处理，不建立按模型分叉的尺寸/编码流水线；
- 静态模型目录随软件发版，只读且不由普通用户编辑；未知模型按协议保守能力基线，用户可显式覆盖；
- 不提供 thinking 关闭开关；effort 是 Session 输入区的动态配置，不进入模型设置；
- macOS 仅验收 Apple Silicon Developer ID 站外分发，不包含 Universal Binary、Mac App Store、
  CI 发布或自动更新；
- 会话列表搜索只匹配标题；Agent Conversation Recall 和 Runtime 全文检索能力不受此 UI 简化影响。
