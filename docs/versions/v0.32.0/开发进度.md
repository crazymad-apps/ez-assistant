## 必要风险与提醒

- 已有 device 模块是用户 Home 内的智能终端 Gateway，不能作为 Host 级登记身份；技术方案仅复用适用文件保护。现有企业退出会收尾用户 Runtime，设备权限移除不能直接复用为全局退出。
- 当前置顶是 Runtime 持久化会话属性；不能把本机快捷入口实现成远端置顶聚合，旧数据过渡待方案确认。
- 当前原生桥接为全局单目标绑定；新设备筛选不能复用旧切 Host 的销毁行为。
- 终端是单 socket 单 PTY，断线回收；代理必须覆盖 ACK、取消和关闭，不能宣称已有持久终端。
- 用户不希望服务器承担全部代理流量；F04 改为 Host 直连优先，中心授权与信令，用户已确认禁用 TURN，直连失败提示不可连接。用户已明确普通业务继续中心桥接，不扩展通用 P2P。
- Demo 仍仅有 macOS 本机采集／输入成果；F04 独立探针已验证合成视频在双原生进程及本地 WKWebView／Chromium 间传送，无二次编码。随后已在 macOS 专用窗口通过双段 WebRTC 验证实际键鼠、文本提交及断线松键；后续已接通专用单窗口采集／硬件编码到 Chromium 的反馈闭环；已补测双显示器整屏采集、选择切换及输入映射；正式 Host、负坐标／混合 DPI／热插拔、Windows 和跨 NAT 尚未验证，未操作用户文件或数据库。
