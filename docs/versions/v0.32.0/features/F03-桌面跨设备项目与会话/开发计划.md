## 二、实施约束与核查

1. 按 M0 → M1 → M2 → M3 顺序实施。每步完成实现和最小有效验证后停止汇报，用户确认后进入下一步。计划确认只启动 M0，不授权一次性实施全部里程碑。
2. 不复制完整 RootStore，不增加 UI 到企业中心的通信。复用原客户端、同步投影、业务操作和原生文件方法，按固定设备归属拆开必要状态。
3. 设备、账号和业务资源归属从第一步贯穿；每步接入的功能当步具备错误、取消及迟到结果处理，不留到最终统一补齐。
4. 未接入的远端操作明确不可用，不能漏带目标后回落本机；里程碑完成仅代表该步范围，F03 未收尾前不宣称完整跨设备工作区可用。
5. 保留既有个人模式、直接远程 Host 登录和本机管理。设备登记不成为本机使用门槛；上方助理会话、设置与插件／智能体管理继续作用于本机连接。
6. 同一企业 Host 可以同时服务多个用户，沿用中心与用户 ID 对应的用户域。F03 不引入设备全局“当前用户”，不新增单窗口多账号功能；共用实际目录仍是共用文件，不宣称操作系统隔离。
7. 旧置顶只从当前本机当前身份读取并保存到本机偏好，远端不导入；不清理 Runtime `is_pinned` 或更改原分页排序。偏好格式变更遵循技术方案中的校验、备份与回退边界。
8. 本计划不包含 F04 远程桌面、F05 模型接入、手机端、发布或部署；安装包和既有环境交付按后续实际指令处理，不借测试自动重打包。

## 四、里程碑内容与完成条件

### M0 设备选择与会话读取

**前置**：本计划确认。

**实现**：

- 在现有 RuntimeClient 接入本机代理能力检查和不可变业务目标；本机控制请求继续无目标。保留错误中的目标与 outcome，不能将远端授权错误变成整个客户端退出。
- 从 RootStore 中按设备组织必要的业务 client、投影和事件同步，保留唯一登录与本机设置 owner。导航引用、异步代次和资源目标基础在本步确定，后续功能复用。
- 侧栏在本机置顶与项目之间增加设备选择，复用目录分页、在线状态与本机去重。项目及独立会话随选择变化，正文不自动切换；分页、归档浏览、现有搜索和历史导航限定目标。
- 接入原应用／会话／子任务读取，已有流式事件和会话状态按设备更新。远端 SSE 重建时重取对应快照，不复用本机实例标识或旧水位。
- 同步会话标题中的设备提示和加载／离线／无权限状态。切换设备保留本机现有资源与终端；远端尚未接入的发送、文件及终端入口不允许落入本机调用。

**最小验证**：受影响前端类型／静态检查；定向核对能力缺失不发远端请求、快速设备切换后迟到响应归属、事件重连重新取快照。用真实客户端连接隔离的本机与目标 Host，验证项目／会话列表及正文归属；本机设置仍作用本机。

**完成条件**：用户可以真实切设备并读取其会话，侧栏与正文可以属于不同设备；原本机路径仍可用，连接关闭与账号切换不留下可操作的旧身份数据。M1—M3 功能未交付，不把只读接入视为完整 F03。

### M1 会话操作与文件传输

**前置**：M0 完成并获用户确认。

**实现**：

- 新建输入区增加位于项目左侧的设备选择，项目入口带入对应设备和项目。目标配置沿原只读接口读取，不借用本机模型／智能体／Skill／MCP ID。
- 草稿按设备与项目分区；切换到已有草稿时保留两份内容。本地文件选择转移唯一 owner，已上传引用不跨设备复用。
- 项目创建／编辑／移除／恢复及远端目录选择接入原接口；会话发送、审批、停止、重命名、归档、删除等已有业务操作固定原目标。通知与待处理事项跳转保留设备归属，未开放的管理命令保持不可用。
- 首次物化固定目标、manifest 和原 key；未知结果回查原目标，不自动重发。原生 Runtime binding 保持，只在资源操作中冻结设备并统一加入目标。
- 贯通本机选文件／粘贴图片、上传、消息预览、缩略图、工具／子任务产物、文件下载和导出；消息及已有会话右栏的资源引用带固定目标。
- 远端文件系统打开先下载，禁止远端 native-path；媒体 URL 使用本机入口与正确登录上下文。传输取消和临时文件清理沿原规则，不能误删其他设备的选择或操作。

**最小验证**：受影响前端与原生检查；正式 WebView 完成目标会话创建、本机附件／图片发送、结果预览与下载。选一条未知结果恢复和取消路径核对，切侧栏后继续操作原会话；核对新增项目目录确在目标。模型验证使用隔离配置，若使用受控响应应明确不能代表真实企业模型可用。

**完成条件**：远端会话可完成主要工作和文件交互，操作不受侧栏切换影响；原生文件入口确实经过目标代理。用户已可用远端普通会话，但本机置顶过渡、会话／草稿标签恢复和远端终端仍由后续步骤完成。

### M2 本机置顶与右栏工作状态

**前置**：M1 完成并获用户确认。

**实现**：

- 将新桌面置顶／取消置顶改为现有本机偏好中的设备会话引用，按身份隔离，保存失败可重试。远端旧 `is_pinned` 不决定本机置顶区，也不能让会话从普通列表消失。
- 按已确认技术方案只导入当前本机当前身份的旧置顶；原分页条数推进、导入完成标记与引用原子保存，不修改 Runtime 旧字段或远端状态。普通 Web 继续原范围。
- 侧栏置顶可直接打开原设备会话，切设备不变化；离线／撤权／删除保留可识别入口供移除。
- 现有右栏始终选取正文当前会话／草稿的资源组，项目文件入口使用其设备和项目。移除独立项目 scope、固定右栏选择、侧栏独立“浏览文件”和“返回会话”入口；资源 key、缓存和恢复描述继续固定原身份与设备。
- 更新现有偏好与资源快照解析，验证旧描述归属并备份原偏好。保留窗口布局、主题等无关设置，不静默重置。标签关闭与视图隐藏分开，不同步到目标设备或其他客户端。

**最小验证**：定向检查本机旧置顶跨页导入、远端旧置顶不聚合、身份分区和保存失败；使用隔离偏好样例验证新旧格式恢复。真实界面核对跨设备置顶、当前会话／草稿项目文件浏览、切换及重开客户端后的资源归属，检查长名称／窄窗口关键布局。右栏修复另覆盖通知／历史导航、草稿物化、旧固定选择及无当前会话时的恢复，不关闭隐藏终端或改写其原目标。

**完成条件**：置顶与右栏工作状态属于本机客户端，身份和设备不会串用；普通资源恢复重新核验权限，已清理的临时内容不被当成持久资源。旧数据过渡及回退限制明确，未触碰用户实际数据库。

### M3 终端与工作区收尾

**前置**：M2 完成并获用户确认。

**实现**：

- TerminalController 捕获原设备 client，Shell 列表、source 和 socket 目标一致；复用原 Open、输入输出、ACK、resize 与 close。
- 按技术方案核对首次准入、Shell 列表与 created 的总等待预算，初值远端 90 秒、本机 15 秒；取消及失败结束对应连接，不自动重试输入。
- 终端隐藏／切会话／切侧栏保留进程内 controller 和输出消费；真正关闭、断线、撤权及账号切换按原规则回收。恢复标签显示已结束，由用户重新打开新终端。
- 收敛前面步骤遗留的归属提示、不可用入口、关闭和恢复行为；去掉已由正式功能替代的临时禁用，F02 未开放的管理能力仍不开放。
- 同步受影响模块约束与用户手册；向 F04 交接设备资源引用、右栏生命周期和身份撤销边界，不实现远程桌面媒体或控制。

**简单联调**：

1. 一次短流程覆盖目标终端打开／输入／resize，附件传输期间切回本机侧栏，再从置顶打开原会话；正文、文件、终端目标一致，关闭后目标 PTY 回收。
2. 两个独立登录上下文使用同一目标 Host，分别操作自己的项目／会话与终端；确认不互相顶下线、不串数据。退出或撤销一个用户时，另一用户仍能继续操作。沿用既有用户域，不为此实现单窗口多账号。
3. 选取终端断线／重新打开及客户端重启恢复标签路径；不自动恢复旧 Shell、不重放输入。前面已经通过且未受改动影响的用例不重复执行。

**完成条件**：F03 的设备选择、项目／会话、文件、本机置顶与右栏终端组成实际客户端闭环；关键失败和同设备多用户行为成立。说明所用平台、是否跨机器、模型来源与未测项，用户确认后记录 F03 完成并交接后续 Feature。未进行跨机器或其他平台验证时不得宣称这些场景已通过。

## 五、验证、数据与交付管理

- 验证按所属改动选择类型检查、静态检查和必要定向测试；原生文件／终端须实际 WebView 操作，独立浏览器预览不替代原生结果。只在变更、失败或未解决风险需要时扩大范围，不机械执行全工作区测试。
- 测试数据使用 `.runtime-test/` 下新建的一次性场景，运行前核实实际主机、端口、数据库、表及读取接口。按仓库数据库规则处理隔离数据，不复用用户目录或共享已有测试数据；涉及共享库破坏性操作另行确认。
- 不新增验证报告、输出归档或截图矩阵；本计划与开发进度只保留完成结论、用户确认、未完成项和必要风险。数据库实际影响按操作要求在会话中汇报。
- 共用受控构建缓存，启动测试前检查磁盘；测试服务结束后停止进程，临时数据按实际需要处理，不擅自清理其他任务目录或缓存。
- 各步汇报包含改动、已执行验证、未执行原因和限制。F03 完成不等于 v0.32.0 发布；部署、双平台安装包、签名／发布清单及版本整体验收沿原授权与最终交付安排处理。
