# v0.32.0 版本总结

2026-10-19 用户将遗留统一归入 v0.32.1，并明确确认 v0.32.0 验收归档。本版按实际交付范围验收通过，状态为 **已完成**；未执行的验证及未修复问题继续保留，不补记为通过。

## 完成范围

- F01：Host 主动申请、中心审批与用户分配、在线心跳、用户准入及定向撤销；Desktop、Client 与后台管理接通。M0—M3 已确认，M4 按用户要求跳过。
- F02：本机 Host 经中心代理目标 Host 的 HTTP、SSE、流式文件与终端 WebSocket；沿用目标用户域、流控、取消及不重放副作用的边界，按用户收窄范围完成组合冒烟与交接。
- F03：设备项目与会话切换、跨设备附件与资源、客户端本机置顶、固定目标终端及右栏恢复；右栏已统一跟随正文当前会话／草稿。
- F04：macOS／Windows 原生采集与编码、授权直连查看／控制、显示器选择、同屏共享采集及断开恢复；中心承担授权和信令，不启用 TURN／媒体中继。
- F05：OpenCode 本地与企业配置、目录发现、本机 Chat／Responses 方言及稳定会话身份、企业受限透明转发；正式 Host／中心与模拟上游自动化闭环完成。
- 版本内修复：原生压缩切换本地摘要的截断边界、右栏归属与图片居中、产物列表检查闪烁、置顶运行提示、终端关闭卡住，以及工具参数 JSON 错误的有限反馈纠正。

具体边界及历次确认见[总体设计](总体设计.md)、[开发计划](开发计划.md)与各 Feature 计划。用户本次接受实际完成范围及说明的限制，五项 Feature 随版本收口；原始记录保留，不继续在本版追加实现。

## 验证与交付事实

沿用已经完成的 Rust 工作区默认回归、定向静态与集成验证、双端配置及中心代理检查、正式 WebView 与适用双平台原生采集／构建结果。封版核查补充通过桌面构建与单测、协议及版本一致性、Client 和企业前后台类型检查、Rust 格式及改动检查。本次归档仅检查文档与引用，不重复全量产品测试或扩展实机覆盖。

已有 macOS arm64、Windows x64 0.32.0 测试包及配套更新文件，构建批次和所含修复存在差异，不能由相同版本号推断内容一致；企业中心曾按授权配套更新。Mac 测试包未公证、Windows 未做 Authenticode 签名等事实按各批次记录保留。本次不重新打包、安装、上传、部署、提交、推送或公开发布，也不由历史交付推断所有环境已同步。

软件及应用最低兼容版本保持 0.32.0，存储下限保持 0.30.0，企业协议保持 3，Host 最低构建工具链为 Rust 1.98。归档不变更源码版本声明。

- 已修复事项的安装版人工回归、必要跨 Feature／平台及升级恢复补验、最终候选与配套中心内容核对、更新日志和手册同步均由 v0.32.1 维护。v0.32.0 用户日志仍按原版本保存，发布日期不虚填。
