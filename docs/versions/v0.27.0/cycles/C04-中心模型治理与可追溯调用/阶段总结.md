## 完成结果

- 中心沿用 Host/Desktop 的服务商、模型目录、固定参数及默认模型结构。在线目录持久化，成功刷新整体覆盖，失败保留；固定配置与内置模板独立。
- 内置规格抽取到共享静态 JSON。中心可独立更新并显式重载，非法文件保留有效模板；个人 Runtime 编译嵌入相同初始数据，运行时判断仍由代码承担。
- Chat Completions 与 Responses 透明代理接通当前身份、默认路由和独立控制错误，不隐藏重发；调用索引、请求/响应快照、恢复与保留期策略及正式后台查询形成闭环。
- 企业与个人模式共用模型业务、默认模型、准备和编译路径及客户端页面；配置层统一适配本地数据库或远程中心来源，只读策略限制企业模型编辑与切换。
- 正式 Host 使用当前用户凭据和唯一有效配置；刷新失败保留、明确失效、旧身份迟到响应与关闭保持既定边界。本人改密和管理员重置后，已有登录仍可完成真实模型调用。
- 后台布局按用户反馈统一卡片、字段、表格操作及分页规则；额外修复重复响应 ID 未提前校验导致 Run 无法正常结算的问题，不重放已执行工具。
