## 完成结果

- Host 配置与个人数据分离，按版本升级到用户目录，保留原个人数据；构建时可内置默认中心地址。
- 企业身份接入 Host，同用户各端共享最新中心凭据和 Runtime，不同用户的数据、配置、MCP、Skill 和资源独立。
- 登录后通过独立接口等待初始化；无空闲回收。客户端凭据到期不取消后台任务，主动退出经确认后中断本人在本 Host 的全部任务。
- 本人改密及管理员重置保留已有中心 Token/key，C01 原归档事实保留，新契约已复验。
- Desktop/Web/Client 接通登录、恢复、账号操作和本机管理边界。企业设置隐藏访问密码；账号菜单保留改密与退出；登录页简化，改密按钮位于 footer。
