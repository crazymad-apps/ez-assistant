## 交付范围

1. Runtime 套件沿用统一 `0.27.0` 版本，先生成 Windows Desktop 与随包 Host 的 x64/arm64 MSI、校验摘要和对应源码来源；架构以用户后续指定为准。
2. 企业制品通过 Host 构建变量内置经用户指定的默认中心地址；安装机不依赖构建环境变量。个人/企业沿用相同业务实现，已有模式、中心地址与身份不被安装包覆盖。
3. 后续交付 Center/Admin 单一中心制品、Runtime 各既有平台制品、部署与备份恢复说明；Center 保持独立版本。
4. 在隔离环境完成安装、旧版本升级与恢复以及跨产品兼容核查；最终仍执行版本级跨循环验收。Windows 构建通过不能代替安装或 GUI 人工验收。2026-09-22 用户要求修复新版 Desktop 与后台旧 Host 的交接，提供自动检测及“更新并重启”入口，后续备份和迁移自动完成。

## 完成标准与边界

- MSI 版本、安装范围、Desktop/Host 架构、运行依赖和内嵌 Web 一致，下载回读摘要一致，来源可追溯。
- 企业默认地址实际由制品 Host 使用，显式地址优先，升级保留配置；不嵌入凭据或中心身份。
- 旧数据升级具有完整可读备份和恢复路径；Center 的数据库、快照文件与模板分别核验。
- 发布渠道、兼容下限和独立版本语义符合总体设计；没有用户发布授权时仅生成候选制品。
- 不新增 Agent 能力、不调整已确认身份/上下文语义，不覆盖构建机已有工作目录。候选验收使用隔离数据；2026-09-22 用户另行明确授权本机日常数据升级，按独立备份与核验规则执行，不外推为其他生产库操作授权。
