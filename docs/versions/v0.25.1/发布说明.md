# v0.25.1 发布说明

2026-09-10 用户授权提交、tag 与 GitHub 发布，复用用户手动构建的安装包。

## 本版更新

- 服务商实例统一管理，支持在线发现、手动添加模型、固定参数与重置／删除。
- 补充模型参数模板，统一默认、识图与会话模型选择及推理强度设置。
- 完善 OpenAI Responses 推理状态续传与工具图片结果适配，拒绝重复工具调用 ID。
- 新增按软件版本执行的数据库自动升级、备份与失败诊断；旧模型选择需重新配置。
- 统一表单、模型列表、折叠面板、危险按钮、密码显示及 Markdown 有序列表样式。
- 开发启动和 Host 重启脚本支持指定 Runtime Home。
