# v0.25.1 版本总结

当前状态：已完成。2026-09-10 用户确认验收并接受未复测范围，设计、验收与进度已归档；详见[验收记录](验收记录.md)。未执行发布。

## 交付范围

- 模型管理改为服务商实例、在线发现、固定参数与手动模型；来源字段区分在线模型重置和手动模型删除。在线目录不持久化，失败不保留上次结果。
- 默认／辅助识图／会话模型统一引用服务商与模型 ID；三级管理页、两级快速选择和推理强度菜单共用组件。
- 补充服务商模板与方言适配；OpenAI Responses 支持 reasoning summary、无摘要的加密推理状态续传及原生工具图片结果。代理注入的原生图片生成不在本版接入范围。
- 数据库按软件版本自动迁移，以 v0.25.1 为初始入口；旧模型配置废弃，不做历史模型映射；失败保留诊断，高版本数据库拒绝降级。
- 工具调用 ID 在当前请求 snapshot 范围内校验，重复响应拒绝执行并提示重试。
- 设置表单、折叠标题、模型列表、清空选择、密码显示、危险按钮和 Markdown 多位有序列表统一交互与样式。
- 开发启动／Host 重启脚本支持入参和环境变量指定 Runtime Home；独立测试目录被 Git 忽略。

## 验证与遗留

前端单测 387 项通过；隔离 Web 模型配置与手动模型 E2E 两项通过。Rust 全仓 1435 项通过、26 项跳过，无失败；其余门禁详见验收记录。
真实服务商与桌面交互沿用开发阶段人工验证证据；本轮没有将全部模型、多尺寸、远端、WKWebView 和发布包重新测试记为通过。
验收中发现的旧测试契约已按最新交互修订，不恢复废弃入口或旧服务商类型。未签名、公证、发布、提交或推送。
