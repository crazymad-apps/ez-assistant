# v0.14.1 版本总结：会话资源与子 Agent

## 一、版本结论

- 版本：`v0.14.1`
- 状态：已完成
- 完成与归档日期：2026-08-15
- 统一产品范围：[`v0.14.0 功能设计`](../v0.14.0/功能设计.md)
- 统一实现方案：[`v0.14.0 技术方案`](../v0.14.0/技术方案.md)
- 开发过程：[`开发计划`](开发计划.md)、[`开发进度`](开发进度.md)
- 验收证据：[`验收记录`](验收记录.md)

本版本完成正式桌面端 MVP 的第二交付片：在主会话闭环上补齐会话与 Workspace 管理、Fork 与删除、
附件和稳定文件资源、右侧上下文、运行定位、子任务树及可进入的子 Agent 消息列表。Runtime 继续持有
权威业务状态，Desktop 仅消费分页、分组、脱敏的正式产品投影。

## 二、主要交付

1. 完成 Session rename、pin、archive/restore、反馈、空会话换目录和 Workspace 分组/原生目录操作；
   活动时间只由可靠终结 Run 推进。
2. 完成指定 Assistant Message 的 Fork，以及带影响预览、一次性确认和跨 SQLite/文件系统恢复边界的
   永久删除。
3. 完成原生文件选择、流式附件上传、带安全扩展名的内容寻址 Blob、稳定 Resource ID、受控预览、
   系统打开、目录定位和 Markdown 导出。
4. 完成子任务树、独立子 Conversation 分页、Reasoning/工具详情、子任务 Usage、取消及父 Session
   唯一审批队列；子 Agent 使用二级 Header 和主消息同款列表。
5. 右栏接入主 Session Usage、Workspace、会话附件、子任务和运行记录；工具访问文件不再错误聚合为
   会话附件，旧 Run 通过 around-run 分页定位。
6. 删除私有整份子 Conversation 命令和 Host Web Demo feature、CLI、路由、静态资源及 capability。
7. 将 WebView 测试统一移到 `tests/`，并按前端规范拆分应用壳、消息区、Composer、会话侧栏、上下文
   面板和 MobX Root Store 的超长职责。

## 三、验证结论

版本级门禁全部通过：

- `cargo fmt --all --check`
- `git diff --check`
- `cargo clippy --workspace --all-targets --all-features -- -D warnings`
- `cargo test --workspace`：`854 passed / 0 failed / 7 ignored`
- `cargo doc --workspace --no-deps`
- `cargo metadata --format-version 1 --no-deps`
- Desktop `npm run lint`、`npm run test`：10 个文件、48 项测试通过
- Desktop `npm run test:e2e`：1 个正式临时 Runtime Host 场景通过

- Desktop `npm run tauri -- build --no-bundle`

Tauri release 集成产物为 `target/release/ez-assistant-desktop`。自动化场景使用隔离临时数据，未修改
用户真实 Runtime 业务数据。

## 四、保留边界

- Windows 只保留兼容口子，未做严肃开发、编译、打包或实机验证。
- 7 项 ignored 测试包含真实 Provider 付费调用或显式系统能力 smoke test，本轮未重复执行。
- 签名、安装器和发布级 bundle 由 `v0.14.2` 完成。
- 少数 Markdown/Code/Math/Mermaid 按需 chunk 仍超过 500 kB，进入 `v0.14.2` 性能收口。
- 模型与权限设置、完整原生菜单/托盘/退出语义、桌面安全和可访问性属于 `v0.14.2`。
