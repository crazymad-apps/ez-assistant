```text

cd apps/desktop
```

- Playwright：1 个连接隔离正式 Runtime Host 的端到端场景通过；

  `target/release/ez-assistant-desktop`；

自动化场景使用临时 Runtime Home、SQLite、Workspace、loopback Host 和离线 Provider，未修改用户
真实 Runtime 业务数据。

## 五、人工核对结论

本版本开发和验收期间在真实桌面窗口持续核对并修正：

- Workspace/独立会话层级、搜索、新建入口、固定和活动时间、菜单及行内重命名；
- 多 Step 消息、Reasoning 独立展开、同批工具行、Turn 级操作栏、流式贴底和 Markdown 表格/代码；
- 附件选择、提交、消息上方展示、预览、系统打开、目录定位及不支持类型提示；
- 子任务入口与委派工具相邻但保持独立，进入子 Agent 后使用二级 Header 和同款消息列表；
- 右栏只聚合会话附件，不混入工具访问文件；Usage、Workspace、子任务和运行记录可独立收起；
- macOS 标题栏、traffic lights、三栏固定高度、窄窗口隐藏边栏和滚动条符合当前确认结果。

用户已于 2026-08-15 明确确认当前效果无问题并同意验收归档。
