## 里程碑进度

### M0：Session/Workspace 导航与非破坏性管理

- 目标：让用户在 Workspace 分组中管理可恢复的会话状态，并保持 Runtime 权威结算。
- 影响模块：`apps/desktop`、`apps/runtime-host`、`assistant-protocol`、`assistant-runtime`
- 状态：✅ 已确认
- 实际结果：
  - 协议、Runtime、SQLite/内存 Store 和正式 Host 已支持重命名、固定、空会话换目录、消息反馈；
  - 首条输入生成有界自动标题，用户标题不会被覆盖；固定会话排序、反馈与重启恢复已有自动测试；
  - Desktop 已完成 Workspace 分组/归档页、Header 最近会话选择与行内编辑、会话更多菜单、
    目录选择式新会话、受控打开与复制路径，并显示统一失败反馈；
  - 有历史会话换目录创建新会话，只有完全空会话允许原位换目录；
  - 会话管理能力已进入 Host capability 握手，旧 Runtime 会被明确识别为组件不匹配，不再把
    重命名请求误报为 JSON 解析错误；faulted Session 仍允许重命名与固定等非执行元数据操作。
  - 会话列表时间已统一为最近一次 Run 可靠终结时间；输入接收、正文分段提交、重命名、固定和
    模式变更均不推进该时间，活动 Run 由 loading 替代时间，终结事件后刷新列表时间与排序。
- 当前步骤：M0 已收口并进入 M1。
- 续作点：无。
- 里程碑确认：用户已于 2026-08-14 确认继续开发
- 遗留/风险：构建存在 Markdown/Mermaid/Shiki 大 chunk 警告，不影响 M0 功能；真实 Provider
  测试因需要密钥并可能产生费用而保持忽略。
- 关联版本文档：[`v0.14.1 开发计划`](开发计划.md)

### M1：Fork、永久删除与跨介质可靠边界

- 目标：完成指定 Assistant Message 的 Fork，以及带影响预览和短期确认 token 的永久删除。
- 影响模块：`assistant-protocol`、`assistant-runtime`、`apps/runtime-host`、`apps/desktop`
- 状态：✅ 已确认
- 实际结果：
  - 新增 Fork、删除影响预检、一次性删除确认和删除完成事件；Desktop 完成分叉/删除弹窗与导航；
  - Fork 复制可靠消息闭包和附件引用，复用 Blob 并改写稳定可读路径，不复制 Run 或执行工具；
  - 删除以 Session 目录 staging + SQLite 事务形成跨介质提交边界，启动恢复会收敛中断残留；
  - faulted Session 仍可从可靠前缀 Fork 或永久删除；Fork 不被源会话后续 Run 阻塞，删除仍要求完全空闲；
  - 正式 Host E2E 已覆盖 Fork、进入分支、精确影响预览、永久删除及会话列表收敛。
- 当前步骤：实现、静态检查、全量回归和真实 Host 浏览器验收均已完成。
- 里程碑确认：用户已于 2026-08-14 确认继续开发，现已进入 M2。
- 验证记录：Rust 定向三包测试全部通过（30 + 120 + 66 项及正式 Host 验收，3 项真实 Provider

### M2：附件、文件预览、系统打开与导出

- 目标：完成原生文件选择、流式附件上传、稳定资源引用、受控预览/打开和 Markdown 导出。
- 影响模块：`assistant-protocol`、`assistant-runtime`、`apps/runtime-host`、`apps/desktop`
- 状态：✅ 已确认
- 实际结果：
  - 本地选择路径只保存在 Tauri Rust；WebView 使用临时 selection ID，上传成功后只提交稳定
    Attachment ID，支持取消、失败保留和重试；
  - 附件可在消息列表和右侧上下文预览/系统打开；允许类型、单 Range 和 4/16 MiB 上限由 Host
    统一执行，HTML/SVG、未知类型和非普通文件拒绝；
  - 工具文件使用稳定 Resource ID，Runtime 根据可靠消息回查真实文件；工具详情可预览、打开和
    复制安全显示路径，WebView 不能把任意路径交给 opener；
  - Session Markdown 导出经过 Runtime 脱敏投影、原生保存对话框和同目录临时文件原子替换。
  - Blob 真实文件保留原始安全扩展名；旧无扩展名 Blob 在 Host 启动时原地迁移并修复已知视图，
    macOS 系统打开不需要额外展示副本或副本生命周期。
  - 不支持预览或文件过大时展示友好的能力说明，不再直接显示 Runtime 原始错误；附件与工具文件
    均可通过稳定资源身份在系统文件管理器中定位，WebView 不获得通用路径打开权限。
  - 用户消息附件组调整到正文上方，消息时间仍位于正文下方。
- 当前步骤：自动测试、Clippy、前端 lint/build、正式 Host E2E 和 Tauri no-bundle 构建均通过。
- 里程碑确认：用户已于 2026-08-14 完成桌面验收并确认继续开发，现已进入 M3。
- 验证记录：assistant-runtime 121、runtime-host 69、desktop Rust 7 项通过；Desktop 9 个文件
  36 项单测、1 项 E2E 通过；生产构建与 Tauri no-bundle 构建通过。3 项真实 Provider 测试按
  约定忽略，构建仅保留既有 Markdown/Mermaid/Shiki 大 chunk 警告。

### M3：子任务树、子 Agent 消息和审批归属

- 目标：在父 Session 中观察、进入和控制单层子 Agent，并复用同一套消息、工具和审批语义。
- 影响模块：`assistant-protocol`、`assistant-runtime`、`apps/runtime-host`、`apps/desktop`
- 状态：✅ 已确认
- 实际结果：
  - 正式产品协议新增 `GetChildTaskView`，Session 投影包含子任务树、独立 Usage、pending approval
    数量和取消能力；子 Conversation 支持游标分页和工具详情，不暴露物理 JSONL 或整份私有快照；
  - 主消息列表展示连续子任务树；点击任务后在中栏进入只读二级消息列表，可返回、分页、查看
    Reasoning/工具详情和任务自身 Usage，并可取消仍在运行的子任务；
  - 子 Agent 审批继续进入父 Session 的唯一审批队列；新审批到达会抢占共享底部工作区，从主视图或
    子视图均处理同一审批，不复制阻塞列表；右侧上下文仍以主 Session 为 owner；
  - 实时 child 事件、断线重连和权威快照已接入同一 MobX Store；子视图不提供 Composer 或独立
    Session 生命周期；
  - 私有整份 child Conversation 命令、`web-demo` feature/CLI/路由/静态资源、capability 和专用
    HTTP 验收接缝已删除，`--web-demo` 明确作为不存在的产品参数回归。
- 当前步骤：实现、静态检查、定向回归、正式 Host E2E 和桌面 no-bundle 构建均已完成。
- 里程碑确认：用户已于 2026-08-14 完成桌面验收并确认继续开发，现已进入 M4。
- 验证记录：protocol 30、runtime 121、runtime-host unit 70，v0.10/v0.12/v0.13 正式 Host
  验收全部通过；Desktop 9 个文件 39 项单测和 1 项 Playwright E2E 通过；Rust fmt、Clippy、
  前端 lint、生产构建和 Tauri no-bundle 构建通过。3 项真实 Provider 测试按约定忽略。
