关键验收：

- 模型只需生成 questions，默认即可问纯文本问题；有选择时明确 options，多选显式 multiple，只有轮后才必须写 end_turn。无 callback、布局 schema 或模型编造的内部 ID。
- UI 支持选择加补充、逐题填写后统一提交，无预选/自动答案，发送失败保留填写；不覆盖普通消息草稿和附件。按用户最新要求，问答面板抢占输入区且不可收起；提交或取消确认后才恢复普通输入。
- 轮内答案是原工具结果；轮后工具先记录等待回执并由引擎结束执行，后续答案是新 user message。混合工具批次在执行前拒绝，不能产生相邻副作用。
- 重复回复、取消竞争、断线、Host 重启和排队输入按方案处理；历史工具结果不被事后改写，通知不重复报“完成”和“待反馈”。
- 参数解析通过不等于模型可用性已通过；代表性模型调用、Windows/macOS/Chrome 交互或系统通知联调未执行时须明确保留未验证项。

验证遵循对应模块规范及仓库最低检查，使用隔离无副作用场景。不得为恢复等待重放真实工具；需要存储迁移时先评估影响并遵守数据库规则。M1 完成后汇报实际结果并等待确认，验收结论直接写本文件，不新增报告。
