### 验证入口

- Center：`npm --prefix apps/enterprise-center run typecheck`、`lint`、`build`；构建后在该工程运行定向 Vitest，优先覆盖现有 llm-records/transport/snapshots 及新增 usage 核心逻辑；协议执行 `openapi:check`。
- PostgreSQL：运行 F06 新隔离集成入口，覆盖升级、聚合、权限和真实 HTTP/快照，不直接运行写死旧库地址的历史调用集成测试；数据库安全核对、备份验证与实际影响在会话汇报。
- Admin：SDK 生成后执行 `genapi:check`、`typecheck`、`lint`、`build`，补充必要的查询口径/身份竞态测试；真实浏览器验证统计到调用明细及正文链路。
- 联合验证：两种协议的代表性真实上游 usage、F01 多次请求消耗；缺少凭据或现场访问时明确保留未验证项，不把模拟结果写成完成。

### 完成判定与 Review 重点

- 满足版本验收第 7 项，汇总、时间桶、分组、调用明细使用同一筛选与精确数字；服务商与模型始终作为一个联合维度。

- 没有重复入账、透传内容变更、额外中心重试或普通用户越权；资源预算、异常结算、保留期变化与升级路径符合技术方案。
