# v0.33.1 版本总结

2026-11-16，用户确认整体验收结果及保留限制，版本完成归档；尚未正式发布。

## 实际完成范围

- **F01 历史阅读与缩略导航**：默认每页 10 个完整 Run 合批，按序补齐历史并定位；左侧缩略条目以真实用户输入及紧随 Run 的最后一段正文为主体，索引与预览按需读取。移除重复的“继承”文案，原只读限制保持。
- **F02 用户消息编辑重发**：工具栏支持复制和完整输入编辑，复用底部输入框与发送按钮，编辑时显示专用抽屉；可靠裁尾后重新执行。已提交输入及请求身份随会话历史保存，SQL 保留暂存输入和未完成控制。
- **F03 介入与运行打断**：Enter 普通发送／排队，Ctrl + Enter、macOS Command + Enter 和队列项“介入”打断当前运行并接续。取消或失败时已输出的 reasoning／正文可靠保存，连续介入与同键重试沿既有输入机制收敛。
- **F04 侧栏列表排序与分页**：Desktop／Web 项目和会话默认按创建时间、新建在前；同组拖动与恢复默认顺序，分组默认每页 10 条。桌面置顶顺序保存在本机，Web 置顶保存在 Host；修正展开回跳、拖动误触及加载入口样式。
- **版本内补修**：恢复编辑后原生压缩执行窗口，统一文件读取的 Unicode 字符分页，限制超长单行的单次工具返回量。

F04 独立工作树的增量已合入主工作树，同时保留后续压缩重建和字符分页修复。各 Feature 的确认记录及跨 Feature 结论见[开发计划](开发计划.md)。
