# v0.33.1 追加修复：稳定会话缓存身份

日期：2026-11-17。归属 v0.33.1；用户授权修复、打包并要求继续收尾，本项已完成归档。原 2026-11-16 验收记录保留，以下为追加修复及交付事实。

## 问题与范围

现有 OpenAI Responses 请求未携带稳定的 `prompt_cache_key`。已用同一实际会话验证：当前兼容代理在缺少该字段时缓存复用较低，补入稳定 key 后连续请求及下一 Step 能复用缓存。缓存用量的代理、企业中心与 Host 统计一致。

## 实现

- Host 为 `openai` Provider 的 Responses 服务绑定已有 `conversation_routing_id`，不按地址或展示名称猜测 Provider。
- 复用 Runtime 按主会话／子任务派生的稳定标识；Step、Run、重试和服务重建不生成新 key，其他会话及子任务分别隔离。
- Adapter 将绑定值作为 `prompt_cache_key` 默认值；调用方已显式提供时保留原值。没有路由标识时不补值。
- 输入计量和压缩接口不新增该字段；企业中心沿用正文透传。无协议 DTO、配置和持久化格式变更。
