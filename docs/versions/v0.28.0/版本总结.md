# v0.28.0 版本总结

- 日期：2026-09-27；状态：按实际交付验收并归档。用户确认主要功能，明确取消个人版打包、跳过本版发版。
- 设计基线：[总体设计](总体设计.md)；循环与验收边界：[开发计划](开发计划.md)。

## 实际交付

- C01：企业中心及管理后台支持自定义智能体、插件完整包上传/替换、市场发现、受保护下载、上架/下架与审计；中心和后台容器已在测试环境完成部署与数据自动升级核验。
- C02：桌面侧栏、置顶和账号/Runtime 入口调整；新会话工作空间选择、快捷入口装配、草稿归属与冲突处理；工作空间允许只用私有目录并可按原 ID 恢复。
- C03：个人上传和企业市场共用插件安装/更新/卸载流程，包内 Skill/MCP 与自带运行环境接入；本地/企业智能体配置、依赖准备与会话首次发送冻结；Desktop/Web 设置和选择流程。CAD 与企业知识库样例包在 macOS arm64、Windows x64 完成包准入及 MCP 启动调用，业务插件源码和快捷入口模板按约定留在本地忽略目录。

## 验证结论

用户已核对主要产品功能并接受按当前范围验收。C01 的中心/API、C02 的正式 Host 与 Desktop/Web 路径、C03 的个人包安装/重启/卸载、智能体首次发送和双平台代表性 MCP 调用已有定向验证；前端构建和受影响 Rust 检查按各循环记录通过。Windows 浏览器安装插件的随机 UUID 兼容及 Host 文件同步修复已完成定向验证，真实 CAD 包在 Windows 可通过解包校验。

本次归档不把开发测试、包准入或局部 MCP 调用推断为全平台交付验收。完整 CAD 图纸/DWG、插件素材与依赖的再分发许可、企业分发与更新/卸载联合场景、Windows 新安装包端到端复测，以及 C02 的部分原生窗口/高缩放/输入法/远端组合均未完成；详见各循环[阶段总结](cycles/C03-插件与自定义Agent完整接入/阶段总结.md)。

## 发布与后续

个人版 macOS/Windows 打包在构建途中依用户要求停止；此前企业测试候选包不作为本次个人版分发产物。未生成经完整校验的本版个人安装包；未执行 Git 暂存、提交、推送、版本标签、GitHub/npm 发布。本版归档与公开发布分开，后续若继续分发，需以新确定的版本和交付范围重新核对敏感信息、企业业务配置、平台验证及许可。
