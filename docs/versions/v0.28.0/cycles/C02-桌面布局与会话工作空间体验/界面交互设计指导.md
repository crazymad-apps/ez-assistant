## 二、页面与入口

| 入口 | 打开结果 |
| --- | --- |
| 侧栏“新建会话” | 无工作空间新会话页；已有草稿直接继续 |
| 侧栏“助理会话” | 打开当前用户既有主控/助理会话；不可用时展示实际状态，不新建替代会话 |
| 侧栏搜索/筛选 | 搜索活动会话；需要时显式切换为已归档范围，不保留常驻“已归档”页签 |
| 工作空间菜单“在此新建会话” | 对应工作空间的新会话页 |
| 工作空间分组“＋”/菜单“新建工作空间” | 先显示创建窗口，不先打开目录选择 |
| 新会话工作空间选项 | 选择/清空归属，或进入同一创建窗口 |
| 工作空间分组标题“恢复已移除工作空间” | 恢复选择窗口；活动列表为空时仍可使用 |
| 左下角账号与 Runtime | 设置、改密、退出等平级二级菜单 |
| 会话菜单“置顶/取消置顶” | 修改既有置顶状态，条目按结果移动 |

保持已有会话标题操作、子任务导航、搜索、归档动作与按需归档筛选、右侧资源区和审批流程可用；移除侧栏常驻“会话/已归档”切换，本循环不重新安排消息内部结构。

## 三、整体布局与响应

### 3.1 展开状态

```text
┌─────────────────────┬──────────────────────────┬──────────────┐
│ 原生控制/导航按钮组  │ 当前会话标题及局部操作    │ 资源标签/控制 │
│                     ├──────────────────────────┤              │
│ ＋ 新建会话          │                          │              │
│ ◉ 助理会话           │ 对话 / 新会话初始化       │ 既有资源区   │
│ 置顶                 │                          │              │
│   会话               │                          │              │
│ 工作空间             │                          │              │
│   工作空间与会话     │                          │              │
│ 独立会话             │                          │              │
│                      ├──────────────────────────┤              │
│ 用户 / Runtime 状态  │ 已有 Composer/审批工作区  │              │
└─────────────────────┴──────────────────────────┴──────────────┘
```

删除整条应用顶栏及其重复标题，也删除会话列表上方常驻的“会话/已归档”双页签。左栏默认宽 286，最小 220、最大 420，随窗口缩放保持固定；右栏以默认窗口的 380px 为比例基准，与中栏按剩余空间分配，最小 320。中栏目标最小 500；三列之间沿用 8px 可拖热区，视觉分隔保持既有 1px 线。

三栏顶部统一为 42px：展开时，左栏顶部按钮组靠右对齐，在 macOS 原生红绿灯之后依次放置左栏显隐、搜索、后退、前进和最近会话下拉按钮；左栏显隐使用右栏显隐图标的镜像；中栏显示当前标题、更多操作与右栏显隐；右栏放资源标签。顶部按钮统一复用无背景的 InlineIconButton，空白处和非交互文字保持可拖动。其下快捷菜单使用纵向单列，“新建会话”“助理会话”各最小高 32、左侧图标与工作空间行对齐，字重接近会话行，当前项使用既有选中底色。搜索输入与活动/归档筛选仅在独立弹窗中出现，不进入左栏；导航一级分组标题较大且颜色更淡，会话行最小高 32。底部账号块最小高 56，与滚动列表分开，不随长列表滚出窗口。

会话和资源标题使用各自局部顶部高度，不新增跨列菜单条。Windows/Linux 窗口按钮置右上角，占用 3×42px 的明确热区；资源标题或会话右侧工具给它留位置，不叠压关闭按钮。

### 3.2 折叠与窄窗口

- 左栏由用户手动收起后宽度缓动至零、不保留导航轨；显隐、搜索、后退、前进和最近会话按钮整体移至中栏标题左侧。macOS 原生红绿灯随之处于中栏顶部左侧，中栏按钮在其命中区右侧保留清晰间距；Windows/Linux/Web 不保留该空白。
- 左右栏的显隐均使用短暂宽度和透明度过渡，并尊重系统的减少动态效果设置；切换时保留当前会话、草稿、资源内容和左栏列表滚动位置，不触发 Runtime 动作。
- 窗口缩放时左栏不自动隐藏。中栏与右栏先按比例调整宽度；若剩余空间不足以同时满足 500 与 320 的最小宽度，仅自动收起右栏，重新放宽时恢复。左侧由用户收起后按零宽计算。
- 原生窗口最小宽度调整为 920，确保左栏即使手动放大到 420，中栏仍能保持至少 500；最小窗口中右栏收起、左栏保持显示。Web 浏览器无法强制窗口下限，极窄时中栏占满左栏之外的空间并允许低于 500，选项换行。
- 浏览器缩放至 200% 或短窗口时允许内容区/窗口正文滚动，标题和确认按钮可达；不通过缩小点击热区维持一行。

### 3.3 原生控制

macOS 保留现有 Overlay 与系统红绿灯，不绘制彩色圆点替代。优先沿用 `{x:14,y:23}` 配置，展开时红绿灯位于左栏，收起时位于中栏左侧；按钮组分别从预留命中区右侧开始。全屏、恢复窗口、系统缩放后按钮不得与导航叠加。

Windows/Linux 保留原最小化/最大化或还原/关闭 glyph 与交互。三栏顶部整行的空白及非交互元素可拖动，按钮、输入、选项与菜单不属于拖动区；右上角窗口控件不得遮挡资源栏显隐按钮。Web 不显示这些控制，也不模拟双击最大化。

### 3.4 快捷菜单与历史查找

展开态在会话列表前纵向显示两个一级快捷项：

1. “新建会话”：加号/会话图标，点击直接打开无工作空间草稿，不带工作空间下拉箭头；工作空间选择留在初始化页，指定工作空间的新建入口仍在对应分组。
2. “助理会话”：助理图标，点击打开既有主控会话。当前已选中该会话时显示选中态；加载中、不可用或无权限时保留入口并用 Tooltip/短状态说明，不创建第二个会话。

搜索图标紧邻左栏显隐按钮右侧，并具有可访问名称。点击后打开独立搜索弹窗并聚焦输入框；左栏收起时也不为搜索展开左栏。弹窗默认范围为活动会话，可显式切换“已归档”，结果区域显示范围、数量、分页和退出动作；选择结果后关闭弹窗并进入该会话。侧栏不再显示“会话/已归档”双页签，也不把归档会话混入默认分组。归档动作本身继续位于会话操作中，避免“入口变简洁”被误解为删除归档能力。

左栏收起时不保留快捷项图标或账号块；它们随左栏重新展开恢复。顶部按钮组键盘顺序为显隐 → 搜索 → 后退 → 前进 → 最近会话，下方继续为新建会话 → 助理会话 → 会话列表。

## 四、账号与连接菜单

左栏底部账号块：第一行用户显示名（长名省略，悬停可查看），第二行状态点＋短 Runtime 状态；Host 名称在有歧义或菜单展开时显示。左栏收起时账号块一并隐藏，可访问名称为“账号与 Runtime”。

菜单锚定账号块，优先向上展开，宽 260，最大高度为视口减 24，必要时内部滚动。菜单分组如下：

1. 身份和 Host 摘要，不重复可见的整段文案。
2. 设置、修改密码（适用时）、打开 Web 端（Desktop）。
3. 故障时提供重新连接，不重复展示左下角已有的 Runtime 状态。
4. 退出登录。

设置、修改密码、退出登录保持同一级，不以“账号设置”再套一层。菜单不能一点击就停止 Runtime；既有生命周期动作仍使用原确认流程。应用版本在设置内展示。

连接中用既有 loading 样式，失败用现有错误 Token和可读文字；颜色不是唯一含义。账号失效回登录页时整个业务壳层销毁。企业 Runtime 初始化失败沿用现有失败页，不为显示菜单创建假侧栏。

键盘 Enter/Space 打开，方向键定位、ESC 关闭并还焦点；打开改密/退出对话框后焦点交给新窗口。退出确认继续显示当前账号、Host、本人任务和各端登录影响。

## 五、置顶与会话导航

分组顺序为“置顶 → 工作空间 → 独立会话”；现有 Controller 不再作为列表内的“主控”分组重复展示，由上方“助理会话”快捷项承担入口。分组标题、折叠箭头和行间距复用独立会话样式。置顶为空时整个置顶分组不显示。

会话菜单使用“置顶”“取消置顶”，不再出现“固定会话”。置顶行正常显示标题及时间；运行时用常显 loading 取代时间。置顶、普通会话和工作空间行的操作位共用右侧对齐轨道，鼠标悬停或键盘焦点进入行时显示操作并暂时让出状态位，触屏设备保持状态和操作可见。原工作空间归属放在 Tooltip/菜单摘要，避免每行增加固定副标题。独立会话注明“无工作空间”。

置顶成功后从原分组移走，选中态随 Session ID 保持；取消后回原分组并展开该分组以使条目可见。请求中禁用重复动作，失败恢复 Runtime 投影并显示简短错误。

搜索态展示当前筛选范围的结果列表，不额外复制置顶分组；命中行仍可识别置顶。默认活动范围，只有用户在搜索/筛选中显式选择时才查询已归档；关闭归档结果后回到活动会话列表。加载更多沿用原规则，尾部加载提示只出现一处，不给每个分组添加独立分页按钮。

## 六、新会话初始化

### 6.1 布局

新会话中栏为单一编辑区域，最大宽 880，左右边距 24，窄窗口缩至 16。标题、快捷入口和输入框作为一组靠中栏底部对齐；可用高度不足时从顶部开始滚动，不裁切工具栏。

```text
           今天想完成什么？

   [整理文档] [使用技能] [使用 MCP 服务]

   ┌ 工作空间：无工作空间 ▾ ────────┐ ← 复用 Composer 上方的浮层抽屉；C03 在同行接入 Agent
   ┌─────────────────────────────────────────┐
   │ 输入需求……                              │
   │                                         │
   │ 附件 / 引用 / 已选能力                   │
   │ ＋  执行设置           模型/思考  发送   │
   └─────────────────────────────────────────┘
```

标题 24px、单行，空白间距 24；快捷入口高 32、间距 8，可换行。工作空间和未来 Agent 选项置于输入框上方的同一浮层抽屉，沿用 Composer 现有抽屉外观，不在输入框内堆放下拉控件。工作空间入口高 32。输入区沿用既有自动随内容增高和超限内部滚动，不为新会话单独设置固定最小编辑高度；底部工具栏保持既有按键和样式。

抽屉与输入框的 10px 接缝属于既有 Composer 外壳；新会话只在自身抽屉抵消该接缝，使可见工作空间控件的上、下留白一致，不修改 SelectionPopover 或普通会话抽屉。新会话顶部标题栏不重复显示“新对话”及工作空间标签，归属只在输入框上方抽屉展示；顶部仍保留导航、拖动区及窗口/布局操作。

窄屏模型名称截断，完整名可查看；工作空间和未来 Agent 控件换行，不把发送按钮移出输入区。C02 不为 Agent 留可见空框，不展示插件安装假状态。

### 6.2 工作空间选择器

工作空间选择器不是普通 select：使用 Composer 私有的搜索列表，复用 AnchoredOverlay 的 Portal、锚点定位和视口边界。浮层宽约 360、列表最大高 320；顶部搜索，主体只列活动工作空间，底部为“新建工作空间”。“无工作空间”不作为列表选项。支持按自定义名称和目录最后一级搜索；当前项有选中标识，已有草稿项标记“有草稿”。

工作空间行并列显示自定义名称及用户主目录的最后一级名称；不展示完整路径。没有用户目录时显示“仅私有目录”。只有名称与末级目录仍相同的多个选项才补短标识，避免无法辨认。

未选中时入口显示“选择工作空间”和下拉箭头；选中后名称与 close 操作组成同一颗完整圆角胶囊，共用背景和焦点外框，close 是胶囊内部的独立命中区，操作名为“清空工作空间选择”。点击名称仍可重新打开列表；清空沿用草稿移动/冲突保护，不是删除工作空间。浮层搜索、选项和新建区使用统一水平对齐与整幅分隔线；不默认高亮第一项。

目标已有草稿时弹 440px 冲突窗口：标题“该工作空间已有草稿”，正文“当前内容不会覆盖已有草稿。”；按钮为“取消”“打开目标草稿”。补充说明后者会保留当前草稿。正文不展示其他账号或 Host 内容，不提供覆盖/合并按钮。

系统文件选择或上传仍在进行时，工作空间控件禁用并说明“文件选择/发送完成后可切换”；不清空现有输入。

### 6.3 快捷入口与选择反馈

首批入口固定在客户端：

- “整理文档”：空输入时填入可编辑文本“请整理我提供的材料，提炼要点，并给出清晰的结构。材料：”；已有文字时打开模板预览，按钮“取消”“追加到末尾”，不自动发送。
- “使用技能”：打开原技能选择器，按当前工作空间加载；选中后用原 Skill 标签展示、可移除。
- “使用 MCP 服务”：打开原 MCP 选择器，选中后用原服务标签展示、可移除；为空可去现有设置。

选择替换已有同类能力时提示将替换的名称；输入文本、附件和其他执行设置不变。列表加载失败显示“加载失败，重试”，与“没有可用技能/服务”区分。

切换工作空间后旧能力不可用时保留标签，使用既有错误样式和“当前工作空间不可用，重新选择或移除”，不偷偷删掉。发送禁用直到解决；无需展示底层 JSON 或依赖信息。

### 6.4 首次发送状态

| 状态 | 界面 |
| --- | --- |
| 空白 | 显示快捷入口与初始化选项；无真实可提交内容时发送禁用 |
| 正常编辑 | 所选项直接可见；附件/引用/文本按既有行为编辑 |
| 发送中 | 保留内容、显示进度，禁用改变本次载荷的操作；不出现空历史会话 |
| 明确未提交失败 | 保留内容，显示原因和重试；允许修正相关选项 |
| 发送结果待确认 | 提示“发送结果待确认，请重试确认”；保留冻结内容，主按钮“重试确认”，不得修改归属、模板、文本、附件或清空草稿 |
| 成功 | 进入真实会话，正常消息与 Composer 布局接续；若用户已切走，不强制抢走新导航 |

结果未知不使用“发送失败，请重新创建”的文案。允许用户查看其他草稿，返回时仍显示待确认；不新增草稿列表或重启恢复承诺。

## 七、工作空间创建、编辑与恢复

### 7.1 创建/编辑窗口

复用 WorkspaceEditorDialog，宽 600、最大宽 `视口 - 32`，最大高 `视口 - 48`；标题区 52、底部操作区 56，内容区独立滚动。名称输入高 36，初始聚焦；名称最多 80 字，沿用原校验。

窗口初始：

```text
新建工作空间                                  关闭

工作空间名称
[请输入名称                                  ]

工作目录（可选）                    [添加目录]
仅使用私有目录
未选择工作目录时，任务文件保存在工作空间私有目录。

                              [取消] [创建]
```

添加目录打开对应平台选择器；取消后仍停留创建窗口，不丢名称。首次选目录且名称为空时填入目录名；已有名称不覆盖。选中后展示有序目录列表，每行路径可截断并查看完整值，首项标“主要”，后续项提供设为主目录/顺序调整。

每项均可移除，删除最后一项显示上述私有目录空态；它只修改表单，不删除磁盘目录。仍有附加目录时移除主项，下一项成为主目录，列表即时标识，不产生无主附加状态。

编辑窗口保持同一结构，底部按钮为“取消”“保存”；目录有改动时显示“已有会话继续使用原目录，新会话使用更新后的目录。” 名称改动不显示此提示。

私有目录路径只有保存成功后才能展示；不能在创建前猜一个路径。表单错误放在相关字段下，保存失败放在正文底部；保存中按钮 loading、禁重复提交/关闭。网络结果不明确时提示先检查工作空间列表，不自动重发创建。

### 7.2 工作空间列表与实际位置

无用户目录工作空间用同样文件夹图标和名称，不设计新的类型徽标。“仅使用私有目录”只在选择器、编辑/详情及 Tooltip 等需要判断的位置显示。

“打开工作目录”“复制目录路径”作用于当前有效目录；原生本机可以打开系统目录，Web/远端保持现有 Host 浏览/复制能力，不打开本机错误路径。会话右侧上下文显示其冻结位置；与当前工作空间不一致时沿用已有差异提示。

新建终端依其入口取当前工作空间或冻结会话位置。随草稿移动的已开终端仍在原目录，终端信息/标题可查看启动位置；不暗中重开 Shell。

### 7.3 恢复窗口

仅从工作空间分组标题的恢复按钮打开“恢复已移除工作空间”，不在单个工作空间菜单重复设置入口；所有活动工作空间都被移除时仍可使用。窗口宽 560、最大高 560，列表可滚动。列出原名称、目录摘要/仅私有目录、原 ID 和移除时间；每项有“恢复”，不要求手输路径或名称匹配。

恢复中禁用该项重复点击，失败在原项显示原因，成功移回活动列表并保持原身份，不创建新会话。列表加载失败有重试，空列表显示“没有可恢复的工作空间”。

恢复后选择目标工作空间；若是从当前初始化流程进入并打算改变草稿归属，仍执行相同冲突保护。移除提示改为“不会删除目录和历史会话，可从‘恢复已移除工作空间’找回”，有主目录的旧重新添加路径仍有效。

## 八、组件、焦点与状态一致性

- 普通下拉选项使用 SelectionPopover；新会话工作空间使用上述可搜索组合浮层。动作菜单使用 DropdownMenu，模态使用 Dialog；不添加原生 select 或浏览器 confirm。
- 初始焦点：新会话输入框、创建名称、恢复列表首个可操作项；打开目录选择后返回原按钮，冲突取消返回工作空间控件。
- ESC 先关闭顶层浮层；有脏数据的创建/编辑窗口进入原放弃确认，不一路关闭丢数据。
- 按钮最小 32×32，主要提交保持 36px 高；Windows 窗口热区保留 42px。所有图标按钮有可访问名称，状态使用 role/status 或 alert，不能只靠颜色。
- 长名、长路径、中文输入法候选、200% 缩放、窄窗口和错误长文案均不得盖住发送/关闭按钮。
- 原生浏览器位于右栏时，账号菜单、选择器和 Dialog 进入同一 overlay 遮挡机制；只有相交区域触发原生隐藏，关闭后恢复原页面。
- 身份/Host 切换销毁旧 owner 的浮层与操作回调；目录或文件选择晚到结果不能写入新账号页面。

## 九、交互验收口径与待确认细节

以[功能设计验收点](功能设计.md#七可观察验收点)为主，重点实测以下组合：

1. macOS 左栏完整收起/展开、最小窗口/全屏、红绿灯跨栏位置与账号菜单；Windows/Linux 顶部全行可拖动及窗口控件不遮挡侧栏按钮；Web 无伪原生控件。
2. “新建会话/助理会话”左栏入口、助理不可用状态、归档页签移除及显式归档筛选；快捷入口不新建重复 Controller Session。
3. 活动/归档查询、置顶/取消、分页和搜索，条目唯一且选中态不丢失。
4. 新会话切换/清空，有文字、附件、引用、非默认设置和资源标签的冲突保护。
5. 结果未知重试冻结、发送成功后导航不抢占、身份切换迟到响应隔离。
6. 创建先开窗口、目录取消保留输入、仅私有目录正常执行、多个同名项可区分、明确恢复。
7. 连接失败、空列表、权限不足、失效附件和能力不可用的错误位置、重试与键盘可达性。
