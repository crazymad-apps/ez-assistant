# v0.28.0 C03 界面交互设计指导：插件与自定义智能体

依据已确认的[功能设计](功能设计.md)、[技术方案](技术方案.md)和 C02 当前 Desktop 壳层。本文只约束 C03 的产品交互，不改变独立 Skill/MCP 设置，也不增加会话级插件开关。

## 入口和层级

- 设置导航新增“插件”“智能体”，与现有“技能”“MCP”并列。插件页只管理受管包；包内 Skill/MCP 在详情中只读展示，不能在独立能力页编辑、删除或单独启停。
- 插件页首屏展示已安装项和明确的“上传插件”；已登录企业中心时增加“市场”。列表同时展示来源、版本、整体开关、包状态与能力故障摘要，避免把已安装写成运行就绪。
- 智能体页同时展示“个人”和“企业”来源。个人配置可创建、编辑、删除；企业配置只读，附后台管理说明。名称相同仍分开展示来源，不自动合并。
- 新会话选项行的智能体入口放在工作空间右侧，共用可搜索浮层、键盘选择与清空交互。未选择时显示“选择智能体”，按普通会话发送；选中后原位显示名称及清除按钮，不在快捷入口或输入框内重复展示。候选列表区分名称和来源，底部提供“管理智能体”；既有会话只显示冻结选择，不提供中途切换。

## 新会话与依赖准备

选择智能体只更新当前草稿的选择，不清除正文、附件或其他选项。切换工作空间继续使用 C02 草稿归属与移动规则；迟到的检查结果以发起时的草稿 key、选择和请求序号校验，不能覆盖新选择。已安装插件对当前用户所有会话可用，不随切换卸载。

选中后后台请求 `prepare_custom_agent`；发送前再次请求，Host 在物化时自动核对最新完整配置。单纯的提示词变化不弹刷新确认。准备结果按依赖逐项显示：可用、缺包、未启用、名称冲突或连接不可用；专业软件路径由插件首次调用时自行发现和写入原生配置，不以 Host 未填写路径显示缺项。缺包但没有精确来源时给上传或重试入口；不能用其他来源同名能力冒充。

出现可下载包时，弹窗列出每个插件的名称、来源、版本、大小和摘要。用户确认后把当前精确候选交给 `begin_plugin_install`，不由 UI 改选版本。确认前可放弃；运行中 `dismissible=false`，关闭按钮、Esc 和遮罩均不能关闭，只提供“取消”，并持续读取 Host 操作状态。取消请求后等待 Host 报告终态才允许关闭。进度区分下载字节与准备、提交、清理阶段；成功、失败、取消后均可关闭。失败保留草稿并提供重试或清理入口；完成安装或配置后不自动发送。

用户发起发送后，插件首次调用时发现的配置或软件问题、能力缺失及运行环境/连接不可用均不阻塞首次物化；只在实际影响使用时展示插件返回的具体指引，保留管理和重检入口。来源删除、身份失效、缺包、显式禁用及来源冲突仍保留草稿，并将焦点留在可处理的状态。网络结果未知时沿用 C02 的原 key 查询恢复，不自动创建第二次发送。用户取消选择后可按普通会话发送。

## 插件详情与数据操作

插件详情将“整体启用”“包内能力”“必要的连接参数”“配置文件（高级）”“更新/卸载”分组。移除通用外部软件路径输入；普通用户无需自行指定软件安装路径或插件配置文件名。插件首次调用时自行初始化配置，失败后再展示插件给出的处理建议。秘密字段只显示是否已设置；原生文件按相对文件名与大小展示，高级用户可按插件说明上传/替换原样文件，界面不猜测文件格式、不提供通用 JSON 编辑器。修改时使用读取到的修订值，过期覆盖需重读。

卸载确认明确默认保留配置和运行数据，另设“同时清除”复选项；两者都不涉及工作空间产物。更新/卸载遇到活动使用时保留当前页面和设置，提供稍后重试。来源不符、中心下架与网络错误分别呈现，不把网络错误写成下架。

## 状态与可访问性

对话框使用现有 Dialog、焦点回收和键盘行为；操作进行时不可关闭但取消按钮可聚焦。窄窗口时详情与进度纵向滚动，底部主要操作始终可达。所有异步状态以当前 Host/账号为范围，切换连接或账号立即丢弃旧页面的请求结果，再从目标 Host 重读；UI 不持有安装成功或配置生效的第二份权威状态。

M4 验证包括鼠标与键盘、中文输入、Esc/遮罩、窄窗、取消/重连、Host/账号切换；实际下载与能力可用性分别核对。

## 会话能力选择

- 技能和 MCP 选择器包含实际可用的插件能力；插件项统一按“插件名 · 技能名／MCP 名称”展示，搜索匹配插件名、能力名和描述。独立能力保持原名称。
- 右侧当前技能面板使用相同插件归属展示；独立技能和 MCP 设置页仍不管理插件内能力。插件只声明外部依赖而未打包的 MCP 不列为已安装服务。
