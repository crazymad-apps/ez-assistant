# v0.33.0 补充修复：更新下载地址

2026-11-06 用户要求下载地址由客户端适配：复用已经配置的企业中心地址，支持后端返回相对路径或绝对 URL。本项是归档后的单独补充修复，不改写原验收结论；软件版本暂保持 0.33.0。

## 范围与方案

- 当前 Host 提供的企业中心地址是更新请求和下载的唯一地址来源。相对路径按中心根地址解析；旧格式 HTTP／HTTPS 绝对 URL 只提供资源路径，不改变实际下载中心。
- 下载路径仍须与已验签清单的平台、版本、updater 用途对应；拒绝凭据、查询参数、片段和非 HTTP(S) URL。清单签名、制品签名、大小及摘要校验保持。
- 原生客户端先有界读取并验证更新响应，再把补全的 URL 交给 Tauri 安装能力；安装前复核走相同规则。无更新仍使用 HTTP 204。
- 现有 Tauri Updater 2.12.0 在应用验证前直接解析绝对 URL，且安装上下文不可由外部构造。采用同版本受控依赖补丁，提供从已读取响应创建 Update 的入口，复用原有版本比较、平台选择和安装实现；不新增代理服务或安装器。
- 本项先调整客户端，中心现有绝对 URL 响应可继续使用，无需更改现有数据库、中心配置或分发接口。已安装的旧客户端不会自动获得此修复，需另行交付修复包或纠正旧中心配置后完成首次升级。

## 单一里程碑

🟨 实现与定向验证完成，待用户确认：业务层接管接口读取和地址解析；根相对路径、普通相对路径及旧格式绝对 URL 均绑定当前中心，非法地址与错误制品路径被拒绝。真实 SDK 候选创建、签名保留和更新模块回归通过，桌面端严格静态检查及格式检查通过。依赖发布包仅修改响应接入点，原平台安装实现保持。

未实际替换或重启用户安装的客户端，未执行 Windows 原生安装验证。需要显式隔离 Host 二进制的进程交接测试沿用现有跳过条件；本次未修改安装交接逻辑。

不包含重新打包、部署、发布或实际安装；完成后汇报验证及交付限制，等待用户确认。
