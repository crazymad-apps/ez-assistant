  写入、迁移或备份操作；测试数据随 TempDir 回收。

`--no-bundle` 只验证构建；本轮另外完成的本地 App/DMG 见第七节，不覆盖原生交互验收。

本轮关闭的问题：

1. 技能用例原先读到本机 `logo-generator`，且固定断言 `skills[0] == review`。现将子进程 Home 隔离，
   显式校验仅两个 fixture 技能可见、目标按名称存在；既有激活、禁用、Fork 与重启断言保留，2 项通过。
2. MCP 工具超时原先调用 Run 共用 token 的 `cancel()`，造成 Run 意外取消。调用现在使用 child token：
   用户停止仍向下传递，单次工具超时不向上取消 Run；模型收到 `remote_may_have_executed` 错误，
   不自动重放。该问题先由正式 Host 故障用例复现，再修复并通过双 Transport 回归。
3. 用户要求工具执行时限作为缺省而非最大值：默认仍为 120 秒；Server `toolTimeoutMs` 填写后直接
   覆盖，可长可短，清空恢复继承；主配置和服务配置都去掉 10 分钟业务上限，只接受正的安全整数毫秒。
   覆盖缺省/更短/更长/30 分钟、非法数值、导入与快照往返、Registry 实际执行时限及浏览器保存/清空。
   连接、目录、关闭时限保持原边界，没有新增无限等待或模型任意修改配置的能力。

人工检查建议在隔离验收环境执行，使用临时会话和测试服务；不要为验收删除现有 Pencil/Blender 配置。

- [ ] **设置页**：列表、详情、导入预览、冲突确认、未保存草稿测试、secret 保持/替换/移除、脏表单离开；

  新会话与现有会话均可用。
- [ ] **审批与详情**：显示服务、真实工具名和完整参数；拒绝不执行，允许一次仅本次生效，不扩大为整个服务权限。
- [ ] **刷新队列**：`/mcp refresh` 立即可见；审批阻塞时不消费，解除后按序执行；不创建新 Run，控制结果可展开。

  下拉列表无内层 padding/圆角；历史标签、Fork 和重启后的投影不漂移。组合标签展示可先不发送。
