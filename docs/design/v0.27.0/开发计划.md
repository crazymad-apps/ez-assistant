## 三、交接与阶段收口

- C01/C02 代码、协议、数据库、锁文件及验证环境按总体设计分工；共享文档由 C01 汇总。不操作另一会话工作树或提交其未完成改动。
- C01 内后端/前端文件归属及契约交接见其开发计划；后端合同单点维护，前端视觉变化不自动修改权限或 API。
- 各循环进入实现前确认自身设计与开发计划；所有里程碑通过后仍需循环验收、用户确认、明确授权提交和阶段归档。
- 并行例外仅覆盖已经明确授权的工作；C03—C06 依赖收口后逐个进入设计，不由本总台账自动批准。

## 四、总版本验收与发布

所有循环归档后执行总体设计 A01—A10 的跨循环验收，覆盖正式 Host/客户端、真实 Center、个人回归、数据隔离、模型流、升级恢复和独立版本兼容。只完成后台或 API 不算企业版本完成。未执行平台及风险如实登记；总版本确认后归档，制品发布另获授权。
