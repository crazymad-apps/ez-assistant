## 对新版设计的影响

1. 在线列表用于发现模型身份，接口元数据用于预填；不足部分可参考厂商文档手动编辑并保存。
2. 固定配置表达用户确定的运行参数。文档最大值、API 默认值、账号／套餐限制、用户运行上限
   必须分别描述，不把“最大输出”与当前 max_tokens 请求预算混为一谈。
3. 保存是一条完整标准化记录，后续刷新不会改写；重置删除记录，回到当前在线数据及显式标注来源的模板预填；两者均缺时显示待配置，不恢复旧 TOML 值。
4. 思考模式是否可关闭、强度集合／默认值及工具／图片能力可在模型配置页确认；协议字段名与编码
   方式仍属服务商，不能通过模型表单自行注入方言。
5. 文档说明不能代替真实调用验证。本轮不为证明最大窗口发送巨量 Token；后续用用户确认的
   合理运行参数做最小文本／工具／图片联调，并单独记录没有实测的上限。

- vLLM／本地部署由部署事实决定，不按模型名称植入官网限额；未收录型号保留待配置。

### OpenAI Responses 能力补齐（2026-09-09）

- OpenAI Responses 推理请求显式发送 `reasoning.summary: auto`，展示返回的推理摘要，不能将其称为完整原始思考过程。其余兼容方言不自动附加该字段。
- 支持图片的已知 OpenAI 模型在 Auto／Responses 接入时预填 `native_tool_result`；显式 Chat Completions 接入仍预填 `follow_up_user_message`。Responses 原生工具结果以 `function_call_output.output` 内容数组携带图片，复用现有编码。
- 已保存固定配置不被模板覆盖；人工验收前手动修改图片传递方式或重置后重新保存。CLI Proxy 透传行为由用户实测，不等同于官方接口能力。
