## 下载页没有我的平台 {#download}

当前中心可能尚未发布该平台的可用安装包，或现有版本不符合兼容要求。先确认设备架构，刷新下载列表，
仍不可用时联系管理员。某个平台有包不代表其他平台也已发布。

## 点击下载后没有完成 {#retry}

先看浏览器下载记录。网络中断、文件已撤回或服务器不可用时，刷新安装包信息后重试。
页面提示“由浏览器接收文件”仅表示开始交接，不是下载或安装完成证明。

## 窗口关了，为什么还在运行 {#background}

关闭窗口默认隐藏到托盘；仅退出客户端也不会默认停止后台 Runtime。
安装或手动更新前，从托盘选择“退出桌面客户端…”，再选“退出并停止 Runtime”，等待完全退出后再安装。
详见[关闭窗口与后台运行](installation.md#background)。

## 重装时需要删除数据目录吗 {#data}

不需要。默认数据目录是当前用户主目录下的 `~/.ez-assistant`，与应用安装目录分开，重装或更新时应保留。
备份前先停止本机 Runtime；项目文件可能在其他目录，需要一并保留。路径与打开方式见[默认数据存储位置](installation.md#data)。

## 企业登录或模型不可用 {#enterprise}

核对企业中心地址、网络、账号状态，以及管理员是否已配置可用模型。不要将服务商 API Key 当作企业登录密码。
登录选项保存结果不明确时，先重新检查；不要因为界面超时就反复覆盖配置。

## 插件装好了但不能使用 {#plugin}

检查是否启用、支持平台、最低 Host 版本与依赖状态。企业市场的可见版本以中心实际发布为准。
涉及外部 CAD 或知识库服务的任务，还需要这些条件可用。见[插件使用说明](plugins.md)。

## 日志和手册不是同一个版本 {#content}

更新日志随本中心已发布版本展示；手册是一套独立维护的当前说明，文章标注适用版本。
撤回安装包会停止下载，但不会删除已发布日志，也不会切换手册。

## 文件或预览与预期不同 {#result}

把目标文件、预期效果与发现的问题补充到会话中，要求核对实际输入和结果。
平面布局示意、三维预览和报价文件各有适用范围；有疑问时保留原件，明确修改对象后再继续。
