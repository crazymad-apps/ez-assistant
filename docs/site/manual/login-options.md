id: login-options
title: 切换个人与企业登录
updated: 2026-10-13
applies_to: v0.31.0
---

在桌面应用首页选择“本机 Runtime”，点击“这台电脑”卡片内的“登录选项”。

1. 选择“个人模式”或“企业模式”。企业模式下填写企业中心提供的访问地址。
2. 点击“保存并重启”，核对变更及重启影响，再确认应用。
3. 等待提示“登录选项已生效”，然后进入项目或使用企业账号登录。

重启会中断这台电脑 Runtime 上所有用户的任务，并断开客户端连接，任务不会自动继续。
修改模式或企业地址时，旧中心绑定会自动清除，下次企业登录重新绑定，原用户数据保留。
如果此前启用了非本地访问，保存这些变更会关闭该选项；需要时可在登录后的访问设置中重新开启。

切换到个人模式会保留已保存的企业中心地址。以后切回企业模式，包括关闭并重新打开应用后，
无需再次输入。编辑中来回切换模式也会保留当前地址草稿；取消编辑会放弃未保存的修改。

没有修改时无需保存。如果显示“已保存，待重启”，可以核对后应用已有配置。
遇到“结果尚未确认”，先点击“重新检查”；配置已经保存不代表重启已经成功。
若提示配置发生变化，重新载入并核对后再操作。

登录选项仅管理这台电脑的模式与企业中心地址。普通 Web 页面和“其他 Runtime”入口不提供此项。
完整设置从进入项目后的账号菜单打开。
