## 新建计划 {#create}

在左侧「助理会话」旁打开「定时任务」，确认执行设备，点击「新建计划」。

- **Agent 型**适合整理日报、生成文件等需要助理判断的工作。填写指令，选择模型和工具权限。每次执行使用独立的临时会话。缺少必要授权或输入时，本次执行会结束，可在记录中查看原因。
- **脚本型**适合运行已有命令。填写执行设备能运行的 Shell 命令。若命令使用项目中的脚本，请选中对应项目，以便使用项目路径。

选择一次、每日或每周的执行时间，再核对显示的下次执行时间。打开「将执行结果返回主控会话」，助理就会整理当次结果并汇报。关闭时可在计划详情查看结果。

## 查看执行与文件 {#results}

打开计划，点击一条执行记录。Agent 型显示任务汇报和已交付文件，脚本型显示标准输出、标准错误和退出状态。当 Agent 已完成而后台命令仍在运行时，可在记录中查看输出或停止执行。

同一计划仍在执行时，下个时间点会留下一条跳过记录。关闭客户端后，设备上的 Runtime 在线且登录有效，计划仍会执行。设备休眠或 Runtime 停止期间错过的时间点会跳过。

## 暂停或删除 {#manage}

暂停会取消后续自动触发，当前执行可继续完成。要试跑一次，在计划详情点击「立即执行」。删除计划会停止当前执行，并清除执行记录及专属文件。已送达主控会话的消息和附件仍可从会话打开。
