## 选择系统与芯片 {#choose}

首页下载按钮会根据当前设备显示对应系统；识别为 macOS 时默认选中 Apple Silicon 版本，
Windows 在能识别芯片时自动选中对应版本，也可以手动切换。未自动选中时，按下面的表格确认系统与芯片。

也可打开[下载页](/download)选择。页面显示的是这个企业中心已发布、可下载且兼容的版本。

| 设备 | 下载选项 | 如何核对 |
| --- | --- | --- |
| Apple 芯片的 Mac | macOS · Apple Silicon | 在“关于本机”查看芯片 |
| Intel 或 AMD 处理器的 Windows 电脑 | Windows · x64 | 在“设置 → 系统 → 系统信息”查看系统类型 |
| ARM 处理器的 Windows 电脑 | Windows · ARM64 | 在系统信息中确认 ARM 处理器 |

各平台可能有不同的最新版本。没有对应安装包时，页面会明确提示；不要用另一种芯片的包替代。
客户端支持的平台与每个业务插件支持的平台分别判断，Windows ARM64 客户端不代表所有插件都支持该平台。

## 安装前准备 {#before-install}

先保存正在编辑的内容，等待任务完成。停止 Runtime 会中断本机未完成的任务，并断开连接它的客户端。

**Windows MSI**：点击安装向导的 Install 开始安装后，安装器会关闭这份安装的旧客户端和本机后台。
只打开向导，或在开始安装前取消，不会停止它们。若进程无法停止或文件仍被占用，安装会报错；
退出占用程序后重试，不要删除 Runtime 数据目录。

**macOS DMG**：打开镜像中的“安装 EZ Assistant.pkg”，按系统安装器提示完成安装。开始安装后会关闭这份安装的旧客户端和本机后台；开始前取消不会停止任务。已有配置和会话记录会保留。安装失败时按提示重试，不要删除 Runtime 数据目录。

历史拖放式 DMG 仍需先退出旧客户端，再在 Finder 中替换应用；打开新版后按提示完成后台交接。

需要完全退出时，打开托盘菜单，选择“退出桌面客户端…”，再选择 **“退出并停止”**。
Windows 托盘位于任务栏右下角，图标可能收在“隐藏的图标”中；Mac 托盘位于屏幕顶部菜单栏。

## 安装与首次打开 {#install}

Mac 下载 DMG 后运行镜像内的安装程序，按系统提示授权安装到“应用程序”，完成后正常打开客户端。Windows 下载 MSI 后按安装程序提示完成安装。

如果系统阻止运行，先核对文件来源、平台与管理员提供的签名／发布说明；不要关闭系统安全功能。
下载页“文件详情”提供文件名和 SHA-256，可用于核对下载文件。浏览器开始接收文件不代表已经完成安装。

首次打开后选择本机 Runtime，按[使用模式](modes.md)完成配置。企业地址与账号由管理员提供。

## 关闭窗口与后台运行 {#background}

Runtime 是负责执行任务和保存会话的后台程序，与客户端窗口分别运行。

| 操作 | 会发生什么 |
| --- | --- |
| 关闭窗口 | 新初始化配置默认弹出退出确认，主操作为“退出并停止”；已有关闭偏好保持原值。设置为隐藏窗口时，可点击 Dock、快捷方式或托盘“显示主窗口”恢复。 |
| 保留后台并退出 | 客户端退出，Runtime 继续执行任务；客户端终端及其中运行的进程会结束。 |
| 停止 Runtime | 本机后台任务停止，连接它的客户端断开；客户端窗口可继续保留。 |
| 退出并停止 | 同时退出客户端和本机后台，并中断本机运行中的会话。 |

托盘菜单可查看本机 Runtime 状态。连接远程 Runtime 时，上述停止操作只针对本机，不会停止远程服务。

## 默认数据存储位置 {#data}

本机 Runtime 默认将运行数据保存在当前用户主目录下的 **`.ez-assistant`** 文件夹，即 `~/.ez-assistant`。
它与应用安装目录分开，包含配置、会话记录、已安装插件和技能等数据，不是可以随手清理的安装缓存。

| 系统 | 默认目录 | 打开方式 |
| --- | --- | --- |
| macOS | `~/.ez-assistant` | 在访达选择“前往 → 前往文件夹”，输入此路径。以点开头的文件夹默认隐藏。 |
| Windows | `%USERPROFILE%\.ez-assistant` | 将此路径粘贴到文件资源管理器地址栏；通常位于 `C:\Users\你的用户名\.ez-assistant`。 |

重装或更新时保留这个目录，不要为了替换应用而删除它。需要备份时，先按上面的步骤完全退出客户端并停止 Runtime，再复制整个数据目录。
项目原始文件和生成成果也可能保存在你选择的项目目录中，需要另行保留；只复制 `.ez-assistant` 不等于备份了全部项目文件。

如果已配置自定义数据目录，以实际配置为准。连接远程 Runtime 时，运行数据保存在远程主机上，不在当前电脑的默认目录中。

## 更新客户端 {#update}

企业模式下可从客户端提供的更新入口检查可用更新，并阅读更新日志。已绑定企业中心且有兼容安装包时，
未登录或旧本机 Runtime 的企业协议不兼容，也可以在登录页更新。按提示下载、更新并重启，新版会接续原 Runtime 数据目录。
没有可用更新入口时，可手动下载对应系统的安装包，按[安装前准备](#before-install)操作。

也可以在[更新日志](/changelog)中查看本中心已经发布的说明，通过版本入口查找仍可下载的安装包。
如果某版本不可用，返回下载页查看最新版本；不要反复点击失效的旧链接。
