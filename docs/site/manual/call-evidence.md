管理员进入企业中心的“调用记录”，打开一条调用详情，点击“查看正文”。

左侧按发送顺序展示请求消息卡片。“系统提示词”是本次发送给模型的总体要求；Responses 请求中
对应 `instructions` 字段。用户消息、工具调用请求和工具结果分别展示，关联 ID 用于核对对应关系。
点击卡片右上角“原文”可以查看完整请求；模型参数与工具定义在下方折叠区。

右侧按接收顺序展示响应事件，相邻的文字或工具参数增量会合并，便于连续阅读。
“聚合 N 条增量事件”表示合并的事件数量，不表示 Token 数量或网络分块数量。
点击“查看来源”可核对原始事件；出现异常时可使用“定位首个异常”。

JSON 内容默认以缩进、高亮的代码块展示。单条事件会分开展示事件名和 JSON 数据；
切换“原文”可核对保存的完整字符，关闭“自动换行”可横向滚动。异常或未完整接收的 JSON
保留原样并给出提示，不自动修复；长内容按需继续展开。

“转发完成”只表示 HTTP 正文完整转发，不代表模型或任务成功。结束内容与增量冲突时会保留两份值；
正文截断、坏事件或未收到响应均单独说明。WS 桥接前返回的错误显示在“上游失败帧”中，需单独点击查看。
非文本正文提供字节证据入口；图片、文件引用不会自动加载。

## 设置记录策略

在“调用记录”中打开“记录策略”：

- **关闭**：不采集后续调用正文，已有正文按保留期处理。
- **仅异常与未确认**：保留已观察到异常或无法确认正常结束的调用正文。
- **全部调用**：保留正常与异常调用正文，适合定向排查。

策略在每次调用开始时确定，修改不改变已经开始的调用。正文与调用索引分别设置保留期；
正文过期后仍可能看到调用摘要，但无法恢复原文。缩短期限可能清理已有记录或正文，请核对后确认。

仅异常模式无法覆盖发生在 Runtime 内部、企业中心未观察到的所有失败。排查这类问题时可提前切换
“全部调用”；此前未采集、按策略未保留或已过期的正文不能事后补录。

正文仅管理员可读。收起正文、切换调用或登录身份后会清除当前阅读内容；读取失败可重试，
若正文已经过期或缺失，则不能通过重试恢复。
