插件为助手补充专业资料、工具与可复用的方法。安装后，在会话中说明任务和需要使用的能力即可；不需要自己运行开发命令。

## 安装与启用 {#install}

1. 打开侧栏“插件管理”，或从设置中的“插件”进入。
2. 个人使用可点击“上传插件”，选择管理员或维护者提供的插件包，核对名称、版本和平台后安装。
3. 企业模式可从企业市场选择管理员已发布的兼容插件并安装；定向提供的试用或专用包按其说明获取。
4. 检查启用状态、依赖和配置提示。使用专业智能体时，也要确认其已接入所需插件能力。
5. 新建会话，提供资料与目标，按实际权限提示确认操作，再检查回复和生成文件。

插件运行在当前连接的 Runtime 上。远程连接时，资料位置、软件依赖和网络可达性都以远端为准，详见[项目、会话与文件](projects.md)。

## 选择合适的插件 {#choose}

| 你想完成的工作 | 插件与使用说明 | 主要结果 |
|---|---|---|
|根据库房条件绘制密集架布局|[库房 CAD 绘图](warehouse-cad.md)|可继续修改的 DXF 布局图|
|把平面方案变成直观的空间预览|[CAD 图纸转三维](cad-scene.md)|离线 HTML 预览与分享包|

|查找企业资料并核对原文|[查询企业知识库](gorag-knowledge.md)|回答、文档片段与引用|
|把好用的方法留到下次|[创建可复用技能](general-assistant.md)|保存在个人目录的技能|

## 库房 CAD 绘图资料 {#cad}

从房间尺寸、底图和布置要求开始，生成密集架平面布局。离线 DXF 与 CAD 原生检查分开进行。
[查看准备资料、绘图步骤与示例](warehouse-cad.md)。

## CAD 图纸转三维 {#scene}

将 DXF 转成可旋转查看的空间，支持密集架、设备与桁架展示，后续调整可复用原场景配置。
[查看三维预览与分享方法](cad-scene.md)。

## 通用报价 {#quote}

直接根据需求、方案或 CAD 整理报价，不要求先完成绘图，也不要求另传价目表。
[查看报价步骤与结果检查](quotation.md)。

## 企业知识库与通用辅助 {#other}

需要带来源的企业问答，阅读[查询企业知识库](gorag-knowledge.md)。
想保存重复工作的方法，阅读[创建可复用技能](general-assistant.md)。

## 版本与平台 {#versions}

以下为本次手册核对的插件仓库版本，不代表企业市场已经上架或当前设备已经安装：

| 插件 | 版本 |
|---|---|
|库房 CAD 绘图资料|0.3.6|
|CAD 图纸转三维|2.4.0|
|通用报价|0.3.0|
|企业知识库 · GoRAG|1.0.3|
|通用辅助|0.1.1|

这五个插件的当前清单声明 macOS Apple Silicon（arm64）和 Windows x64，最低 Runtime 版本为 0.28.0。
Windows ARM64、Intel Mac 等其他平台不在当前声明范围内。平台声明不等于已完成所有实机验收，实际可用性以所安装包的说明和运行检查为准。

插件版本独立于客户端版本。遇到不可用提示，先核对实际包版本、Runtime 平台、启用状态与依赖，再参考对应插件页的常见问题。
