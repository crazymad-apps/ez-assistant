同一个客户端可以使用个人模式，也可以连接企业中心。区别在于谁维护可用能力。

## 个人模式 {#personal}

进入个人工作环境后，在设置中配置模型服务商、密钥与模型，按需要上传和启用插件、创建自己的智能体。

项目资料与工具操作由所连接的 Runtime 处理。调用外部模型或知识库时，任务中使用的内容可能发送到对应服务；“本地优先”不表示完全离线。

## 企业模式 {#enterprise}

填写管理员提供的企业中心地址，使用企业账号登录。企业中心统一管理模型服务、插件市场、智能体和客户端安装包。

成员使用中心下发的模型，不必逐人配置服务商密钥；从插件市场按需安装，使用管理员发布的兼容版本。
中心配置的智能体由管理员维护，成员可以查看和选用；可用项取决于当前账号和中心配置。

“统一分发”指统一准备与管理能力，不代表插件会自动执行，也不等于项目文件自动上传到中心。
企业模型请求经过中心代理；管理员可以按记录策略留存调用正文，使用前应了解所在团队的数据使用约定。

## 切换方式 {#switch}

在桌面首页的“这台电脑”卡片打开“登录选项”。模式与企业地址实际变更后，需要核对影响并保存、重启。
已有企业地址会保留，切换不会清空原用户数据。详见[切换个人与企业登录](login-options.md)。

## 本机与其他 Runtime {#runtime}

本机 Runtime 负责这台电脑上的任务。连接其他 Runtime 时，工作目录与工具操作发生在对方主机，而不是当前浏览器所在电脑。

关闭窗口默认隐藏到托盘；仅退出客户端时，Runtime 默认继续运行。安装或手动更新前，应从托盘选择“退出并停止 Runtime”。
操作步骤及默认数据目录见[安装客户端](installation.md#before-install)。
工作目录用于定位文件，不是隔离所有系统访问的安全边界。执行文件修改或命令前请核对权限提示。
