同一个客户端可以使用个人模式，也可以连接企业中心。区别在于谁维护可用能力。

## 个人模式 {#personal}

进入个人工作环境后，在设置中配置模型服务商、密钥与模型，按需要上传和启用插件、创建自己的智能体。

项目资料与工具操作由所连接的 Runtime 处理。调用外部模型或知识库时，任务中使用的内容可能发送到对应服务；“本地优先”不表示完全离线。

## 企业模式 {#enterprise}

填写管理员提供的企业中心地址，使用企业账号登录。企业中心统一管理模型服务、插件市场、智能体和客户端安装包。

成员使用中心下发的模型，不必逐人配置服务商密钥；从插件市场按需安装，使用管理员发布的兼容版本。
中心配置的智能体由管理员维护，成员可以查看和选用；可用项取决于当前账号和中心配置。

“统一分发”指统一准备与管理能力，不代表插件会自动执行，也不等于项目文件自动上传到中心。
企业模型请求经过中心代理；管理员可以按记录策略留存调用正文，使用前应了解所在团队的数据使用约定。

## 切换方式 {#switch}

在桌面首页的“这台电脑”卡片打开“登录选项”。模式与企业地址实际变更后，需要核对影响并保存、重启。
已有企业地址会保留，切换不会清空原用户数据。详见[切换个人与企业登录](login-options.md)。

## 本机与其他 Runtime {#runtime}

本机 Runtime 负责这台电脑上的任务。连接其他 Runtime 时，工作目录与工具操作发生在对方主机，而不是当前浏览器所在电脑。

新初始化配置在关闭窗口时默认询问是否退出并停止本机后台；已有关闭偏好保持。
需要任务继续运行时，选择“保留后台并退出”。
操作步骤及默认数据目录见[安装客户端](installation.md#before-install)。
工作目录用于定位文件，不是隔离所有系统访问的安全边界。执行文件修改或命令前请核对权限提示。

## 企业组网登记（v0.32.0 开发中） {#device-registration}

本节对应尚未发布的 v0.32.0，已发布客户端可能没有此入口。设备登记、用户分配和在线状态已接通；开发版已接入跨设备项目、会话、文件与终端；远程桌面仍在后续开发。

在桌面端连接本机 Runtime 并登录企业账号后，打开 **设置 → Runtime → 企业组网**，填写设备名称并申请登记。此页只显示当前中心，切换中心仍使用原有登录选项／访问设置。等待期间可以继续使用本机工作区，也可以撤回申请。

管理员在企业后台的 **设备管理** 中处理“未登记设备”栏顶部的待审批卡片，确认登记并选择可用用户。已登记与未登记分栏显示，可以分别收起、搜索和翻页；未登记栏只展示在线设备，已拒绝、已撤回和已注销历史记录不再显示为设备卡片。申请人和管理员不会自动获得设备使用权；进入设备详情后，直接在“可用用户”区域通过“添加用户”加入表格，桌面查看／控制权限使用行内开关，点击保存后生效；远程桌面功能尚未开放。

“已登记”表示中心已经确认，“在线”表示 Host 已建立控制连接；设备停用后仍可能在线。移除组网授权或退出组网，不删除本机文件、会话，也不改变原有 Host 直连登录规则。已登记设备可在本机退出组网，管理员也可在设备详情停用或注销；注销后重新申请会生成新的登记。

无图形界面的电脑使用 Client 的 `config → 企业组网`：先启动 Host，配置并启用企业模式，然后在申请时输入企业账号及密码。`status` 可查询登记和连接状态。关闭 Client 不停止 Host，也不自动退出已登录用户。

如果提交结果尚未确认，先查询状态，不重复申请；中心不可达时保留上次结果并提示未更新。退出提示“中心撤销待确认”时，本机已停止目标接入，等待恢复连接后完成中心核实。


## 跨设备工作区与终端（v0.32.0 开发中） {#network-workspace}

在置顶与项目列表之间切换浏览设备，列表默认仅显示在线且启用的授权设备。新建会话时也可在项目选择左侧选择执行设备。项目、独立会话和目录属于所选设备；已打开的正文与右栏资源保留自己的来源，切换侧栏不会把它们搬到另一台电脑。

置顶保存在当前客户端，可以置顶本机或其他设备的会话。右栏标签也是本机工作状态，不与其他客户端共享。附件会上传到会话所属设备，文件浏览和下载从原设备读取。

在目标会话或项目的右栏点击“＋ → 终端”，使用目标设备的默认 Shell，也可在终端工具栏切换其可用 Shell。切换会话或隐藏标签不会结束终端；关闭标签、退出客户端或连接断开会结束对应连接。重启客户端后仅恢复标签，需点击“重新打开”创建新终端；不会恢复旧进程或重发历史输入。连接失败时确认设备和授权后手动重开。
