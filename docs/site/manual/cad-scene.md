把 CAD 平面方案转换成可离线打开的三维预览，直观查看密集架、环控设备与空间关系。也支持桁架梁柱展示和装配关系核查。

## 准备哪些资料 {#prepare}

准备 DXF 图纸；如果只有 DWG，先通过 CAD 导出 DXF。补充单位、层高、架体尺寸、设备型号与安装高度，说明哪些位置必须保留、哪些可以调整。

插件带有密集架样式、设备模型及桁架梁柱模板，常规模型先从内置资源匹配。需要特殊款式时，提供明确参数或有权使用的静态 GLB 模型。图例与实际设备需要区分，不能把图例也算进布置。

运行环境随包提供，无需另装 Node 或 Blender。查看预览需要支持 WebGL2 的浏览器。

## 生成和查看预览 {#use}

1. 安装并启用插件，在项目会话中提供图纸，说明要“按原图还原”还是“调整方案”。
2. 让助手检查图纸与缺失参数，确认设备匹配、尺寸和安装位置；没有确定的条件应列为待确认。
3. 生成三维预览后打开 HTML，旋转、缩放，切换俯视与透视；用图源对照和墙体剖切检查布局。
4. 核对架体数量、设备位置、门窗、安装高度和通道。需要留图时，可保存 PNG。
5. 修改时指出具体对象与范围，并要求保留已确认的位置、尺寸和旧版成果。

## 分享与后续修改 {#result}

交付包含可以直接打开的 HTML 预览，以及同一版本的 ZIP 下载包。HTML 内嵌模型和纹理，无需部署网站即可离线查看。

保留项目里的场景配置、模型和 `scene.lock.json`，便于之后复用已确认的空间关系。预览包用于分享，维护文件留在项目目录；只保留 HTML 会失去部分后续重建所需资料。

## 常见问题 {#faq}

- **预览空白或无法旋转。** 检查浏览器是否支持 WebGL2，以及硬件加速是否可用。
- **墙体或设备缺失。** 让助手检查未支持的图形、图层映射与缺少的模型；不能将缺项当成完整转换。
- **想保持原图位置。** 明确选择原图还原；方案调整可能按确认的编组改变间距。
- **剖切后设备看不到。** 剖切只影响显示，不表示设备已移动或删除。

三维预览用于方案沟通；桁架静态展示不等于承载、行程或运动验证，不能替代工程与安装验收。
