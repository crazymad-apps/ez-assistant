---
id: appearance
title: 切换应用配色
updated: '2026-10-13'
applies_to: '0.31.0'
---

进入项目后，从左下角账号菜单打开“设置 → 外观”，选择默认浅色、Monokai、
Solarized Light 或 Solarized Dark。选择后立即应用并自动保存，无需再点保存按钮。
也可以用 Tab 移到配色卡片，再用方向键选择。

左侧栏、会话、设置、代码、图表和终端会一起调整颜色。切换配色不会清空消息、草稿或
终端历史；图片、PDF、网页内容和内容中明确指定的颜色保留各自外观。
网页自身可能响应系统或浏览器的明暗设置。

桌面端的选择仅保存在当前桌面客户端，退出重开、切换账号或 Runtime 后继续使用。
Web 端按当前浏览器和站点保存，与桌面端分别设置；其他已打开的标签页在重新加载后
读取最新选择。配色不会自动跟随系统明暗切换。

如果提示配色尚未保存，当前窗口仍保留你的选择，可在外观页点击“重试”。
原生窗口外观应用失败时可单独重试。读取设置失败或遇到无法识别的配色时，应用先使用
默认浅色；重新选择配色后才会保存新的选择。
