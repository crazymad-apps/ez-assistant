## 组织一个项目 {#project}

在侧栏“项目”旁新建项目，填写名称并选择工作目录，把相关资料与成果放在便于查找的位置。
创建会话时可以选择所属项目；不需要项目的临时任务可以使用独立会话。

工作目录属于当前连接的 Runtime。远程连接时，请选择远端可访问的目录，不要把本机路径当成远端路径。

## 让任务更容易执行 {#session}

在输入框说明目标、输入资料、限制和交付格式。需要使用指定智能体或插件时，先确认其可用状态。

例如：“根据这份需求资料整理产品选型和数量，生成 Excel 报价单，缺价保持待确认。”

“构建”模式允许在授权范围内修改和执行；“规划”模式适合先分析和制定方案。遇到权限确认时，
核对具体文件、命令和影响范围。需要中止当前任务时使用会话中的停止入口。

## 查看与保存成果 {#files}

会话中出现文件链接时，可以打开资源面板检查预览与文件位置。不同文件格式的可预览能力不同；
不能预览时，用相应的软件检查实际文件。

CAD 布局、三维 HTML 与 Excel 报价可以分别交付，不要求每个任务都经过全部步骤。
提出修改要求时，明确目标文件与需要保留的内容，避免误改其他成果。

## 继续之前的工作 {#continue}

从项目或独立会话列表打开历史会话，补充本次目标。新的任务先核对已生成文件是否仍在原位置，
以及外部资料是否有变化。历史回复不保证文件仍存在，也不代表当时未完成的操作已经完成。

## 从一条回复尝试另一种方向 {#fork}

在助手回复旁选择“从此消息分叉”，确认创建后，会打开保留该回复及之前可靠历史的新会话。
可以继续从分支创建分支，再分别输入新的要求。

继承的历史会标注来源状态；在一轮中途分支时，“截至分支点”表示只保留到所选位置的内容，
后续结果和结束时间仍属于原会话。历史中的旧任务供阅读，新输入从分支独立执行。

删除来源会话后，分支保留的历史仍可阅读。可用的会话附件、工具图片和相关子任务历史随分支独立保留；
已经缺失的资源会显示不可用。工作目录中的外部文件仍需自行保留，继续工作前请核对实际文件。

## 排队、耗时与读取失败 {#loading}

排队轮次显示排队状态，耗时从真正开始执行后计算；重试使用本次执行的起点。
历史没有可靠起止时间时，界面保留未知状态。

读取遇到临时繁忙时会有限重试。仍然繁忙或超时后，可点击“重新读取”或“重试”。
切换会话只切换当前阅读内容，已接纳的后台任务继续由 Runtime 执行。

备份会话时请保留完整 Runtime 数据目录，其中包含会话历史与受管资源；仅保存单个数据库文件不足以恢复全部历史。

升级初始化时会显示数据库检查、备份、历史迁移及恢复阶段；已知总量时显示当前阶段的完成数量。自动升级备份只保全数据库、会话历史和配套配置，项目文件、虚拟环境、依赖与缓存不纳入。上述完整 Runtime 目录备份建议用于用户主动保全全部会话资源，与自动迁移备份的范围不同。
