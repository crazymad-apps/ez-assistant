## 组织一个项目 {#project}

在侧栏“项目”旁新建项目，填写名称并选择工作目录，把相关资料与成果放在便于查找的位置。
创建会话时可以选择所属项目；不需要项目的临时任务可以使用独立会话。

工作目录属于当前连接的 Runtime。远程连接时，请选择远端可访问的目录，不要把本机路径当成远端路径。

## 查看后台命令 {#background}

会话里启动的后台命令可在本轮对话结束后继续运行。打开右侧「当前上下文」的「后台运行」，点击命令查看最新输出。向上滚动可加载更早的内容，滚回底部即可继续跟随新输出。关闭弹窗后命令会继续运行。

要终止命令，点击该行的「停止」。命令结束后，列表条目及临时日志会自动清理。运行记录、技能、子任务、附件和产物可在各自区块翻页。

## 整理侧栏顺序 {#sidebar-order}

项目和会话默认按创建时间排序，新建在前；继续聊天或改名不会改变位置。项目列表、各项目内会话和独立会话分别每页加载 10 条，点击各自的“加载更多”继续查看。

按住条目稍作停留后拖动，可以在同一组内调整顺序；置顶会话也可以拖动。拖到其他组或按 Esc 会取消本次移动。在项目列表、项目菜单或独立会话区选择“恢复默认顺序”，只恢复对应范围按创建时间排序。

项目及组内会话的顺序由所连接的 Runtime 保存。桌面端置顶顺序是本机偏好，可包含不同设备的会话；Web 置顶顺序保存在当前 Runtime。置顶区不提供恢复默认顺序。

## 让任务更容易执行 {#session}

在输入框说明目标、输入资料、限制和交付格式。需要使用指定智能体或插件时，先确认其可用状态。

例如：“根据这份需求资料整理产品选型和数量，生成 Excel 报价单，缺价保持待确认。”

“构建”模式允许在授权范围内修改和执行；“规划”模式适合先分析和制定方案。遇到权限确认时，
核对具体文件、命令和影响范围。需要中止当前任务时使用会话中的停止入口。

## 查看与保存成果 {#files}

会话中出现文件链接时，可以打开资源面板检查预览与文件位置。不同文件格式的可预览能力不同；
不能预览时，用相应的软件检查实际文件。

CAD 布局、三维 HTML 与 Excel 报价可以分别交付，不要求每个任务都经过全部步骤。
提出修改要求时，明确目标文件与需要保留的内容，避免误改其他成果。

## 继续之前的工作 {#continue}

从项目或独立会话列表打开历史会话，补充本次目标。新的任务先核对已生成文件是否仍在原位置，
以及外部资料是否有变化。历史回复不保证文件仍存在，也不代表当时未完成的操作已经完成。

## 浏览较长的会话 {#history-navigation}

消息历史按完整轮次加载，默认每页 10 轮；单轮中的工具调用和中间输出不会被拆到另一页。

聊天左侧留白充足时会出现缩略导航。悬停条目可预览用户输入及紧随其后的最后一段助手正文，没有助手正文时只显示用户输入。预览按需读取，点击后按顺序补齐历史并定位到对应位置。缩略列表可以单独滚动，初次打开默认显示底部；窗口较窄时自动隐藏。

## 编辑并重发一条消息 {#edit-message}

从 0.33.1 起，可以把指针移到自己的消息上，或用键盘聚焦消息操作栏，然后选择“编辑”。空闲会话中可编辑在该会话直接发送的消息，继承消息仍可复制。

原输入会载入底部输入框，可以调整文字、附件、引用及执行选项，也可以原样重发。编辑时其他附属抽屉暂时隐藏，输入框上方仅显示编辑抽屉；“返回原位置”用于查看原消息，“取消”会恢复普通草稿并保留会话历史。运行中不显示编辑入口。

点击发送后，Runtime 保留该条之前的历史，用编辑后的消息开始新一轮。原消息及其后续记录会从当前会话移除，已经发生的文件修改或外部操作仍需单独处理。如果显示“发送结果尚未确认”，请使用“重试原发送”核实同一次提交。

## 从一条回复尝试另一种方向 {#fork}

在助手回复旁选择“从此消息分叉”，确认创建后，会打开保留该回复及之前可靠历史的新会话。
可以继续从分支创建分支，再分别输入新的要求。

继承历史不再重复显示“继承”标签，原有只读限制保持；在一轮中途分支时，“截至分支点”表示只保留到所选位置的内容，
后续结果和结束时间仍属于原会话。历史中的旧任务供阅读，新输入从分支独立执行。

删除来源会话后，分支保留的历史仍可阅读。可用的会话附件、工具图片和相关子任务历史随分支独立保留；
已经缺失的资源会显示不可用。工作目录中的外部文件仍需自行保留，继续工作前请核对实际文件。

## 排队、耗时与读取失败 {#loading}

按 Enter 正常发送；已有运行任务时，消息进入待执行队列。需要立即调整方向时，按 Ctrl + Enter，macOS 也可按 Command + Enter；已有队列消息可点击“介入”。当前运行会被打断，已输出的思考内容和正文保存后，由介入消息接续运行。介入用于引导后续执行，不替换已有 Goal 的目标。

介入成功的消息直接出现在消息列表中。若未能完成切换，请按界面提示核实原请求或处理保留的队列消息。普通停止和运行失败也会保留已生成的内容，但不会撤销已经执行的文件修改或外部操作。

待执行消息显示在队列抽屉中，耗时从真正开始执行后计算；重试使用本次执行的起点。
历史没有可靠起止时间时，界面保留未知状态。

读取遇到临时繁忙时会有限重试。仍然繁忙或超时后，可点击“重新读取”或“重试”。
切换会话只切换当前阅读内容，已接纳的后台任务继续由 Runtime 执行。

备份会话时请保留完整 Runtime 数据目录，其中包含会话历史与受管资源；仅保存单个数据库文件不足以恢复全部历史。

升级初始化时会显示数据库检查、备份、历史迁移及恢复阶段；已知总量时显示当前阶段的完成数量。自动升级备份只保全数据库、会话历史和配套配置，项目文件、虚拟环境、依赖与缓存不纳入。上述完整 Runtime 目录备份建议用于用户主动保全全部会话资源，与自动迁移备份的范围不同。
