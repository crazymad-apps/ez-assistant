“企业知识库 · GoRAG”帮助你查找企业文档、阅读相关段落，并在回答中保留引用。适合查询制度、设备要求和项目资料。

## 使用前准备 {#prepare}

向管理员获取适用于本企业工作空间的插件包，安装并启用。当前包已配置服务连接与访问凭据，用户无需填写参数，也不要把密钥粘贴到会话中。

插件包包含工作空间访问凭据，仅供可信人员和设备定向使用，不上传公开渠道或企业市场。插件只能查询其绑定的工作空间。

实际运行插件的 Runtime 必须能访问企业知识库服务。连接远程 Runtime 时，应检查远端网络，而不只是客户端电脑的网络。

## 检索与追问 {#use}

1. 在会话中明确提出“查询企业知识库”，带上问题、文档名称或关键词。
2. 不清楚资料在哪时，可以先让助手列出可访问的知识库或相关文档，再缩小范围。
3. 需要准确核对时，要求读取相关正文并给出文档标题与引用；需要综合解答时，可以指定已有 GoRAG 智能体。
4. 查看回答的引用，继续追问具体条款、适用范围或上下文。

## 可以这样说 {#examples}

> 查询企业知识库里的设备维护要求，列出维护周期和注意事项，并保留文档来源。

> 先找出与这个项目有关的验收文档，再读取相关段落。没有找到的内容请明确说明，不要补写结论。

> 刚才提到的维护要求适用于哪个型号？请结合原文上下文再核对一下。

## 如何核对答案 {#result}

回答应保留知识库、文档标题及可用引用。没有命中或引用为空时，不能把回答视为已经获得企业资料支持；可以调整关键词或缩小范围再查。

GoRAG 问答不会自动同步整个 EZ Assistant 会话历史。跨问题追问时，把关键对象与条件说清楚，方便助手提供所需上下文。

## 常见问题 {#faq}

- **无法连接或超时。** 检查 Runtime 所在设备的网络与服务可用性，稍后再试或联系管理员。
- **没有权限、凭据失效。** 联系管理员核对工作空间和插件包；不要自行在对话中填写访问密钥。
- **找不到文档。** 核对名称、查询范围和文档处理状态；一次未命中不等于资料不存在。
- **没有默认智能体。** 先让助手列出可用智能体，再明确选择。

插件只提供查询和问答，不负责上传、修改或删除知识库文档。问答可能消耗知识库服务的模型额度。
