# v0.32.0

发布日期：2026-10-19

- 新增企业设备管理，支持设备申请登记、管理员审批、用户分配和访问权限管理。
- 支持在桌面客户端切换授权设备，查看和操作对应设备的项目、会话、文件与终端。
- 新增远程桌面查看与控制，支持 macOS、Windows、显示器选择、全屏及适应窗口显示。
- 支持置顶跨设备会话，并显示运行状态；右侧资源栏随当前会话或草稿切换。
- 新增 OpenCode 服务商配置，支持模型目录发现及 Chat、Responses 接入。
- 修复切换上下文压缩方式时重新带入已压缩旧历史的问题。
- 修复远程终端断开后关闭标签卡住的问题。
- 优化产物列表检查与刷新，减少列表闪烁，并改善右栏图片预览居中显示。
- 工具参数 JSON 无效时，支持在有限次数内反馈模型纠正，减少任务直接中断。
