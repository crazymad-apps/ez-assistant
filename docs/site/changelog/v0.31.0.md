# v0.31.0

发布日期：2026-10-14

- 企业中心新增官网首页、客户端下载、更新日志和操作手册，无需登录即可查看。
- 登录首页增加登录选项，可直接选择个人或企业模式、修改企业中心地址；切换模式时保留已填写的地址。
- 新增“设置 → 外观”，提供默认浅色、Monokai、Solarized Light、Solarized Dark 四套配色，即时生效并自动保存。
- 侧栏、会话、代码、图表、编辑器和终端同步切换配色，保留当前内容与阅读位置。
- 模型调用记录支持保留异常及结果未确认调用的请求体、响应体，帮助排查上游错误与响应中断。
- 调用正文按请求消息和响应事件分栏展示，合并连续增量，支持定位异常和查看原文。
- 安装包版本详情支持编辑、预览更新说明，官网与客户端展示同一份内容。
- 优化 macOS 应用图标，移除图标画布外侧多余留白。
