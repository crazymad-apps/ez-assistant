# v0.32.1

已按当前交付范围完成版本验收，尚未发布。

- 新初始化配置在关闭窗口时默认确认退出并停止本机后台，已有设置保持；退出时仍可选择保留后台继续任务。
- 改进 macOS Dock、Finder 和托盘唤起，以及 Windows 快捷方式重复打开时的窗口恢复。
- 修复旧本机后台启动中或版本不兼容时无法停止、重启的问题。
- Windows 安装器可在开始安装后自动关闭当前安装的旧客户端和后台。
- macOS DMG 内置系统安装程序，安装前自动关闭当前安装的客户端和后台，保留原数据目录。
- 保留未登录和旧后台协议不兼容时的应用内更新入口。
- 移除登录页残留的用户菜单和重复更新提示。
- 修正分支历史的轮次、工具与子任务归属；连续分支及删除来源后，保留的历史与受管资源仍可独立读取。
- 排队阶段不累计执行耗时，重试、刷新和历史显示使用可靠的实际开始时间。
- 改进并发会话读取；持续繁忙或超时后显示重读入口，快速切换和重连时保留当前阅读结果的一致性。
- 会话历史统一保存在会话文件中；输入入队后只暂存，实际开始处理时才显示处理过程，等待期间可以撤销。
- 升级备份只包含迁移所需数据库、会话历史及必要配置，不复制项目文件或虚拟环境；显示实际迁移阶段与进度，升级成功并校验后删除本轮备份，失败时保留。
- 改进长会话加载和新消息响应：冷启动恢复压缩后的有效上下文，后续增量维护，减少重复历史扫描；输出期间读取会话不再因文字流反复重读。
- 主会话与子任务的用量使用持久快照，重启后可恢复，避免查看用量时反复读取全部历史。
- 统一本地手动压缩与自动压缩的处理流程，改进压缩后的继续对话、取消和重启恢复。
- 内置 DeepSeek 搜索与 skill-creator，随应用更新。DeepSeek 搜索默认关闭，配置后需主动启用；支持通过界面或授权 Agent 配置插件与内置 MCP。
- 同名 MCP 按用户添加、普通插件、内置资源的优先级加载；被覆盖的条目仍可管理，连接错误以中文说明来源和已识别的缺失配置。
- Agent 在新会话中获得当前运行模式和目录说明；内置操作指引涵盖运行环境、Skill、MCP 和插件开发，并支持离线按需读取。
- 官网操作手册与会话共用 Markdown 排版，修复代码块语言高亮与布局。
- 网页版会话中的外链默认在浏览器新标签页打开。
- 修复置顶会话的运行图标在鼠标悬停或按钮保有焦点时消失的问题。
- 支持 Sub2API 模型目录发现，改进兼容服务的模型列表解析及未声明能力的默认处理。
- 随应用提供本地搜索工具，修复大型普通附件误触图片大小限制，并兼容更多模型的思考内容响应字段。

长会话复制分支的性能优化、跨网络连接稳定性仍待后续处理。
