# v0.33.0

本版本新增多组织工作区、企业模式下的多模型选择，以及插件应用页面与交互卡片。

## 多组织工作区

- 同一账号可以加入多个组织，登录后选择进入的组织。会话、记忆、文件记录和个人模型配置按组织独立保存。
- 在左下角账号菜单的姓名下方切换组织。有任务运行时，确认终止并等待后台全部收尾后才切换；失败时保留原组织。
- 新增组织管理员，原管理员升级为系统管理员。后台通过统一范围入口切换组织或系统管理，组织资源、设备、调用记录和反馈按范围管理。
- 企业登录凭据有效期固定为 7 天；切换范围换发对应凭据，撤销授权即时失效。

## 企业与个人模型

- 管理员可为组织配置多个可用模型、默认模型，以及是否允许成员自行选择。
- 企业模式下可选择组织模型，也可配置个人服务商和密钥。选择列表在两类模型之间显示分隔线，只有一类时不分组。
- 企业模型经中心调用，个人模型使用本人配置直连；配置和历史选择保留在所属组织工作区。

## 插件应用与消息卡片

- 支持 MCP Apps 和轻量插件的交互卡片，显示在助手正文下方，可恢复最近保存的状态。
- 右侧资源栏新增“应用”，支持插件内置页面及经授权接入的 HTTP／HTTPS 外部页面。普通浏览器与应用标签分别保留。
- 卡片可打开右侧应用并接收结果。页面工具调用遵循权限规则；重载卡片不会重新执行历史业务操作。

## 界面与更新修复

- 会话搜索弹窗按窗口可用高度收缩，搜索结果在弹窗内滚动。
- 改善拖动资源栏分隔线时卡片滚动条显隐引起的布局跳变，统一输入区按钮为圆形样式。
- 更新下载地址按当前配置的企业中心解析，支持相对路径及历史绝对路径响应。

## 追加修复（本地测试包，尚未正式发布）

- 修复升级后旧会话因模型配置指纹变化而无法继续的问题，保留组织工作区隔离。
- 修复聊天正文资源文件菜单位置偏移；菜单靠近窗口边缘时自动调整，滚动正文时关闭。

上述两项已纳入最新 macOS 测试包，现有正式发布包尚未包含。

## 升级说明

- 企业中心、客户端和 Runtime 需配套升级，客户端与 Runtime 最低兼容版本提高到 0.33.0。
- 历史企业数据归入默认组织；其他组织使用独立工作区。升级前备份中心数据库、文件及本机 Runtime 数据，升级后重新登录。
