# v0.33.2

- 新增定时任务。可安排助理按时完成工作，也可以直接运行 Shell 脚本。支持一次、每日或每周执行，在计划详情查看结果和文件，也可让助理在主控会话汇报。
- Shell 命令可在后台继续运行。在会话右侧「当前上下文」中点开命令即可查看实时输出、向上翻阅或停止进程。进程结束后自动移除。
- 「当前上下文」的运行记录、技能、子任务、附件和产物支持分页查看。
- 客户端和 Runtime 需配套升级至 0.33.2。升级前请备份 Runtime 数据目录，旧版 Host 无法打开升级后的数据库。
