# v0.32.2

本版本重点改善网络波动下的会话稳定性，优化上下文压缩、MCP 结果处理与语音播报体验。

## 网络与会话稳定性

- 修复企业中心暂时不可达时意外退出登录的问题。短暂网络波动期间保留登录状态，网络恢复后通过保活重新核验连接与身份。
- 修复企业中心不可达时，本机会话、工具详情等本地数据无法读取的问题；企业中心连接异常不再阻断已登录用户对本机 Runtime 的正常访问。
- 分别展示企业中心连接异常、Runtime 断连和模型请求重试状态。恢复企业中心连接提示，完善模型等待响应、自动重试次数及失败原因的展示。
- 修复任务已结束但界面仍显示“运行中”、侧栏持续转圈或仍可点击中断的问题，使会话展示与实际任务状态保持一致。

## 上下文与模型调用

- 修复切换压缩方式后，已有压缩结果的会话无法再次执行本地压缩的问题，改善长会话继续处理上下文的体验。
- 完善 OpenAI 服务端流式压缩及企业中心转发支持，并改进压缩失败时的错误提示。
- 优化 MCP 工具结果转换：当文本 JSON 与结构化结果内容相同时，仅向模型提供一份，保留其他有效内容，减少重复结果造成的上下文占用和输入 Token 消耗。

## 语音与预览体验

- 语音播报按标点自动分段，每段最多 60 个字符，按原文顺序连续播报。
- 修复切换 Wi-Fi 后智能终端发现无法恢复的问题。
- PNG 图片预览增加透明棋盘格背景，便于识别图片的透明区域。

## 升级说明

- 企业部署使用本版 OpenAI 服务端压缩能力时，需先更新配套企业中心，再更新客户端。
- 客户端与 Runtime 最低兼容版本保持为 0.32.1。
